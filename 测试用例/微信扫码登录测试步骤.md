# 微信扫码登录测试步骤

## 📋 测试前准备

### 1. 确认云函数已部署
- ✅ `wechat-login` 云函数已部署
- ✅ `wechat-bind` 云函数已部署

### 2. 确认数据库集合
- ✅ `wechat_sessions` 集合已创建
- ✅ `users` 集合已创建且有测试用户

### 3. 确认测试用户已绑定微信
需要一个已经绑定微信的测试用户，如果没有：
1. 先用密码登录
2. 在个人信息页面绑定微信
3. 或使用模拟器绑定微信

---

## ✅ 测试步骤 1: 生成登录二维码

### 操作步骤：
1. **确保已退出登录** (点击右上角头像 → 退出登录)
2. **刷新页面**,回到登录页
3. **点击"微信登录"按钮** (在密码输入框下方)
4. **等待二维码生成**

### 预期结果：
- 页面切换到微信登录界面
- 显示一个二维码
- 二维码下方显示"请使用微信扫描二维码"

### 获取 Scene ID 的方法：

#### 方法 1: 查看浏览器控制台 (推荐)
1. 按 `F12` 打开开发者工具
2. 切换到 **Console** 标签
3. 查找类似这样的日志:
   ```
   生成登录Scene: login_1735650000000_abc123def
   ```

#### 方法 2: 查看 Network 面板
1. 按 `F12` 打开开发者工具
2. 切换到 **Network** 标签
3. 找到 `wechat-login` 云函数调用
4. 查看 **Response** 标签:
   ```json
   {
     "code": 200,
     "message": "生成成功",
     "data": {
       "sceneId": "login_1735650000000_abc123def",
       "expiresAt": "2025-12-31T20:45:00.000Z"
     }
   }
   ```

#### 方法 3: 直接读取二维码内容
二维码的内容就是 Scene ID，但由于是机器可读的，建议使用方法1或2

---

## ✅ 测试步骤 2: 使用模拟器扫码

### 操作步骤：
1. **打开模拟器**
   - 在页面右上角找到"微信扫码模拟器"按钮
   - 或使用快捷键 (如果配置了)

2. **选择操作类型**
   - 点击右侧 **"微信登录"** 按钮 (绿色)
   - 确保按钮高亮显示

3. **输入 Scene ID**
   - 将步骤1中获取的 Scene ID 粘贴到输入框
   - 例如: `login_1735650000000_abc123def`
   - **注意**: 完整复制，包含 `login_` 前缀

4. **点击"模拟扫码"**
   - 等待 1 秒模拟扫码过程
   - 应该显示 "请确认操作"

5. **点击"确认登录"**
   - 模拟器调用云函数 `wechat-login`
   - action: `confirmLogin`

### 预期结果：

#### 场景 A: 用户已绑定微信 ✅
- 模拟器显示: "登录成功!"
- PC 端自动跳转到系统首页
- 显示用户信息
- 3秒后模拟器自动关闭

#### 场景 B: 用户未绑定微信 ⚠️
- 模拟器显示: "该微信未绑定任何账号"
- 提示需要先绑定微信
- 可以切换到绑定模式进行绑定

#### 场景 C: Scene ID 过期 ⏱️
- 模拟器显示: "二维码已过期"
- 需要刷新二维码重新测试

#### 场景 D: Scene ID 不存在 ❌
- 模拟器显示: "会话不存在或已过期"
- 可能原因:
  - Scene ID 输入错误
  - PC 端未正确生成二维码
  - Scene ID 已被使用或清理

---

## 🔍 故障排查

### 问题 1: 提示"会话不存在或已过期"

#### 可能原因:
1. **Scene ID 输入错误**
   - 检查是否完整复制 Scene ID
   - 确保包含 `login_` 前缀
   - 确保没有多余的空格

2. **PC 端二维码未正确生成**
   - 检查浏览器控制台是否有错误
   - 检查 Network 面板中云函数调用是否成功
   - 尝试刷新页面重新生成

3. **Scene ID 已过期**
   - Scene ID 有效期为 5 分钟
   - 重新生成二维码

4. **数据库连接问题**
   - 检查云函数日志
   - 确认 `wechat_sessions` 集合是否正确创建记录

#### 解决方法:
```javascript
// 1. 直接查询数据库确认 Session 是否存在
db.collection('wechat_sessions')
  .where({ sceneId: 'login_xxx' })
  .get()
  .then(res => console.log('Session:', res.data))

// 2. 手动创建测试 Session
db.collection('wechat_sessions').add({
  data: {
    sceneId: 'login_test_123',
    type: 'login',
    userId: null,
    username: null,
    status: 'pending',
    openid: null,
    unionid: null,
    createdAt: new Date(),
    expiresAt: new Date(Date.now() + 5 * 60 * 1000),
    scannedAt: null,
    confirmedAt: null
  }
})
```

### 问题 2: 提示"该微信未绑定任何账号"

这是正常的！说明云函数工作正常，只是当前微信还没有绑定用户。

#### 解决方法:
1. **先绑定微信**:
   - 使用密码登录
   - 进入个人信息页面
   - 使用"绑定微信"功能

2. **或使用模拟器绑定**:
   - 切换到"绑定微信"模式
   - 使用测试用户的 userId
   - 完成绑定流程

### 问题 3: PC 端没有反应

#### 检查项:
1. **PC 端是否正在轮询**
   - 检查 Network 面板
   - 应该每 2 秒调用一次 `checkLoginStatus`

2. **Session 状态是否更新**
   - 查询数据库中的 Session 记录
   - 检查 status 字段是否变为 `completed`

3. **Token 生成是否成功**
   - 检查云函数日志
   - 确认用户信息查询成功
