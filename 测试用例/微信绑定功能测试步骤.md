# 微信绑定功能测试步骤

## 测试环境
- **测试地址**: https://152.136.183.181:3443
- **测试账号**: 使用现有账号登录
- **测试时间**: 2025-12-31

## 功能位置
**路径**: 登录后 → 右上角用户头像 → 个人信息 → **微信绑定**标签

## 测试步骤

### 1. 访问微信绑定页面
1. 登录系统: https://152.136.183.181:3443
2. 点击右上角用户头像
3. 点击"个人信息"
4. 在标签栏中找到**"微信绑定"**标签(在"绩效"之后)
5. 点击"微信绑定"标签

### 2. 未绑定状态测试
**预期显示**:
```
[⚠️警告图标] 未绑定微信
绑定微信后可使用扫码快速登录

[立即绑定微信] (绿色按钮)
```

**操作**:
1. 点击"立即绑定微信"按钮
2. 弹出绑定弹窗

### 3. 绑定弹窗测试
**预期显示**:
- 标题: "绑定微信"
- 副标题: "使用微信扫码完成绑定"
- 二维码区域(WechatBinding组件)
- 关闭按钮(×)

**操作**:
1. 确认二维码正常显示
2. 使用模拟器或真实微信扫码
3. 等待绑定结果

### 4. 绑定成功测试
**预期结果**:
1. 显示成功提示: "微信绑定成功!"
2. 弹窗自动关闭
3. 页面刷新,显示已绑定状态

**已绑定状态显示**:
```
[✓成功图标] 已绑定微信
您可以使用微信扫码快速登录系统
OpenID: wx_xxxxxxxxxxxxx

[重新绑定微信] (橙色按钮)
```

### 5. 重新绑定测试
**操作**:
1. 在已绑定状态下
2. 点击"重新绑定微信"按钮
3. 再次显示绑定弹窗
4. 扫码完成新的绑定

**预期**:
- 原OpenID被替换为新OpenID
- 显示成功提示

### 6. 云函数验证
**检查点**:
1. 绑定成功后,检查`users`集合
2. 确认用户文档中`wechatOpenId`字段已更新
3. 字段格式: `wx_xxxxxxxxxxxxxxxxxx`

### 7. 微信扫码登录验证
**前提**: 已成功绑定微信

**操作**:
1. 退出当前账号
2. 在登录页点击"微信扫码登录"
3. 使用已绑定的微信扫码
4. 确认能否成功登录

**预期**:
- 扫码后自动登录
- 跳转到工作台
- 显示用户信息

## 可能的问题

### 问题1: 二维码不显示
**原因**: 
- 云函数未部署
- 网络连接失败

**解决**:
- 检查`wechat-bind`云函数
- 查看浏览器控制台错误

### 问题2: 扫码后无反应
**原因**:
- 轮询未启动
- 云函数返回错误

**解决**:
- 检查网络请求
- 查看云函数日志

### 问题3: 绑定后状态未更新
**原因**:
- 页面未刷新
- 数据库写入失败

**解决**:
- 手动刷新页面
- 检查数据库权限

### 问题4: 重复绑定
**原因**:
- 同一微信绑定多个账号

**解决**:
- 云函数已做检查
- 显示"此微信已绑定其他账号"
