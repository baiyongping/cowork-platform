## 🎯 测试原则

### ✅ 精简原则
- 每个模块只保留5个最核心的测试点
- 聚焦核心业务流程
- 删除边缘场景测试

### ✅ 实用原则
- 每个测试点1-3步操作
- 预期结果清晰明确
- 支持快速验证

---

## 🚀 如何使用

### 场景1：功能开发完成后测试
1. 找到对应模块的测试用例文件
2. 按照5个核心测试点逐项验证
3. 确认所有测试点通过

### 场景2：快速回归测试
1. 找到模块的"快速回归检查清单"
2. 逐项快速验证（无需详细步骤）
3. 确认核心功能正常

### 场景3：新功能影响评估
1. 识别可能影响的模块
2. 对这些模块执行快速回归测试
3. 确保新功能不影响已有功能
