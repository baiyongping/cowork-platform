## 1️⃣ users 集合（用户信息）

### 📝 字段结构

```typescript
interface User {
  _id: string;                    // MongoDB自动生成的文档ID
  _openid?: string;               // CloudBase用户标识（微信登录时使用）
  
  // 基本信息
  username: string;               // 用户名（唯一，用于登录）
  password: string;               // 密码哈希（SHA-256）
  email: string;                  // 邮箱（唯一）
  phone: string;                  // 手机号
  name: string;                   // 真实姓名
  
  // 角色和权限
  role: 'admin' | 'user';         // 角色：管理员/普通用户
  department: string;             // 所属部门
  avatar?: string;                // 头像URL
  isActive: boolean;              // 是否激活
  
  // 审核相关
  approvalStatus: 'pending' | 'approved' | 'rejected'; // 审核状态
  approvedBy?: string;            // 审核人ID
  approvedAt?: Date;              // 审核时间
  rejectReason?: string;          // 拒绝原因
  
  // 安全相关
  needChangePassword: boolean;    // 是否需要修改密码
  lastLoginAt?: Date;             // 最后登录时间
  
  // 系统字段
  status: '在职' | '离职' | '休假';  // 员工状态
  createdAt: Date;                // 创建时间
  updatedAt: Date;                // 更新时间
}
```

| `_openid_1` | `_openid` | 普通索引 | CloudBase用户标识 |
| `username_unique` | `username` | 唯一索引 | 用户名唯一约束 |
| `email_unique` | `email` | 唯一索引 | 邮箱唯一约束 |

## 3️⃣ tasks 集合（任务管理）

### 📝 字段结构

```typescript
interface Task {
  _id: string;                    // MongoDB自动生成的文档ID
  
  // 基本信息
  name: string;                   // 任务名称
  description?: string;           // 任务描述
  level: '公司级' | '团队级' | '个人级';  // 任务级别
  type: '日常工作' | '商机跟进' | '项目任务'; // 任务类型
  
  // 状态和进度
  status: '未开始' | '进行中' | '已完成' | '延期' | '取消' | '暂停'; // 任务状态
  progress: number;               // 完成进度（0-100）
  
  // 责任人和协同
  owner: string;                  // 负责人ID（引用users._id）
  collaborators: string[];        // 协同人ID数组
  team?: string;                  // 所属团队
  
  // 时间计划
  startDate: Date;                // 开始日期
  endDate: Date;                  // 截止日期
  actualStartDate?: Date;         // 实际开始日期
  actualEndDate?: Date;           // 实际完成日期
  
  // 关联内容
  opportunityActionType?: string; // 商机跟进动作类型
  projectPhase?: string;          // 项目任务环节
  relatedTo?: string;             // 关联内容ID
  
  // 可见性
  isPublic: boolean;              // 是否公开
  
  // 系统字段
  createdBy: string;              // 创建人ID
  createdAt: Date;                // 创建时间
  updatedAt: Date;                // 更新时间
}
```

## 🔗 数据关系说明

### 用户关系
- `users._id` → `tasks.owner` （任务负责人）
- `users._id` → `tasks.collaborators[]` （任务协同人）
- `users._id` → `opportunities.owner` （商机负责人）
- `users._id` → `projects.owner` （项目负责人）
- `users._id` → `projects.members[]` （项目成员）
- `users._id` → `goals.owner` （目标负责人）
- `users._id` → `departments.leader` （部门负责人）

### 业务关系
- `opportunities._id` → `projects.opportunityId` （商机→项目）
- `tasks.relatedTo` → `opportunities._id` 或 `projects._id` （任务关联）
- `tasks._id` → `task_comments.taskId` （任务评论）

## 📝 数据库操作示例

### 查询示例

```typescript
// 查询某用户的所有进行中任务
const tasks = await db.collection('tasks')
  .where({
    owner: userId,
    status: '进行中'
  })
  .orderBy('endDate', 'asc')
  .get();

// 查询本月待成交商机
const startOfMonth = new Date('2025-12-01');
const endOfMonth = new Date('2025-12-31');
const opportunities = await db.collection('opportunities')
  .where({
    status: db.command.in(['意向', '报价', '谈判']),
    expectedCloseDate: db.command.gte(startOfMonth).and(db.command.lte(endOfMonth))
  })
  .get();

// 查询部门下的所有员工
const users = await db.collection('users')
  .where({
    department: '业务部',
    isActive: true
  })
  .get();
```
