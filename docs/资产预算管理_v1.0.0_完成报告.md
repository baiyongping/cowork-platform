- **数据集合**: `asset_budgets`
- **环境**: `jihua-oa-dev-3goht9irae4d949f`

- **明细字段**:
  - 物品名称（必填）

- **交互功能**:
  - ✅ 新增明细（绿色按钮）
  - ✅ 保存明细（蓝色按钮，新增后切换）
  - ✅ 删除明细（红色垃圾桶图标）
  - ✅ 自动计算总价：总价 = 数量 × 单价
  - ✅ 自动汇总总金额：所有明细总价之和

### 5. 数字格式化
- **千分位显示**: `Math.round(num).toLocaleString('zh-CN')`

- **单位统一**: 全部使用"元"（之前是"万元"）
- **应用范围**:
  - 预算总金额
  - 明细预算单价
  - 明细预算总价
  - 卡片列表总金额

### 6. 按钮状态切换
- **新增明细**状态:
  - 按钮文字: "新增明细"
  - 按钮颜色: 绿色（`bg-green-600`）
  - 图标: Plus
  
- **保存明细**状态:
  - 按钮文字: "保存明细"
  - 按钮颜色: 蓝色（`bg-blue-600`）
  - 图标: Save
  - 验证: 物品名称必填
  
- **状态管理**: `isAddingItem` 布尔值控制

### 7. 浏览/编辑模式（最新功能）⭐

#### 默认浏览模式

  - 成功提示: "预算已放入回收站"
  - 自动关闭模态框并刷新列表

#### UI细节优化

### 数据结构

```typescript
interface AssetBudget {
  _id?: string;
  name: string;                    // 预算名称
  category: string;                // 资产类别
  totalAmount: number;             // 总金额（元）
  completionDate: string;          // 采购完成日期
  department: string;              // 需求部门
  contactPerson: string;           // 对接人
  purchaseManager: string;         // 采购责任人
  status: string;                  // 采购状态
  items: BudgetItem[];             // 预算明细
  createdAt?: Date;
  updatedAt?: Date;
  createdBy?: string;
}

interface BudgetItem {
  id: string;
  itemName: string;          // 物品名称
  quantity: number;          // 数量
  unitPrice: number;         // 预算单价（元）
  totalPrice: number;        // 预算总价（元，自动计算）
  specifications: string;    // 规格属性
}
```

## 📝 使用说明

### 创建预算
1. 点击"新建预算"按钮
2. 填写预算名称、类别等基本信息
3. 点击"新增明细"添加物品项
4. 填写物品名称、数量、单价、规格
5. 点击"保存明细"（可继续添加）
6. 系统自动计算总金额
7. 点击底部"保存"按钮完成创建

### 查看预算
1. 在列表中点击任意预算卡片
2. 查看所有字段（只读模式）
3. 查看明细列表和总金额
4. 点击"关闭"或"X"退出

### 编辑预算
1. 打开预算详情（浏览模式）
2. 点击顶部"编辑"按钮
3. 修改任意字段或明细
4. 点击"保存"按钮完成修改
5. 自动返回浏览模式

### 删除预算
1. 打开预算详情
2. 点击"回收站"按钮
3. 在确认对话框中点击"确认删除"
4. 预算被移除，列表自动刷新
