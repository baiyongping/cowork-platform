# 邀请注册与扫码登录功能说明

## 📋 功能概述

本次开发实现了完整的**邀请注册**和**扫码登录**功能，包括：
1. ✅ Web端邀请注册功能
2. ✅ H5移动端注册页面
3. ✅ 首次登录绑定手机号
4. ✅ Web端扫码/账号登录切换
5. ✅ 超级管理员微信绑定弹窗
6. ✅ 小程序端扫码功能

---

## 🎯 功能详细说明

### 1. 邀请注册功能

#### Web管理端操作
**位置**：系统设置 > 用户管理 > 邀请注册按钮

**操作流程**：
1. 管理员点击"邀请注册"按钮
2. 系统自动生成：
   - 邀请码（7天有效）
   - 注册链接
   - 二维码图片
3. 管理员通过微信发送给受邀人

#### 受邀人注册流程
**访问方式**：
- 扫描二维码
- 点击邀请链接

**注册步骤**：
1. 在H5页面填写姓名
2. 用户名自动使用OpenID
3. 系统生成默认密码
4. 提交注册等待审核

**技术实现**：
- H5页面：`e:/cowork/public/register.html`
- 云函数：`cloudfunctions/createInvitation/` 和 `cloudfunctions/registerUser/`
- 数据库集合：`invitation_codes`

---

### 2. 审核后首次登录

#### 用户状态流转
```
注册完成 → 待审核
    ↓
管理员审核通过 → 已激活(未绑定手机)
    ↓
首次登录 → 强制跳转手机号绑定页面
    ↓
绑定成功 → 正常状态
```

#### 手机号绑定
**使用微信能力**：`wx.getPhoneNumber`

**实现方式**：
- 云函数：`cloudfunctions/bindPhone/`
- 小程序端调用微信获取手机号能力
- 验证并保存到用户记录

---

### 3. 登录方式

#### Web端登录页面
**支持两种登录方式**：

**方式1：账号密码登录**
- 输入用户名和密码
- 传统登录方式

**方式2：扫码登录**
- 显示登录二维码（2秒轮询）
- 用户用小程序扫码
- 确认后自动登录

**切换按钮**：
```
[账号登录] ←→ [扫码登录]
```

**技术实现**：
- 登录页面：`components/LoginPage.tsx`
- 云函数：`cloudfunctions/scanLogin/`
- 数据库集合：`login_codes`

---

### 4. 超级管理员微信绑定

#### 触发条件
- 超级管理员使用**用户名+密码**登录成功
- 且账号未绑定微信（`!user.wxOpenId`）

#### 绑定流程
1. 登录成功后自动弹出绑定弹窗
2. 显示绑定二维码（2秒轮询）
3. 用户用小程序扫码
4. 确认绑定
5. 绑定成功，关闭弹窗

#### 用户选择
- ✅ 绑定微信（扫码确认）
- ⏸️ 暂不绑定（下次登录继续提示）
- 🔕 不再提示（永久关闭）

**技术实现**：
- 绑定弹窗：`components/WechatBindModal.tsx`
- 主应用：`App.tsx`
- 云函数：`cloudfunctions/bindWxOpenId/`

---

### 5. 小程序端扫码功能

#### 扫码入口
**位置**：首页右下角浮动按钮

#### 支持的二维码类型
1. **注册邀请二维码**（`jihuaoa://invite?code=xxx`）
   - 跳转到浏览器完成注册
   - 自动复制注册链接

2. **登录二维码**（`jihuaoa://scanlogin?code=xxx`）
   - 确认后调用云函数
   - Web端自动登录

3. **绑定二维码**（`jihuaoa://bind?code=xxx`）
   - 确认后调用云函数
   - 绑定微信账号

**技术实现**：
- 扫码页面：`miniprogram/pages/scan/`
- 浮动按钮：首页添加

## ☁️ 云函数列表

### 1. `createInvitation`
- **功能**：生成邀请码和二维码
- **操作**：create（生成）、verify（验证）、list（列表）

### 2. `registerUser`
- **功能**：处理用户注册
- **逻辑**：验证邀请码 → 创建用户 → 标记邀请码已使用

### 3. `bindPhone`
- **功能**：绑定手机号
- **使用**：调用微信`wx.getPhoneNumber`获取手机号

### 4. `scanLogin`
- **功能**：扫码登录
- **操作**：create（生成登录码）、confirm（确认登录）、checkStatus（轮询状态）

### 5. `bindWxOpenId`（扩展）
- **功能**：微信绑定
- **新增操作**：
  - `generateBindCode`：生成绑定码
  - `confirmBind`：确认绑定
  - `checkBindStatus`：检查绑定状态
