## 🔐 权限设计

### 模块权限
每个模块支持以下权限：
- `view` - 查看权限
- `create` - 创建权限
- `edit` - 编辑权限
- `delete` - 删除权限
- `approve` - 审批权限（预算、绩效）

### 权限配置示例
```typescript
{
  budget: {
    view: ['admin', 'finance'],
    create: ['admin', 'finance'],
    edit: ['admin', 'finance'],
    delete: ['admin'],
    approve: ['admin', 'ceo']
  },
  meetings: {
    view: ['admin', 'all'],
    create: ['admin', 'all'],
    edit: ['admin', 'manager'],
    delete: ['admin']
  },
  performance: {
    view: ['admin', 'hr', 'manager'],
    create: ['admin', 'hr'],
    edit: ['admin', 'hr'],
    delete: ['admin'],
    approve: ['admin', 'manager']
  },
  business: {
    view: ['admin', 'sales', 'manager'],
    create: ['admin', 'sales'],
    edit: ['admin', 'sales', 'manager'],
    delete: ['admin']
  }
}
```

## 📝 开发注意事项

1. **数据一致性**: 所有模块都要与现有的任务、商机、项目、目标模块保持数据关联
2. **用户体验**: 统一的交互方式和视觉风格
3. **性能优化**: 大数据量场景的分页和懒加载
4. **权限控制**: 细粒度的权限控制，确保数据安全
5. **移动端适配**: 考虑响应式设计，支持移动端访问
