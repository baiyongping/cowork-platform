#### **表格样式优化**

**表头设计**：
- ✅ 渐变背景：`from-blue-600 to-indigo-600`
- ✅ 科目列：固定宽度 152px，蓝色渐变背景
- ✅ 年度预算列：100px，绿色背景 `bg-emerald-600`
- ✅ 月度列：80px，蓝紫渐变 `from-blue-500 to-purple-500`
- ✅ 实际总额列：100px，紫色背景 `bg-purple-600`
- ✅ 完成率列：90px，靛蓝背景 `bg-indigo-600`

**单元格样式**：
```css
/* 费用科目 */
- 固定左侧：sticky left-0 z-10
- 背景色：bg-gray-50
- 字体：font-medium text-gray-900

/* 年度预算 */
- 背景色：bg-emerald-50
- 文字颜色：text-emerald-700
- 悬停效果：ring-2 ring-emerald-400 bg-emerald-100

/* 月度数据 */
- 已过月份：bg-blue-50, text-blue-700
- 未到月份：bg-gray-100, text-gray-400
- 编辑悬停：ring-2 ring-blue-400 bg-blue-100

/* 实际总额 */
- 背景色：bg-purple-50
- 文字颜色：text-purple-700
- 字体：font-semibold

/* 完成率（动态颜色）*/
- >= 100%：bg-red-100, text-red-700
- >= 90%：bg-yellow-100, text-yellow-700
- >= 70%：bg-blue-100, text-blue-700
- < 70%：bg-emerald-100, text-emerald-700
```

**合计行设计**：
```css
- 背景：bg-gradient-to-r from-blue-100 via-indigo-100 to-purple-100
- 边框：border-t-2 border-indigo-300
- 字体：font-bold, text-base
- 年度预算列：bg-emerald-200, text-emerald-800
- 月度列：bg-blue-200, text-blue-800
- 实际总额列：bg-purple-200, text-purple-800
```
