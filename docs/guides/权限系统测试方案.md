## 📝 测试执行步骤

### 第一步：创建测试角色 (由admin执行)

1. 登录admin账号
2. 进入"系统设置" > "角色权限"
3. 依次创建上述三个测试角色
4. 配置对应的权限

### 第二步：创建测试用户 (由admin执行)

1. 在"系统设置" > "员工管理"
2. 添加三个测试用户
3. 分配对应的测试角色
4. 审核通过

### 第三步：执行测试用例

1. 按测试ID顺序执行
2. 记录实际结果
3. 标记状态: ✅通过 / ❌失败 / ⏳待测

### 第四步：问题修复

1. 收集失败的测试用例
2. 分析原因并修复代码
3. 重新测试失败用例
