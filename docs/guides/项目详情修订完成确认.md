### 需求2：项目经理在编辑状态下变更后，在项目详情里更新
**状态**: ✅ 已修复并验证

**问题根源**: `refreshProject()` 函数只刷新项目基础数据，没有查询 ownerName 和 memberNames

**修复方案**: 
在 `refreshProject()` 函数中添加负责人和成员名称查询逻辑

**修改文件**: `e:\cowork\components\ProjectDetailModal.tsx`
**修改位置**: 第21-55行

**修复内容**:
```typescript
const refreshProject = async () => {
  try {
    const result = await db.collection('projects').doc(project._id).get();
    if (result.data && Array.isArray(result.data) && result.data.length > 0) {
      const proj = result.data[0];
      
      // 查询负责人名称
      let ownerName = '未知';
      if (proj.owner) {
        const ownerRes = await db.collection('users').where({ _id: proj.owner }).get();
        if (ownerRes.data && ownerRes.data.length > 0) {
          ownerName = ownerRes.data[0].name;
        }
      }
      
      // 查询成员名称
      let memberNames: string[] = [];
      if (proj.members && proj.members.length > 0) {
        const memberRes = await db.collection('users')
          .where({ _id: db.command.in(proj.members) })
          .get();
        memberNames = memberRes.data.map((u: any) => u.name);
      }
      
      setCurrentProject({
        ...proj,
        ownerName,
        memberNames
      });
    }
  } catch (error) {
    console.error('刷新项目数据失败:', error);
  }
};
```

```typescript
const parseDeliverables = (deliverables?: string) => {
  if (!deliverables) return [];
  
  try {
    const products = deliverables.split('\n\n').filter(p => p.trim());
    
    return products.map(product => {
      const lines = product.split('\n').filter(l => l.trim());
      const nameMatch = lines[0]?.match(/^\d+\.\s+(.+)$/);
      
      // 兼容新旧字段名称：产品数量 / 需求数量
      const quantityMatch = lines.find(l => l.includes('产品数量') || l.includes('需求数量'))?.match(/(\d+)\s*件/);
      
      // 兼容新旧字段名称：单价 / 预算单价
      const unitPriceMatch = lines.find(l => l.includes('单价') && !l.includes('预算'))?.match(/([\d.]+)\s*元/)
        || lines.find(l => l.includes('预算单价'))?.match(/([\d.]+)\s*元/);
      
      // 总价
      const totalPriceMatch = lines.find(l => l.includes('总价'))?.match(/([\d.]+)\s*元/);
      
      // 兼容新旧字段名称：采购成本 / 预估成本
      const estimatedCostMatch = lines.find(l => l.includes('采购成本') || l.includes('预估成本'))?.match(/([\d.]+)\s*元/);
      
      return {
        productType: nameMatch?.[1] || '',
        quantity: parseInt(quantityMatch?.[1] || '0'),
        unitPrice: parseFloat(unitPriceMatch?.[1] || '0'),
        totalPrice: parseFloat(totalPriceMatch?.[1] || '0'),
        estimatedCost: parseFloat(estimatedCostMatch?.[1] || '0'),
        grossProfit: (parseFloat(totalPriceMatch?.[1] || '0') - parseFloat(estimatedCostMatch?.[1] || '0'))
      };
    });
  } catch (error) {
    console.error('解析项目交付产品失败:', error);
    return [];
  }
};
```

**兼容性说明**:
- ✅ 支持旧格式（需求数量、预算单价、预估成本）
- ✅ 支持新格式（产品数量、单价、采购成本）
- ✅ 向后兼容，不影响已有数据
