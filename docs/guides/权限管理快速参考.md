## 🔧 操作指南

### 新增角色

**步骤**:
1. 进入 系统设置 → 角色权限
2. 点击"新增角色"
3. 填写基本信息：
   - 角色标识（英文，如：sales_manager）
   - 角色名称（中文，如：销售经理）
   - 角色描述（职责说明）
4. 配置权限：
   - 勾选需要的权限checkbox
   - 注意：目标管理和系统设置有子模块
5. 点击"保存"

### 编辑角色权限

**步骤**:
1. 在角色列表中找到目标角色
2. 点击"编辑权限"
3. 修改权限配置
4. 点击"保存"

**注意**:
- admin角色不可编辑
- 修改后立即生效
- 已登录用户需重新登录

### 删除角色

**步骤**:
1. 在角色列表中找到目标角色
2. 点击"删除"
3. 确认删除

**注意**:
- admin角色不可删除
- 删除前请确保没有用户使用此角色

## 🚨 注意事项

### ⚠️ 删除权限谨慎授予
删除权限应该谨慎授予，建议：
- 只有管理员拥有删除权限
- 经理角色可以考虑不授予删除权限
- 使用软删除（回收站）代替硬删除

### ⚠️ 权限最小化原则
遵循最小权限原则：
- 只授予岗位必需的权限
- 不要"一刀切"授予全部权限
- 定期审查和调整权限配置

### ⚠️ 子模块权限独立配置
目标管理和系统设置的子模块权限是独立的：
- 可以只授予某个子模块的权限
- 可以对不同子模块授予不同权限
- 灵活组合，满足各种业务需求

## 🔍 故障排查

### 问题1: 权限配置后不生效
**解决方案**:
1. 确认角色配置已保存
2. 用户重新登录
3. 清除浏览器缓存
4. 检查数据库中的角色权限记录

### 问题2: 旧角色显示异常
**解决方案**:
1. 重新编辑旧角色
2. 保存权限配置
3. 完成数据迁移

### 问题3: 子模块权限不显示
**解决方案**:
1. 检查角色权限数据结构
2. 确认是否为双层权限结构
3. 使用默认结构重新创建角色
