## 功能说明

### 核心功能
1. **生成邀请码**: 管理员可以生成唯一的邀请注册码
2. **小程序码生成**: 自动生成微信小程序码，扫码即可跳转到注册页面
3. **自动过期**: 邀请码24小时后自动失效
4. **一次性使用**: 每个邀请码只能使用一次

### 用户流程
```
管理员 → 点击"邀请注册" → 生成邀请码 + 小程序码 
       ↓
    下载小程序码图片
       ↓
   分享给新员工
       ↓
新员工 → 微信扫码 → 跳转小程序注册页面 → 填写信息 → 完成注册
```

### 1. 前端实现

#### 1.1 邀请注册按钮（系统设置页面）

**位置**: `src/components/settings/Settings.tsx`

**核心代码**:
```typescript
const handleInviteRegister = async () => {
  try {
    setInviteLoading(true);
    
    // 调用云函数生成邀请码
    const result = await app.callFunction({
      name: 'createInvitation',
      data: { action: 'create' }
    });
    
    if (result.result.code === 200) {
      const { invitationCode, qrCodeBuffer, expireAt } = result.result.data;
      
      // 将Buffer转换为Blob并下载
      if (qrCodeBuffer && qrCodeBuffer.data) {
        const blob = new Blob(
          [new Uint8Array(qrCodeBuffer.data)], 
          { type: 'image/png' }
        );
        
        // 创建下载链接
        const url = window.URL.createObjectURL(blob);
        const a = document.createElement('a');
        a.href = url;
        a.download = `邀请注册_${invitationCode}.png`;
        a.click();
        window.URL.revokeObjectURL(url);
      }
    }
  } catch (error) {
    message.error('生成邀请码失败');
  } finally {
    setInviteLoading(false);
  }
};
```

**关键技术点**:
- 使用 CloudBase SDK 调用云函数
- Buffer 数据转换为 Blob 对象
- 动态创建下载链接并触发下载
- 完善的错误处理和加载状态

##### 功能2: 获取微信 Access Token

```javascript
async function getAccessToken() {
  const APPID = 'wx79afc92f6fe01a31';
  const SECRET = process.env.WX_APP_SECRET;
  
  return new Promise((resolve, reject) => {
    const url = `https://api.weixin.qq.com/cgi-bin/token?grant_type=client_credential&appid=${APPID}&secret=${SECRET}`;
    
    https.get(url, (res) => {
      let data = '';
      res.on('data', (chunk) => data += chunk);
      res.on('end', () => {
        const result = JSON.parse(data);
        if (result.access_token) {
          resolve(result.access_token);
        } else {
          reject(new Error(`获取access_token失败: ${result.errmsg}`));
        }
      });
    }).on('error', reject);
  });
}
```

**特点**:
- 从环境变量读取 AppSecret，避免硬编码
- 使用 HTTPS 直接调用微信 API
- 完善的错误处理

##### 功能3: 生成小程序码

```javascript
async function generateMiniProgramCode(accessToken, scene) {
  const postData = JSON.stringify({
    scene: scene,  // 邀请码作为场景值
    page: 'pages/register/register',  // 跳转到注册页面
    check_path: false,  // 开发阶段不检查路径
    env_version: 'develop',  // 使用开发版
    width: 280
  });
  
  return new Promise((resolve, reject) => {
    const options = {
      hostname: 'api.weixin.qq.com',
      port: 443,
      path: `/wxa/getwxacodeunlimit?access_token=${accessToken}`,
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Content-Length': Buffer.byteLength(postData)
      }
    };
    
    const req = https.request(options, (res) => {
      const chunks = [];
      
      res.on('data', (chunk) => chunks.push(chunk));
      res.on('end', () => {
        const buffer = Buffer.concat(chunks);
        
        // 检查是否返回错误（JSON格式）
        if (res.headers['content-type']?.includes('application/json')) {
          const error = JSON.parse(buffer.toString());
          reject(new Error(`微信API错误: ${error.errmsg}`));
        } else {
          resolve(buffer);  // 返回图片Buffer
        }
      });
    });
    
    req.on('error', reject);
    req.write(postData);
    req.end();
  });
}
```

**关键技术点**:
- 使用 `getwxacodeunlimit` 接口（不限生成次数）
- 场景值（scene）携带邀请码
- 返回 PNG 图片的 Buffer 数据
- 区分错误响应和图片响应

##### 功能4: 主流程

```javascript
exports.main = async (event, context) => {
  const { action = 'create' } = event;
  
  if (action === 'create') {
    // 生成邀请码
    const invitationCode = generateInvitationCode();
    const expireAt = new Date(Date.now() + 24 * 60 * 60 * 1000);
    
    // 存储到数据库
    await db.collection('invitations').add({
      data: {
        code: invitationCode,
        expireAt,
        used: false,
        createdAt: new Date()
      }
    });
    
    // 获取 access_token
    const accessToken = await getAccessToken();
    
    // 生成小程序码
    const qrCodeBuffer = await generateMiniProgramCode(accessToken, invitationCode);
    
    return {
      code: 200,
      message: '邀请码生成成功',
      data: {
        invitationCode,
        expireAt,
        qrCodeBuffer
      }
    };
  }
};
```

**流程说明**:
1. 生成随机邀请码
2. 计算过期时间（24小时）
3. 存储到数据库
4. 获取微信 access_token
5. 调用微信API生成小程序码
6. 返回邀请码和小程序码图片

## 关键技术突破

### 问题1: `missing wxCloudApiToken` 错误

**问题描述**:
最初使用 `cloud.openapi.wxacode.getUnlimited()` 时报错：
```
errCode: -501007
errMsg: cloud.openapi.wxacode.getUnlimited:fail missing wxCloudApiToken
```

**根本原因**:
云开发环境的 `cloud.openapi` 调用方式需要环境具备微信开放接口的权限配置。

**解决方案**:
改用 **HTTPS 直连方式**调用微信 API：
1. 手动获取 `access_token`
2. 直接调用微信开放接口
3. 绕过云开发环境的权限限制

**优势**:
- ✅ 不依赖云开发环境配置
- ✅ 更灵活的错误处理
- ✅ 可以精确控制请求参数

---

### 问题2: Buffer 数据传输

**问题描述**:
小程序码图片需要从云函数传输到前端，并触发下载。

**解决方案**:
1. **云函数端**: 直接返回 Buffer 对象
2. **前端接收**: CloudBase SDK 自动序列化为 `{ type: 'Buffer', data: [...] }`
3. **前端转换**: 
   ```javascript
   const blob = new Blob(
     [new Uint8Array(qrCodeBuffer.data)], 
     { type: 'image/png' }
   );
   ```
4. **触发下载**: 创建临时 URL 并触发下载
