# 小程序码生成配置完整指南

## 问题描述

当前邀请注册功能无法生成小程序码，报错：
```
missing wxCloudApiToken
errCode: -501007 invalid parameters
```

## 根本原因

虽然 `jihua-oa-dev-3goht9irae4d949f` 是小程序的云开发环境，但**调用微信开放接口（如生成小程序码）需要额外的权限配置**。

## 🎯 解决方案

### 方案一：腾讯云 CloudBase 控制台配置（推荐）

#### 步骤1：访问控制台

打开链接：
```
https://console.cloud.tencent.com/tcb/env/setting?envId=jihua-oa-dev-3goht9irae4d949f&tabId=wx
```

或者：
1. 访问：https://console.cloud.tencent.com/tcb
2. 选择环境：`jihua-oa-dev-3goht9irae4d949f`
3. 点击左侧菜单 **环境设置 → 微信小程序**

#### 步骤2：配置小程序授权

1. 在 **微信小程序** 标签页
2. 点击 **授权小程序**
3. 输入小程序信息：
   - **AppID**: `wx79afc92f6fe01a31`
   - **AppSecret**: `[您的小程序密钥]`
4. 点击 **保存**

#### 步骤3：启用云调用

1. 在同一页面找到 **云调用**
2. 开启 **微信开放接口** 权限
3. 确认启用 `wxacode.getUnlimited` API

#### 步骤4：等待生效

配置保存后，等待 **1-2分钟** 让配置生效。

---

### 方案二：使用备用二维码（临时方案）

如果方案一配置复杂或暂时无法完成，可以使用备用方案：

#### 修改前端代码

修改 `components/pages/SystemSettings.tsx`，当小程序码生成失败时，使用第三方二维码服务：

```typescript
// 如果 qrCodeBuffer 不存在，使用备用二维码
if (!qrCodeBuffer) {
  // 使用 QR Code API 生成邀请码文本二维码
  const fallbackUrl = `https://api.qrserver.com/v1/create-qr-code/?size=280x280&data=${invitationCode}`;
  setQrCodeUrl(fallbackUrl);
}
```

**优点**:
- ✅ 立即可用，无需配置
- ✅ 零依赖

**缺点**:
- ❌ 扫码后显示的是邀请码文本，需要用户手动输入
- ❌ 不如小程序码方便
