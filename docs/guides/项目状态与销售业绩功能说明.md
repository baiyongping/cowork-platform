# 项目状态与销售业绩功能实现说明

## 功能概述

本次更新实现了两个核心功能：
1. **项目状态与进度自动联动**：当项目状态改为"已完成"时，项目进度自动变为100%
2. **销售业绩计入功能**：已完成的项目可以将总金额计入目标管理模块的销售收入目标

---

## 一、项目状态与进度联动

### 1.1 功能说明

- **触发条件**：项目状态更改为"已完成"
- **自动行为**：项目进度（progress）自动设置为 100%
- **生效场景**：
  - ✅ 在项目列表中直接修改状态
  - ✅ 在编辑模态框中修改状态
  - ✅ 项目详情页面实时更新进度显示

### 1.2 实现逻辑

#### 场景1：项目列表中直接修改状态
**文件**：`components/pages/ProjectManagement.tsx`
**函数**：`handleUpdateProjectStatus`

```typescript
const handleUpdateProjectStatus = async (projId: string, newStatus: ProjectStatus) => {
  const updateData: any = {
    status: newStatus,
    updatedAt: new Date(),
  };
  
  // 如果状态改为"已完成"，自动将进度设为100%
  if (newStatus === '已完成') {
    updateData.progress = 100;
  }
  
  await db.collection('projects').doc(projId).update(updateData);
  await loadProjects();
};
```

**效果**：
- 用户在项目列表中选择"已完成"状态
- 系统自动将进度设为100%
- 进度条立即更新显示

## 二、销售业绩计入功能

### 2.1 功能说明

- **显示条件**：仅当项目状态为"已完成"时显示"计入销售业绩"按钮
- **计入规则**：
  - 项目总金额 = 所有交付产品的总价之和
  - 计入时期 = 根据项目交付日期（endDate）确定年份和季度
  - 计入目标 = `sales_goals` 集合中的 `revenueActual` 字段
- **防重复机制**：
  - 项目添加 `revenueRecorded` 字段标记是否已计入
  - 已计入后，按钮变灰且显示"已计入业绩"
  - 无法重复计入

### 2.2 实现逻辑

#### 核心函数：handleRecordRevenue
**文件**：`components/ProjectDetailModal.tsx`

**步骤1：前置检查**
```typescript
// 检查是否已计入
if (currentProject.revenueRecorded) {
  alert('该项目已计入销售业绩，无法重复计入');
  return;
}

// 检查项目总金额
if (!totalAmount || totalAmount <= 0) {
  alert('项目总金额为0，无法计入销售业绩');
  return;
}
```

**步骤2：确定计入时期**
```typescript
// 获取项目交付日期的年份和季度
const endDate = new Date(currentProject.endDate);
const year = endDate.getFullYear();
const quarter = `Q${Math.floor(endDate.getMonth() / 3) + 1}` as 'Q1' | 'Q2' | 'Q3' | 'Q4';

// 转换金额单位（元 → 万元）
const revenueAmount = totalAmount / 10000;
```

**步骤3：更新季度销售目标**
```typescript
// 查询对应年份和季度的销售目标
const quarterlyGoalResult = await db.collection('sales_goals')
  .where({
    year: year,
    quarter: quarter,
    type: 'quarterly'
  })
  .get();

if (quarterlyGoalResult.data && quarterlyGoalResult.data.length > 0) {
  // 存在记录：累加销售收入
  const goal = quarterlyGoalResult.data[0];
  const newRevenueActual = (goal.revenueActual || 0) + revenueAmount;
  
  await db.collection('sales_goals').doc(goal._id).update({
    revenueActual: newRevenueActual,
    updatedAt: new Date(),
  });
} else {
  // 不存在记录：创建新记录
  await db.collection('sales_goals').add({
    year: year,
    quarter: quarter,
    type: 'quarterly',
    orderTarget: 0,
    orderActual: 0,
    revenueTarget: 0,
    revenueActual: revenueAmount,
    createdBy: currentProject.owner,
    createdAt: new Date(),
    updatedAt: new Date(),
  });
}
```

**步骤4：更新年度销售目标**
```typescript
// 同步更新年度销售目标（逻辑同季度）
const annualGoalResult = await db.collection('sales_goals')
  .where({
    year: year,
    type: 'annual'
  })
  .get();

// ... 累加或创建年度记录 ...
```

**步骤5：标记项目已计入**
```typescript
// 更新项目记录
await db.collection('projects').doc(currentProject._id).update({
  revenueRecorded: true,
  revenueRecordedAt: new Date(),
  updatedAt: new Date()
});

// 刷新项目详情
await refreshProject();
```

```typescript

  _id?: string;

  quarter?: 'Q1' | 'Q2' | 'Q3' | 'Q4'; // 季度（季度目标）
  type: 'annual' | 'quarterly';    // 类型
```

## 三、已完成项目的状态锁定

### 3.1 功能说明

- **限制规则**：项目状态为"已完成"后，状态字段不可再修改
- **限制范围**：
  - ✅ 项目详情页面：编辑按钮变灰且禁用
  - ✅ 编辑模态框：状态选择框禁用

### 3.2 实现逻辑

#### 项目详情编辑按钮

## 五、注意事项

### 5.1 数据一致性

- ⚠️ 销售业绩计入后无法撤销，请确保项目总金额和交付日期正确
- ⚠️ 已完成的项目状态无法修改，如需调整请联系管理员通过数据库操作

### 5.2 权限说明

- 所有用户都可以将自己负责的已完成项目计入销售业绩
- 建议：后续可以考虑限制为仅管理员或项目经理可操作

### 5.3 后续优化建议

1. **撤销计入功能**：为管理员提供撤销计入销售业绩的功能
2. **批量计入**：支持批量选择多个已完成项目一次性计入
3. **计入历史**：记录详细的计入历史，包括操作人、操作时间、金额等
4. **后端验证**：在云函数或API层面添加业务逻辑验证，防止绕过前端限制
