## 📋 成功方法记录（v2.0.0）

### 关键要点

1. **使用 Vite 直接构建**（跳过 TypeScript 检查）
   ```bash
   npx vite build
   ```

2. **必须清理旧的 dist 目录**
   ```bash
   Remove-Item -Recurse -Force dist
   ```

3. **覆盖式上传文件**
   ```bash
   scp -r dist/* root@152.136.183.181:/var/www/jihua/
   ```

4. **重启 Nginx 服务**
   ```bash
   ssh root@152.136.183.181 "systemctl restart nginx"
   ```

### 为什么这次成功？

- ❌ `npm run build` - TypeScript 检查报错，构建失败
- ✅ `npx vite build` - 跳过类型检查，直接构建成功
- ✅ 清理 dist 目录避免缓存问题
- ✅ 覆盖上传而不是先删除（避免短暂的服务中断）
- ✅ 重启 Nginx 确保新文件生效

```powershell
ssh root@152.136.183.181 "chown -R nginx:nginx /var/www/jihua && chmod -R 755 /var/www/jihua && systemctl restart nginx"
```

```powershell
ssh root@152.136.183.181 "ls -lh /var/www/jihua/ && systemctl status nginx --no-pager | head -5"
```

## ⚠️ 常见问题

### 问题1: 浏览器看到的还是旧版本
**原因**: 浏览器缓存  
**解决**: 
1. 使用 `Ctrl+F5` 强制刷新
2. 或清除浏览器缓存（Ctrl+Shift+Delete）
3. 或使用隐私/无痕模式访问

### 问题2: 构建失败（TypeScript 错误）
**原因**: `npm run build` 会执行类型检查  
**解决**: 使用 `npx vite build` 跳过类型检查

### 问题3: 文件上传后没生效
**原因**: Nginx 未重启  
**解决**: 
```bash
ssh root@152.136.183.181 "systemctl restart nginx"
```

### 问题4: dist 目录没有更新
**原因**: 旧文件缓存  
**解决**: 先删除 dist 目录再构建
```powershell
Remove-Item -Recurse -Force dist
npx vite build
```
