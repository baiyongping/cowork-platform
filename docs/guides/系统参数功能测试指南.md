# 系统参数功能测试指南

## 测试目标

验证系统参数功能正确实现，确保：
1. ✅ 系统参数正确显示"系统参数"徽章
2. ✅ 系统参数的编辑和删除按钮被禁用
3. ✅ 尝试编辑/删除系统参数时显示提示信息
4. ✅ 新增的自定义参数可以正常编辑和删除
5. ✅ 数据正确保存到数据库

## 测试环境准备

### 1. 启动开发服务器
```bash
cd e:\cowork
npm run dev
```

### 2. 登录系统
- 使用管理员账号登录
- 确保有系统设置访问权限

## 测试步骤

### 测试1：验证系统参数显示

**操作步骤：**
1. 登录系统
2. 点击右上角用户头像 → 系统设置
3. 点击"类型设置"标签页
4. 展开任意类型设置块（例如：任务类型设置）

**预期结果：**
- ✅ 每个默认选项旁边显示蓝色的"系统参数"徽章
- ✅ 系统参数的"编辑"按钮显示为灰色
- ✅ 系统参数的"删除"按钮显示为灰色
- ✅ 自定义参数（如果有）没有"系统参数"徽章
- ✅ 自定义参数的编辑和删除按钮显示为蓝色/红色（正常状态）

**截图位置：**
- 任务类型设置块（展开状态）
- 商机阶段设置块（展开状态）

---

### 测试2：尝试编辑系统参数

**操作步骤：**
1. 在类型设置页面
2. 找到任意带有"系统参数"徽章的选项
3. 尝试点击"编辑"按钮

**预期结果：**
- ✅ 按钮无法点击（禁用状态）
- ✅ 鼠标悬停时显示"系统参数不可编辑"提示

**注意：**
如果通过其他方式触发编辑操作，应弹出提示："系统参数不能编辑！"

---

### 测试3：尝试删除系统参数

**操作步骤：**
1. 在类型设置页面
2. 找到任意带有"系统参数"徽章的选项
3. 尝试点击"删除"按钮

**预期结果：**
- ✅ 按钮无法点击（禁用状态）
- ✅ 鼠标悬停时显示"系统参数不可删除"提示

**注意：**
如果通过其他方式触发删除操作，应弹出提示："系统参数不能删除！"

---

### 测试4：添加自定义参数

**操作步骤：**
1. 在类型设置页面
2. 点击任意类型设置块右上角的"+ 新增"按钮
3. 输入新的选项名称，例如："测试参数001"
4. 点击"添加"按钮

**预期结果：**
- ✅ 新参数成功添加到列表底部
- ✅ 新参数**没有**"系统参数"徽章
- ✅ 新参数的"编辑"和"删除"按钮正常显示（蓝色/红色）
- ✅ 页面右上角"保存所有设置"按钮变为蓝色（可点击状态）

---

### 测试5：编辑自定义参数

**操作步骤：**
1. 找到刚才添加的"测试参数001"
2. 点击"编辑"按钮
3. 修改名称为"测试参数002"
4. 点击"保存"按钮

**预期结果：**
- ✅ 编辑模态框正常打开
- ✅ 修改成功，列表中显示新名称
- ✅ "保存所有设置"按钮变为蓝色
- ✅ 仍然没有"系统参数"徽章

---

### 测试6：删除自定义参数

**操作步骤：**
1. 找到"测试参数002"
2. 点击"删除"按钮
3. 在弹出的确认对话框中点击"确定"

**预期结果：**
- ✅ 删除确认对话框正常显示
- ✅ 参数从列表中移除
- ✅ "保存所有设置"按钮变为蓝色

---

### 测试7：启用/禁用系统参数

**操作步骤：**
1. 找到任意系统参数
2. 点击左侧的启用/禁用开关

**预期结果：**
- ✅ 开关可以正常切换
- ✅ 禁用后显示"(已禁用)"标签
- ✅ 背景色变为灰色
- ✅ "保存所有设置"按钮变为蓝色
- ✅ 仍然不能编辑和删除

**说明：**
系统参数可以禁用但不能删除。禁用后在新建记录时不会显示该选项。

---

### 测试8：保存所有设置

**操作步骤：**
1. 确保已进行过某些修改（新增、编辑、删除、启用/禁用）
2. 点击右上角的"保存所有设置"按钮

**预期结果：**
- ✅ 弹出提示："所有设置已保存成功！"
- ✅ "保存所有设置"按钮变为灰色（禁用状态）
- ✅ 按钮文字变为"暂无更改"

---

### 测试9：数据持久性验证

**操作步骤：**
1. 完成测试8后
2. 刷新页面（F5）
3. 重新打开系统设置 → 类型设置

**预期结果：**
- ✅ 所有修改都已保存
- ✅ 系统参数仍然显示"系统参数"徽章
- ✅ 自定义参数仍然可以编辑和删除
- ✅ 启用/禁用状态正确保留

## 数据库验证

### 检查数据结构

**查询类型设置：**
```javascript
// 在浏览器控制台执行
const db = window.cloudbase.database();
db.collection('type_settings').get().then(res => {
  console.log('类型设置数据:', res.data);
});
```

**预期数据格式：**
```json
{
  "_id": "xxx",
  "type": "task",
  "values": [
    {
      "value": "日常工作",
      "enabled": true,
      "isSystem": true
    },
    {
      "value": "商机跟进",
      "enabled": true,
      "isSystem": true
    },
    {
      "value": "项目任务",
      "enabled": true,
      "isSystem": true
    },
    {
      "value": "测试参数002",
      "enabled": true,
      "isSystem": false
    }
  ],
  "createdAt": "...",
  "updatedAt": "..."
}
```

**验证要点：**
- ✅ 每个 `values` 项都有 `value`、`enabled`、`isSystem` 属性
- ✅ 系统默认值的 `isSystem` 为 `true`
- ✅ 自定义参数的 `isSystem` 为 `false`
