## 🔧 技术实现

### 页面加载逻辑（onLoad）

```javascript
1. 清除缓存的用户信息（确保每次都是新授权）
2. 初始化 userInfo = null（触发显示授权页面）
3. 获取并验证邀请码
4. 后台静默获取 OpenID
```

### 条件渲染

- `wx:if="{{!userInfo}}"` → 显示授权页面
- `wx:if="{{userInfo}}"` → 显示注册表单页面

### 数据流

```
扫码 → onLoad() 
    → userInfo = null 
    → 显示授权页面 
    → 用户点击"确认授权" 
    → 调用 wx.getUserProfile() 
    → userInfo 有值 
    → 显示注册表单
```

## 🐛 排查问题

### 如果仍然直接显示注册表单

**可能原因**：
1. 微信开发者工具缓存未清除
2. 小程序代码未重新编译
3. 之前有缓存的 userInfo

**解决方案**：
1. 关闭微信开发者工具
2. 删除小程序缓存目录
3. 重新打开项目
4. 点击"清缓存"
5. 重新编译
6. 测试
