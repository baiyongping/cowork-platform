## 📋 任务概述

**需求：** 在系统设置的类型设置中，为所有选项添加"是否系统参数"属性，系统参数不可编辑和删除。

**完成时间：** 2025-12-12

**状态：** ✅ 已完成

---

## ✅ 实现功能

### 1. 数据模型扩展
- 在 `TypeItem` 接口中新增 `isSystem?: boolean` 属性
- 支持标记系统参数和自定义参数
- 向后兼容旧数据格式

### 2. 数据自动升级
- 自动识别旧格式数据（字符串数组）
- 转换为新格式（对象数组）
- 自动标记系统默认值为系统参数
- 自动标记自定义值为非系统参数

### 3. UI视觉标识
- 系统参数显示蓝色"系统参数"徽章
- 编辑按钮对系统参数显示为灰色禁用状态
- 删除按钮对系统参数显示为灰色禁用状态
- 鼠标悬停提示清晰明确

### 4. 操作保护机制
- **UI层保护**：禁用系统参数的编辑和删除按钮
- **逻辑层保护**：在函数中检查 `isSystem` 属性
- **双重保护**：确保系统参数不被误操作

### 5. 功能完整性
- ✅ 新增参数默认为非系统参数（`isSystem: false`）
- ✅ 系统参数可以启用/禁用
- ✅ 自定义参数可以正常编辑和删除
- ✅ 所有9种类型设置都支持系统参数功能

## 🔧 技术实现细节

### 数据结构

**旧格式（已废弃但仍支持）：**
```typescript
{
  type: 'task',
  values: ['日常工作', '商机跟进', '项目任务']
}
```

**新格式：**
```typescript
{
  type: 'task',
  values: [
    { value: '日常工作', enabled: true, isSystem: true },
    { value: '商机跟进', enabled: true, isSystem: true },
    { value: '项目任务', enabled: true, isSystem: true },
    { value: '自定义任务', enabled: true, isSystem: false }
  ]
}
```

### 关键代码修改

#### 1. TypeItem 接口扩展
```typescript
interface TypeItem {
  value: string;
  enabled: boolean;
  isSystem?: boolean; // 新增属性
}
```

#### 2. 数据加载逻辑
```typescript
// 支持新旧格式，自动标记系统参数
if (typeof values[0] === 'string') {
  // 旧格式转换
  typeMap[item.type] = item.values.map((v: string) => ({ 
    value: v, 
    enabled: true,
    isSystem: defaults[item.type]?.includes(v) || false
  }));
} else {
  // 新格式，确保有isSystem属性
  typeMap[item.type] = item.values.map((v: any) => ({
    value: v.value,
    enabled: v.enabled !== undefined ? v.enabled : true,
    isSystem: v.isSystem !== undefined ? v.isSystem : (defaults[item.type]?.includes(v.value) || false)
  }));
}
```

#### 3. UI渲染
```tsx
{item.isSystem && (
  <span className="inline-flex items-center px-2 py-0.5 text-xs font-medium bg-blue-100 text-blue-800 rounded-full">
    系统参数
  </span>
)}

<button 
  disabled={item.isSystem}
  className={`text-sm ${
    item.isSystem 
      ? 'text-gray-400 cursor-not-allowed' 
      : 'text-blue-600 hover:text-blue-700'
  }`}
  title={item.isSystem ? '系统参数不可编辑' : '编辑'}
>
  编辑
</button>
```

## 📖 使用指南

### 管理员操作

#### 1. 查看系统参数
1. 登录系统
2. 进入系统设置 → 类型设置
3. 查看带有"系统参数"徽章的选项

#### 2. 添加自定义参数
1. 点击类型设置块的"+ 新增"按钮
2. 输入参数名称
3. 点击"添加"
4. 点击右上角"保存所有设置"

#### 3. 编辑自定义参数
1. 找到自定义参数（无"系统参数"徽章）
2. 点击"编辑"按钮
3. 修改名称
4. 点击"保存"
5. 点击右上角"保存所有设置"

#### 4. 删除自定义参数
1. 确认参数未被引用
2. 点击"删除"按钮
3. 确认删除
4. 点击右上角"保存所有设置"

#### 5. 启用/禁用参数
- 系统参数和自定义参数都可以启用/禁用
- 点击左侧的开关即可切换
- 禁用的参数在新建时不显示

## 📌 注意事项

### 开发者注意
1. **不要硬编码系统参数列表**
   - 系统参数通过 `isSystem` 属性识别
   - 不依赖特定的参数名称

2. **保持数据兼容性**
   - 始终支持旧格式数据
   - 自动升级而不是强制升级

3. **保护机制要完善**
   - UI层和逻辑层都要有保护
   - 不能只依赖UI禁用

4. **提示信息要清晰**
   - 告诉用户为什么不能操作
   - 提供解决方案或替代方案

### 用户注意
1. **系统参数谨慎禁用**
   - 禁用可能影响业务流程
   - 建议保持默认启用状态

2. **自定义参数命名规范**
   - 避免与系统参数重名
   - 使用清晰易懂的名称

3. **删除前检查引用**
   - 系统会自动检查
   - 但建议先手动确认
