# 系统参数功能 - 快速参考卡片

## 🎯 一句话说明
在类型设置中标记核心配置为"系统参数"，防止被误编辑或删除。

---

## 🔍 如何识别系统参数？

### 视觉标识
- 🏷️ 显示蓝色"系统参数"徽章
- ⚫ "编辑"按钮为灰色（禁用）
- ⚫ "删除"按钮为灰色（禁用）

### 鼠标提示
- 悬停在编辑按钮：显示"系统参数不可编辑"
- 悬停在删除按钮：显示"系统参数不可删除"

## ✅ 能做什么？

### 系统参数
- ✅ 启用/禁用
- ❌ 编辑名称
- ❌ 删除

### 自定义参数
- ✅ 启用/禁用
- ✅ 编辑名称
- ✅ 删除（无引用时）

## 🚀 常用操作

### 1️⃣ 添加自定义参数
```
系统设置 → 类型设置 → 点击"+ 新增"
→ 输入名称 → 点击"添加"
→ 点击"保存所有设置"
```

### 2️⃣ 编辑自定义参数
```
找到自定义参数（无"系统参数"徽章）
→ 点击"编辑" → 修改名称
→ 点击"保存" → 点击"保存所有设置"
```

### 3️⃣ 删除自定义参数
```
找到自定义参数 → 点击"删除"
→ 确认删除 → 点击"保存所有设置"
```

### 4️⃣ 启用/禁用参数
```
点击参数左侧的开关
→ 点击"保存所有设置"
```

---

## ⚠️ 重要提示

1. **系统参数不能删除**
   - 保护系统核心功能
   - 防止数据引用错误

2. **禁用 ≠ 删除**
   - 禁用后新建时不显示
   - 已有记录仍然有效

3. **删除前检查引用**
   - 有记录使用时无法删除
   - 需先修改相关记录

4. **记得保存**
   - 修改后点击"保存所有设置"
   - 否则修改不会生效

## 🆘 常见问题

### Q: 为什么有些参数不能编辑？
**A:** 这些是系统参数，保护核心功能。

### Q: 可以禁用系统参数吗？
**A:** 可以！禁用后新建时不显示，但不影响已有记录。

### Q: 如何删除不用的参数？
**A:** 
1. 确认无记录引用
2. 点击"删除"
3. 点击"保存所有设置"

### Q: 修改后不生效？
**A:** 记得点击右上角"保存所有设置"按钮！
