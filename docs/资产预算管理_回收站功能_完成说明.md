# 资产预算管理 - 回收站功能完成说明

## ✅ 功能概述

为资产预算管理页面增加了**回收站功能**，用户可以：
1. 将不需要的预算项放入回收站（软删除）
2. 查看回收站中的所有预算项
3. 从回收站恢复预算项
4. 永久删除回收站中的预算项

---

## 🎯 新增功能

### 1️⃣ **列表页顶部按钮**
- **新增"回收站"按钮** - 灰色按钮，位于"新建预算"按钮旁边
- 点击后弹出回收站弹窗

### 2️⃣ **回收站弹窗**
- **全屏居中显示** - 黑色半透明背景遮罩
- **弹窗尺寸** - 最大宽度 4xl，最大高度 90vh
- **顶部标题栏** - 显示"回收站"和项目数量
- **内容区域** - 显示已删除的预算项列表

### 3️⃣ **回收站操作**
每个回收站项目显示：
- 预算名称
- 类别、总金额、部门
- 删除时间（红色显示）
- **恢复按钮**（绿色）- 将预算恢复到正常列表
- **永久删除按钮**（红色）- 彻底删除，不可恢复

### 4️⃣ **软删除机制**
- 点击详情页的"放入回收站"按钮时，不会真删除数据
- 只是将 `deleted` 字段设置为 `true`
- 记录删除时间（`deletedAt`）和删除人（`deletedBy`）
- 正常列表查询时会过滤掉已删除的项目

## 🚀 使用流程

### 删除预算
1. 打开任意预算详情页
2. 点击右上角"放入回收站"按钮
3. 弹出确认对话框
4. 确认后，预算被移到回收站

### 查看回收站
1. 点击列表页顶部"回收站"按钮
2. 查看所有已删除的预算项
3. 每个项目显示删除时间

### 恢复预算
1. 在回收站中找到要恢复的预算
2. 点击"恢复"按钮
3. 预算恢复到正常列表

### 永久删除
1. 在回收站中找到要删除的预算
2. 点击"永久删除"按钮
3. 弹出二次确认对话框
4. 确认后，数据被彻底删除，**不可恢复**

---

## ⚠️ 注意事项

1. **软删除机制** - "放入回收站"不会真删除数据，只是隐藏
2. **永久删除** - "永久删除"按钮会真删除，操作不可撤销
3. **二次确认** - 永久删除时会弹出确认对话框
4. **自动加载** - 打开回收站时会自动加载当前年份的已删除项目
5. **年份过滤** - 回收站只显示当前选择年份的已删除预算
