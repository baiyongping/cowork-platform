## 1. 模块概述

### 1.1 模块定位

预算管理模块是际华协同办公平台的**财务资源管控核心**，与现有的目标管理模块形成"战略-财务"双轮驱动体系。通过年度预算编制、执行监控、动态预测，实现企业财务资源的精细化管理。

### 1.2 核心价值

| 价值维度 | 具体价值 |
|---------|---------|
| **战略支撑** | 为战略目标提供财务资源保障，确保资金投向与战略方向一致 |
| **风险预警** | 实时监控预算执行偏差，提前预警资金风险 |
| **决策支持** | 基于现金流预测，支持管理层做出更合理的投资和资源配置决策 |
| **成本优化** | 通过预算对比分析，识别成本控制改进空间 |

### 1.3 与目标管理的协同关系

```
战略目标管理层 (Goal Management)
    ↓ 资源保障
预算管理层 (Budget Management)
    ↓ 财务支撑
任务/商机/项目执行层
```

**协同机制**:
- 年度战略目标 → 驱动 → 年度预算编制
- 季度措施 → 关联 → 季度资产预算
- 项目立项 → 触发 → 资产预算申请
- 人员变动 → 影响 → 人力费用预算调整

## 3. 五大子功能详细设计

### 3.1 预算执行 (Execution)

**功能定位**: 预算管理的"总控制台"，类似于Dashboard，实时监控各预算科目的执行情况。

#### 3.1.1 核心指标卡片

**4个关键指标**（顶部并列显示）:

```
┌─────────────────────┐ ┌─────────────────────┐ ┌─────────────────────┐ ┌─────────────────────┐
│   年度预算总额       │ │   已执行金额         │ │   执行进度           │ │   预算余额           │
│   ¥ 10,000万        │ │   ¥ 6,500万         │ │   65%               │ │   ¥ 3,500万         │
│   vs去年 ↑15%       │ │   vs上月 ↑8%        │ │   vs计划 ↓3%        │ │   vs目标 -5%        │
└─────────────────────┘ └─────────────────────┘ └─────────────────────┘ └─────────────────────┘
```

#### 3.1.2 预算科目执行对比表

**表格字段**:
| 字段 | 说明 | 数据来源 |
|------|------|---------|
| 预算科目 | 如"人力成本"、"营销费用"、"研发投入" | 手动维护 |
| 年度预算 | 该科目的年度总预算 | 年度预算模块 |
| 已执行金额 | 截至当前实际支出 | 财务系统对接/手动录入 |
| 执行率 | 已执行 / 年度预算 * 100% | 自动计算 |
| 时间进度 | 当前日期 / 全年天数 * 100% | 自动计算 |
| 执行偏差 | 执行率 - 时间进度 | 自动计算 |
| 预警状态 | 根据偏差自动判断 | 红色(>10%)、黄色(5-10%)、绿色(<5%) |
| 操作 | 查看明细、申请调整 | - |

**示例数据**:
```

营销费用      1500万       1100万      73.3%     58.3%     +15.0%      🔴
研发投入      2000万       980万       49.0%     58.3%      -9.3%      🟡
管理费用      1200万       680万       56.7%     58.3%      -1.6%      🟢
```

### 3.4 现金流预测 (Cash Flow Forecast)

**功能定位**: 基于销售目标、应收账款、应付账款等数据，预测未来现金流状况。

#### 3.4.1 现金流预测模型

**数据结构**:
```typescript
interface CashFlowForecast {
  _id?: string;
  year: number;
  quarter: 'Q1' | 'Q2' | 'Q3' | 'Q4';
  month?: number;          // 月度预测(可选)
  
  // 现金流入
  salesRevenue: number;    // 预计销售收入
  accountsReceivable: number; // 应收账款回收
  otherInflow: number;     // 其他流入
  totalInflow: number;     // 总流入
  
  // 现金流出
  laborCost: number;       // 人力成本支出
  operatingExpense: number; // 运营费用
  assetPurchase: number;   // 资产采购
  accountsPayable: number; // 应付账款支付
  otherOutflow: number;    // 其他流出
  totalOutflow: number;    // 总流出
  
  // 净现金流
  netCashFlow: number;     // 净现金流 = 总流入 - 总流出
  cashBalance: number;     // 期末现金余额
  
  // 预警
  isShortage: boolean;     // 是否资金短缺
  shortageAmount?: number; // 短缺金额
  
  createdBy: string;
  createdAt: Date;
  updatedAt: Date;
}
```

#### 3.4.3 资金缺口预警

**预警规则**:
- 🔴 红色预警: 期末现金余额 < 0（资金链断裂风险）
- 🟡 黄色预警: 期末现金余额 < 500万（资金紧张）
- 🟢 绿色: 期末现金余额 >= 500万（资金充足）

**预警触发动作**:
- 自动发送消息给财务负责人和总经理
- 在Dashboard首页显示预警通知
- 建议的应对措施（如加快应收账款回收、延缓非紧急支出）

**折线图**（展示12个月的现金流趋势）:
- X轴: 月份
- Y轴: 金额（万元）
- 3条曲线: 现金流入、现金流出、净现金流

### 3.6 预算参数 (Budget Parameters)

**功能定位**: 预算管理的"基础设施"层，管理损益项配置，确保损益表结构完整且灵活适应不同年度的预算侧重点。

#### 3.6.1 核心问题与解决方案

**问题背景**:
- 不同年度企业战略重点不同（如某年重点投资研发，某年重点市场拓展）
- 损益表项目需要根据年度侧重点动态调整
- 需要确保财务报表的完整性和一致性

**解决方案**:
- 维护一套完整的损益项字典库
- 支持按年度激活/停用损益项
- 自动校验预算编制的完整性

#### 3.6.2 损益项配置管理

**数据结构**:
```typescript
interface BudgetParameter {
  _id?: string;
  category: '收入类' | '成本费用类' | '资产投资类' | '其他';
  itemName: string;           // 损益项名称
  itemCode: string;           // 损益项编码(如 "5001-人力成本")
  parentItem?: string;        // 父级损益项(支持二级分类)
  level: 1 | 2;              // 层级(1=一级科目, 2=二级科目)
  isStandard: boolean;        // 是否标准科目(标准科目不可删除)
  description?: string;       // 说明
  calculationFormula?: string; // 计算公式(可选,如"工资+奖金+社保")
  relatedModule?: string;     // 关联模块(如"人力费用预算")
  
  // 年度激活状态
  activeYears: number[];      // 激活年份数组 [2024, 2025, 2026]
  
  // 显示顺序
  displayOrder: number;       // 显示顺序(用于损益表排序)
  
  createdBy: string;
  createdAt: Date;
  updatedAt: Date;
}
```

### 3.7 产品销售预测 (Product Sales Forecast)

**功能定位**: 为现金流预测和收入预算提供数据支撑，通过多维度预测（产品线、客户、区域）提升销售收入预测准确性。

#### 3.7.1 核心价值

**与现有模块的协同**:
```
产品销售预测
    ↓ 提供收入预测数据
现金流预测 (salesRevenue字段)
    ↓ 提供现金流预测
资金计划和风险管理

产品销售预测
    ↓ 提供目标数据
年度预算 (产品销售收入科目)
    ↓ 提供收入预算依据
预算编制和执行监控
```

## 4. 数据模型

### 4.1 数据库集合设计

**核心集合**（CloudBase NoSQL）:

| 集合名称 | 用途 | 关键字段 |
|---------|------|---------|
| `annual_budgets` | 年度预算 | year, category, budgetAmount |
| `budget_execution` | 预算执行记录 | year, category, executedAmount, executionRate |
| `asset_budgets` | 资产预算 | year, quarter, assetType, totalAmount, status |
| `cash_flow_forecasts` | 现金流预测 | year, quarter, netCashFlow, cashBalance |
| `labor_cost_budgets` | 人力费用预算 | year, month, department, totalCost |
| `budget_adjustments` | 预算调整申请 | year, adjustmentType, amount, status |
| `budget_parameters` | 预算参数(损益项) | itemName, itemCode, category, activeYears |
| `year_budget_focus` | 年度预算侧重点 | year, focusArea, activeParameters |
| `budget_mapping` | 预算科目映射 | budgetParameterId, sourceModule, mappingRule |
| `product_sales_forecasts` | 产品销售预测 | year, productLine, forecastRevenue, actualRevenue |

### 4.2 关联关系

```
annual_budgets (年度预算)
    ├── 1:N → budget_execution (预算执行)
    └── 1:N → budget_adjustments (预算调整)

asset_budgets (资产预算)
    ├── N:1 → projects (项目)
    └── N:1 → annual_strategies (年度战略目标)

cash_flow_forecasts (现金流预测)
    ├── 基于 → sales_goals (销售目标)
    └── 基于 → opportunities (商机)

labor_cost_budgets (人力费用预算)
    └── 关联 → departments (部门)

budget_parameters (预算参数)
    ├── 1:N → year_budget_focus (年度侧重点)
    └── 1:N → budget_mapping (科目映射)

product_sales_forecasts (产品销售预测)
    ├── N:N → opportunities (商机)
    ├── 影响 → cash_flow_forecasts (现金流预测)
    └── 支撑 → annual_budgets (年度预算)
```

### 4.3 计算字段规则

**预算执行率**:
```javascript
executionRate = (executedAmount / budgetAmount) * 100
```

**执行偏差**:
```javascript
timeProgress = (当前日期 - 年初日期) / (年末日期 - 年初日期) * 100
executionDeviation = executionRate - timeProgress
```

**净现金流**:
```javascript
netCashFlow = totalInflow - totalOutflow
```

**期末现金余额**:
```javascript
cashBalance = 期初余额 + 当期净现金流
```

**产品销售预测准确率**:
```javascript
accuracy = (1 - |actualRevenue - forecastRevenue| / actualRevenue) * 100
```

**损益表完整性得分**:
```javascript
completenessScore = (激活的标准科目数 / 标准科目总数) * 100
```

## 7. 业务流程

### 7.1 年度预算编制流程

```
每年11-12月
    ↓
财务部发起年度预算编制
    ↓
各部门提交预算草案
    ↓
财务部汇总审核
    ↓
管理层审批
    ↓
预算确定并下达
    ↓
次年1月开始执行
```

### 7.2 预算执行监控流程

```
每月5日前
    ↓
财务部录入上月实际执行数据
    ↓
系统自动计算执行率和偏差
    ↓
触发预警（如有偏差>10%）
    ↓
相关责任人收到消息
    ↓
提交分析报告或调整申请
```

### 7.3 资产预算审批流程

```
申请人提交资产预算申请
    ↓
部门经理初审（是否符合部门规划）
    ↓
财务部审核（是否在总预算内）
    ↓
管理层审批（金额>50万需董事会）
    ↓
批准后进入采购流程
    ↓
采购完成后更新实际金额
```

### 7.4 现金流预测更新流程

```
每月25日
    ↓
财务部更新下月预测
    ↓
基于销售目标、应收应付数据计算
    ↓
系统自动生成现金流预测报告
    ↓
检测资金缺口风险
    ↓
触发预警（如有）
    ↓
管理层审阅并采取措施
```

### 7.5 年度损益项配置流程

```
每年12月初 (预算编制前)
    ↓
财务部分析本年度损益表使用情况
    ↓
基于下年度战略重点,确定侧重领域
    ↓
配置下年度激活的损益项
    ↓
运行完整性校验
    ↓
确认无误后保存配置
    ↓
相关人员开始编制年度预算
```

### 7.6 产品销售预测更新流程

```
每季度第一个月
    ↓
销售部门提交本季度销售预测
    ↓
基于: 在手订单 + 高概率商机 + 历史数据
    ↓
销售总监审核
    ↓
财务部引用数据
    ↓
用于现金流预测和年度预算
    ↓
季度结束后对比实际数据
    ↓
分析预测偏差,改进预测模型
```
