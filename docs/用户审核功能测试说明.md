# 用户审核管理功能 - 测试说明

## 功能概述

在系统设置中新增"用户审核"Tab页,用于管理员审核新注册用户。

## 功能位置

**路径**: 系统设置 > 用户审核

访问方式:
1. 使用admin账号登录系统
2. 点击顶部导航栏的"系统设置"
3. 点击"用户审核"Tab(带有待审核数量徽章)

## 核心功能

### 1. 待审核数量提示
- Tab上显示待审核用户数量的橙色徽章
- 实时更新待审核数量

### 2. 筛选和搜索
**状态筛选** (单行显示):
- 全部: 显示所有用户
- 待审核: 只显示approvalStatus='pending'的用户
- 已通过: 只显示approvalStatus='approved'的用户
- 已拒绝: 只显示approvalStatus='rejected'的用户

**关键词搜索**:
- 支持搜索用户名、姓名、手机号
- 实时过滤结果

### 3. 用户列表
显示字段:
- **用户信息**: 头像、姓名、用户名、管理员标识
- **角色/部门**: 用户角色和所属部门
- **联系电话**: 手机号(不显示邮箱)
- **注册时间**: 用户注册日期、最后登录时间
- **审核状态**: 待审核/已通过/已拒绝徽章
- **操作**: 审核按钮

### 4. 审核操作

#### 通过审核
1. 点击"通过"按钮
2. 浏览器弹窗确认
3. 系统执行:
   - 更新数据库: `approvalStatus='approved'`
   - 记录审核人: `approvedBy`
   - 记录审核时间: `approvedAt`
   - 发送短信通知用户(审核通过)
4. 刷新用户列表

#### 拒绝审核
1. 点击"拒绝"按钮
2. 弹出原因填写对话框
3. 必须填写拒绝原因
4. 点击"确认拒绝"
5. 系统执行:
   - 更新数据库: `approvalStatus='rejected'`
   - 保存拒绝原因: `rejectReason`
   - 记录审核人和时间
   - 发送短信通知用户(拒绝原因)
6. 刷新用户列表

#### 重新审核
- 已拒绝的用户可以"重新审核"
- 相当于再次执行"通过审核"流程

## 数据库字段

相关字段 (users集合):
```javascript
{
  approvalStatus: 'pending' | 'approved' | 'rejected',
  approvedBy: '审核人用户ID',
  approvedAt: '审核时间',
  rejectReason: '拒绝原因'
}
```

## 短信通知

### 审核通过短信
内容: "尊敬的{姓名}，您的账号已审核通过，现在可以正常使用系统。【际华定制】"

### 审核拒绝短信
内容: "尊敬的{姓名}，抱歉您的账号审核未通过，原因：{拒绝原因}。如有疑问请联系管理员。【际华定制】"

## UI设计特点

1. **筛选区简洁**: 搜索框和状态筛选在同一行
2. **状态徽章**: 圆角矩形,带图标和颜色区分
3. **操作按钮**: 绿色"通过"、红色"拒绝"、蓝色"重新审核"
4. **头像渐变**: 多色渐变头像,根据用户ID自动分配
5. **表格分页**: 底部显示分页控件(当前版本暂不分页)

## 已知限制

1. **分页功能**: 当前版本最多显示100条记录,未实现真正的分页
2. **批量操作**: 不支持批量审核
3. **审核历史**: 不记录审核操作日志
4. **邮件通知**: 只发送短信,不发送邮件
