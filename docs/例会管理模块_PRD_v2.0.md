## 1. 产品概述

### 1.1 产品背景
例会管理是际华协同办公平台的重要功能模块，旨在通过系统化的会议管理、会议纪要记录和问题跟踪，提高团队协作效率，确保关键决策和问题得到有效跟进落实。

### 1.2 目标用户
- 企业管理层（主持会议、查看会议记录）
- 各部门负责人（参与会议、记录纪要、跟进问题）
- 普通员工（查看相关会议信息、处理分配的问题）

### 1.3 核心价值
- **系统化管理**: 统一管理各类会议，避免会议信息散落
- **可追溯性**: 完整记录会议决议和待办事项，便于后续查阅
- **问题闭环**: 自动关联问题管理，确保会议决议得到执行
- **关联业务**: 会议可关联目标、任务、商机、项目，建立业务全景视图

## 2. 功能架构

### 2.1 模块组成
```
例会管理
├── 会议列表 (Meeting List)
│   ├── 会议创建
│   ├── 会议编辑
│   ├── 会议删除（软删除）
│   └── 会议筛选
├── 会议纪要 (Meeting Minutes)
│   ├── 纪要编辑
│   ├── 纪要查看
│   └── 纪要导出
└── 问题列表 (Issue List)
    ├── 会议问题查看
    ├── 问题状态更新
    └── 问题关联跳转
```

### 2.2 与其他模块的关联
- **目标管理**: 会议可关联季度目标，跟踪目标达成情况
- **任务管理**: 会议可关联团队任务，讨论任务进展和问题
- **商机管理**: 会议可关联商机，讨论商机跟进和成交策略
- **项目管理**: 会议可关联项目，讨论项目进展和风险
- **问题管理**: 会议中提出的问题自动关联到问题管理模块

## 3. 详细功能设计

## 3.1 会议列表

### 3.1.1 会议数据模型

**数据库集合**: `meetings`

**字段定义**:
```typescript
interface Meeting {
  _id: string;                    // 会议ID
  title: string;                   // 会议标题（必填）
  type: MeetingType;               // 会议类型
  status: MeetingStatus;           // 会议状态
  startTime: Date;                 // 开始时间（必填）
  endTime: Date;                   // 结束时间（必填）
  location?: string;               // 会议地点（可选）
  isOnline: boolean;               // 是否线上会议
  meetingLink?: string;            // 线上会议链接
  host: string;                    // 主持人ID（必填）
  hostName?: string;               // 主持人姓名（关联查询）
  participants: string[];          // 参会人员ID数组
  participantNames?: string[];     // 参会人员姓名数组（关联查询）
  recorder?: string;               // 记录人ID（可选）
  recorderName?: string;           // 记录人姓名（关联查询）
  agenda?: string;                 // 会议议程
  minutes?: string;                // 会议纪要
  decisions?: MeetingDecision[];   // 会议决议列表
  actionItems?: ActionItem[];      // 待办事项列表
  attachments?: string[];          // 附件URL数组
  
  // 关联业务字段
  relatedGoals?: string[];         // 关联季度目标ID数组
  relatedGoalNames?: string[];     // 关联目标名称数组（关联查询）
  relatedTasks?: string[];         // 关联团队任务ID数组
  relatedTaskNames?: string[];     // 关联任务名称数组（关联查询）
  relatedOpportunities?: string[]; // 关联商机ID数组
  relatedOpportunityNames?: string[]; // 关联商机名称数组（关联查询）
  relatedProjects?: string[];      // 关联项目ID数组
  relatedProjectNames?: string[];  // 关联项目名称数组（关联查询）
  
  // 问题关联
  relatedIssues?: string[];        // 关联问题ID数组（从问题管理自动同步）
  relatedIssueCount?: number;      // 关联问题数量
  
  // 元数据
  isDeleted?: boolean;             // 是否已删除（软删除）
  deletedAt?: Date;                // 删除时间
  createdBy: string;               // 创建人ID
  createdAt: Date;                 // 创建时间
  updatedAt: Date;                 // 更新时间
}

// 会议类型
type MeetingType = 
  | '周例会'
  | '月度例会'
  | '季度例会'
  | '专题会议'
  | '临时会议'
  | '项目评审会'
  | '目标复盘会';

// 会议状态
type MeetingStatus = 
  | '待召开'   // 会议创建，还未开始
  | '进行中'   // 会议正在进行
  | '已结束'   // 会议已结束，待整理纪要
  | '已完成'   // 纪要已整理完成
  | '已取消';  // 会议取消

// 会议决议
interface MeetingDecision {
  id: string;                 // 决议ID
  content: string;            // 决议内容
  responsible?: string;       // 责任人ID
  responsibleName?: string;   // 责任人姓名
  deadline?: Date;            // 完成期限
  status: 'pending' | 'completed'; // 状态
}

// 待办事项
interface ActionItem {
  id: string;                 // 事项ID
  content: string;            // 事项内容
  assignee: string;           // 负责人ID
  assigneeName?: string;      // 负责人姓名
  deadline: Date;             // 截止日期
  priority: 'high' | 'medium' | 'low'; // 优先级
  status: 'pending' | 'inProgress' | 'completed'; // 状态
  relatedIssueId?: string;    // 关联的问题ID（如果转化为问题）
}
```

### 3.1.2 功能列表

#### (1) 会议列表展示
**功能描述**: 展示所有会议记录，支持筛选和搜索

**展示信息**:
- 会议标题
- 会议类型标签
- 会议状态标签
- 开始时间
- 主持人
- 参会人员数量
- 关联问题数量
- 操作按钮（查看、编辑、删除）

**筛选条件**:
- 会议类型（全部/周例会/月度例会/...）
- 会议状态（全部/待召开/进行中/已结束/...）
- 时间范围（本周/本月/本季度/自定义）
- 主持人筛选
- 关键词搜索（会议标题、议程）

**排序规则**:
- 默认按开始时间倒序
- 支持按状态、参会人数排序

#### (2) 创建会议
**功能描述**: 创建新的会议记录

**表单字段**:
```typescript
// 基础信息（必填）
- 会议标题 (input, required, max: 100)
- 会议类型 (select, required)
- 开始时间 (datetime-picker, required)
- 结束时间 (datetime-picker, required)
- 主持人 (user-select, required)
- 参会人员 (multi-user-select, required, min: 1)

// 会议方式
- 是否线上会议 (checkbox)
- 会议地点 (input, optional, max: 100) // 线下时必填
- 会议链接 (input, optional, max: 200) // 线上时必填

// 会议内容
- 会议议程 (textarea, optional, max: 2000)
- 记录人 (user-select, optional)

// 业务关联（可选，支持多选）
- 关联季度目标 (multi-select)
  * 下拉列表展示: {目标名称} - {目标负责人}
  * 搜索支持: 按目标名称、负责人搜索
  * 数据来源: 从 goals 集合查询当前季度的目标
  
- 关联团队任务 (multi-select)
  * 下拉列表展示: {任务名称} - {任务负责人} - {状态}
  * 搜索支持: 按任务名称、负责人搜索
  * 数据来源: 从 tasks 集合查询团队级任务
  
- 关联商机 (multi-select)
  * 下拉列表展示: {商机名称} - {客户} - {预计金额} - {阶段}
  * 搜索支持: 按商机名称、客户名称搜索
  * 数据来源: 从 opportunities 集合查询进行中的商机
  
- 关联项目 (multi-select)
  * 下拉列表展示: {项目名称} - {项目编号} - {状态}
  * 搜索支持: 按项目名称、项目编号搜索
  * 数据来源: 从 projects 集合查询进行中的项目
```

**表单验证**:
- 会议标题: 不能为空，长度1-100字符
- 开始时间: 不能为空，不能早于当前时间（创建时）
- 结束时间: 不能为空，必须晚于开始时间
- 主持人: 必须选择
- 参会人员: 至少选择1人
- 会议地点/链接: 根据会议方式，至少填写一个

**业务规则**:
- 会议创建后，状态默认为"待召开"
- 创建人自动加入参会人员（如果未选择）
- 主持人自动加入参会人员（如果未选择）

#### (3) 编辑会议
**功能描述**: 修改会议信息

**权限控制**:
- 创建人可以编辑
- 主持人可以编辑
- 管理员可以编辑

**可编辑字段**:
- 状态为"待召开"时: 所有字段可编辑
- 状态为"进行中"时: 
  * 不可修改: 开始时间、主持人
  * 可修改: 其他字段
- 状态为"已结束"/"已完成"时:
  * 不可修改: 基础信息（标题、时间、人员）
  * 可修改: 会议纪要、决议、待办事项

#### (4) 删除会议
**功能描述**: 软删除会议记录（放入回收站）

**权限控制**:
- 仅创建人和管理员可删除
- 状态为"进行中"的会议不可删除

**删除逻辑**:
- 软删除: 设置 `isDeleted = true`, `deletedAt = now()`
- 删除后会议不在列表展示
- 可从回收站恢复或永久删除

#### (5) 会议详情查看
**功能描述**: 查看会议完整信息

**展示内容**:
```
- 基础信息卡片
  * 会议标题
  * 会议类型/状态
  * 时间: 开始时间 ~ 结束时间
  * 地点/链接
  * 主持人
  * 参会人员（头像+姓名）
  * 记录人

- 关联业务卡片（Tab切换）
  * 关联目标: 列表展示，支持跳转
  * 关联任务: 列表展示，支持跳转
  * 关联商机: 列表展示，支持跳转
  * 关联项目: 列表展示，支持跳转

- 会议内容
  * 会议议程
  * 会议纪要（富文本）
  * 会议决议列表
  * 待办事项列表

- 关联问题
  * 显示问题数量
  * 问题列表（问题名称、状态、负责人）
  * 支持跳转到问题管理

- 附件列表
  * 支持上传/下载
```

### 3.1.3 会议状态管理

**状态流转**:
```
待召开 → [开始会议] → 进行中 → [结束会议] → 已结束 → [完成纪要] → 已完成
   ↓                                                          ↑
 [取消]                                                      [编辑]
   ↓                                                          ↓
 已取消                                                     已完成
```

**状态触发条件**:
- 待召开 → 进行中: 手动点击"开始会议"，或系统自动在开始时间到达时更新
- 进行中 → 已结束: 手动点击"结束会议"，或系统自动在结束时间到达时更新
- 已结束 → 已完成: 手动点击"完成纪要"，确认纪要整理完成
- 任何状态 → 已取消: 手动点击"取消会议"

**状态颜色规范**:
- 待召开: `bg-gray-100 text-gray-800`
- 进行中: `bg-blue-100 text-blue-800`
- 已结束: `bg-yellow-100 text-yellow-800`
- 已完成: `bg-green-100 text-green-800`
- 已取消: `bg-red-100 text-red-800`

- 完成期限（可选）

**决议列表**:
- 序号、内容、责任人、期限、状态
- 支持编辑、删除
- 支持标记完成/未完成

### 3.2.4 待办事项管理

**添加待办事项**:
- 事项内容（必填，max: 500）
- 负责人（必填）
- 截止日期（必填）
- 优先级（必填: 高/中/低）

**待办事项列表**:
- 序号、内容、负责人、截止日期、优先级、状态
- 支持编辑、删除

- 支持跳转到问题详情

**附件列表**:
- 文件名、大小、上传时间、上传人
- 支持下载、删除

### 3.2.6 纪要导出

**导出格式**:
- PDF格式（推荐）
- Word格式

**导出内容**:
- 会议基本信息
- 会议议程

- 待办事项列表

## 3.3 问题列表

### 3.3.1 功能描述
问题列表展示所有解决方式为"会议"的问题记录，这些问题来自问题管理模块。

### 3.3.2 数据来源
**查询条件**:
```typescript
// 从问题管理(issueRecords)集合查询
{
  solutionMethod: '会议',  // 解决方式为会议
  relatedMeetingId: { $exists: true } // 有关联会议ID
}
```

**关联字段**:
- `relatedMeetingId`: 关联的会议ID（问题管理中的字段）
- 通过此字段可以反向查询某个会议的所有问题

### 3.3.3 展示内容

**列表字段**:
- 问题名称
- 问题描述（简略）
- 关联会议（会议标题+时间）
- 责任人
- 优先级标签
- 问题状态标签
- 创建时间
- 操作按钮（查看详情、跳转到问题管理）

**筛选条件**:
- 会议筛选（全部/特定会议）
- 状态筛选（全部/待解决/解决中/已解决/已关闭）
- 优先级筛选（全部/紧急/重要/一般）
- 责任人筛选
- 时间范围筛选
- 关键词搜索（问题名称、描述）

**排序规则**:
- 默认按创建时间倒序
- 支持按优先级、状态排序

### 3.3.4 业务逻辑

**问题创建**:
- 在问题管理中创建问题时，如果解决方式选择"会议"，需要选择关联的会议
- 问题的 `relatedMeetingId` 字段记录会议ID
- 会议的 `relatedIssues` 数组自动添加问题ID

**问题更新**:
- 问题状态更新后，会议的关联问题数量自动更新
- 问题删除后，会议的关联问题数量自动更新

**问题查看**:
- 点击问题列表的"查看详情"，跳转到问题管理模块的问题详情页
- 问题详情页中显示关联的会议信息，支持跳转到会议详情

### 4.2 索引设计
```javascript
// meetings 集合索引
db.meetings.createIndex({ startTime: -1 }); // 开始时间倒序
db.meetings.createIndex({ status: 1, startTime: -1 }); // 状态+时间
db.meetings.createIndex({ host: 1, startTime: -1 }); // 主持人+时间
db.meetings.createIndex({ participants: 1, startTime: -1 }); // 参会人+时间
db.meetings.createIndex({ isDeleted: 1, startTime: -1 }); // 软删除+时间
db.meetings.createIndex({ createdAt: -1 }); // 创建时间倒序

// issueRecords 集合索引（已存在）
db.issueRecords.createIndex({ solutionMethod: 1, relatedMeetingId: 1 }); // 解决方式+会议
```

## 7. 交互设计

### 7.1 创建会议流程
```
1. 用户点击"新建会议"按钮
2. 弹出创建会议弹窗
3. 填写会议基本信息
4. 选择关联业务（可选）
5. 点击"确定"提交
6. 系统验证表单
7. 调用云函数创建会议
8. 创建成功，关闭弹窗，刷新列表
9. Toast提示"创建成功"
```

### 7.2 编辑纪要流程
```
1. 用户进入会议详情页
2. 点击"编辑纪要"或直接在编辑器中输入
3. 编辑会议纪要（富文本）
4. 添加决议和待办事项
5. 点击"保存纪要"
6. 系统保存纪要内容
7. Toast提示"保存成功"
8. 如果纪要完成，点击"完成纪要"
9. 会议状态更新为"已完成"
```

### 7.3 待办事项转化为问题流程
```
1. 在待办事项列表中，点击"转化为问题"
2. 确认弹窗提示
3. 系统创建问题记录:
   - 调用问题管理云函数
   - 问题名称: 待办事项内容
   - 责任人: 待办事项负责人
   - 解决方式: 会议
   - 关联会议ID: 当前会议ID
4. 待办事项记录关联的问题ID
5. 会议的关联问题列表更新
6. Toast提示"已转化为问题"
7. 支持跳转到问题详情
```
