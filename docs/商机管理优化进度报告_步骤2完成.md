- `types/opportunity.ts` - 添加 `isDeleted` 和 `deletedAt` 字段

**功能详情**:

#### 2.1 商机列表页面重构 ✅
- **UI风格**: 参考任务管理模块,采用卡片式列表
- **头部按钮**: 新建商机 + 回收站
- **商机卡片**: 显示商机名称、阶段、级别、产品类型、客户信息、负责人、协同人、预计金额、成交概率
- **交互**: 点击商机卡片打开详情模态框
- **筛选**: 支持按阶段、级别、关键词搜索
- **权限控制**: 自动过滤已删除的商机 (`isDeleted: neq(true)`)

#### 2.2 商机详情模态框 ✅
- **显示内容**: 
  - 基本信息(名称、阶段、级别、金额、成交概率)
  - 商机详情(产品类型、预计成交日期)
  - 客户信息(客户名称、联系人、电话、邮箱、地址)
  - 负责人信息(负责人、协同人)
  - 商机描述和备注
  - 商机跟进记录(TODO:待后续实现)
- **功能按钮**: 
  - 编辑(蓝色) - 打开编辑模态框
  - 放入回收站(橙色) - 软删除商机
- **二次确认**: 删除前弹出确认对话框

#### 2.3 商机编辑模态框 ✅
- **表单内容**:
  - 基本信息: 商机名称、阶段、级别、产品类型、预计金额
  - 客户信息: 客户名称、联系人、电话、邮箱、地址
  - 商机进展: 成交概率、预计成交日期
  - 负责人信息: 负责人、协同人
  - 可见性设置: 团队可见/不公开(单选按钮卡片式)
  - 商机描述和备注
- **数据验证**:
  - 必填项: 商机名称、客户名称、联系人、电话、预计成交日期、预计金额
  - 金额验证: 必须大于0
  - 概率验证: 0-100之间
- **产品类型关联**: 从系统设置动态加载产品类型

#### 2.4 商机回收站 ✅
- **功能**: 显示所有已删除的商机
- **列表内容**: 商机名称、阶段、级别、客户、产品类型、负责人、预计金额、删除时间
- **搜索功能**: 支持按商机名称、客户名称、负责人搜索
- **交互**: 点击商机打开回收站详情

#### 2.5 商机回收站详情 ✅
- **显示内容**: 完整的商机信息(只读)
- **功能按钮**:
  - 返回继续执行(绿色) - 恢复商机到正常列表
  - 永久删除(红色) - 真正删除商机
- **安全保护**: 永久删除前弹出确认对话框
- **数据清理**: 永久删除时会删除商机及相关数据

#### 2.6 软删除机制 ✅
- **实现方式**: 标记 `isDeleted: true`,而非真正删除
- **字段**: `isDeleted`(布尔型)、`deletedAt`(删除时间)
- **查询**: 列表查询自动排除 `isDeleted: true` 的商机
- **恢复**: 更新 `isDeleted: false`,移除 `deletedAt`
