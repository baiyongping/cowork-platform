# 解决方式字段新增说明

## 📋 更新概述

为问题管理模块新增了"解决方式"字段,提供三种可选方式:
- **转交**: 将问题转交给其他人处理
- **会议研讨**: 通过会议讨论解决问题
- **形成任务**: 将问题转化为具体任务执行

## 🔄 更新内容

### 1. 类型定义更新 (`types/issue.ts`)

#### 新增类型
```typescript
export type IssueSolution = '转交' | '会议研讨' | '形成任务';
```

#### Issue接口更新
```typescript
export interface Issue {
  // ... 其他字段
  solution?: IssueSolution; // 🆕 解决方式 (可选)
  // ... 其他字段
}
```

#### 新增颜色辅助函数
```typescript
export const getSolutionColor = (solution?: IssueSolution): string => {
  if (!solution) return 'bg-gray-100 text-gray-800';
  switch (solution) {
    case '转交':
      return 'bg-blue-100 text-blue-800';
    case '会议研讨':
      return 'bg-purple-100 text-purple-800';
    case '形成任务':
      return 'bg-green-100 text-green-800';
    default:
      return 'bg-gray-100 text-gray-800';
  }
};
```

## 🎨 UI 设计

### 颜色方案
- **转交**: 蓝色背景 (`bg-blue-100 text-blue-800`)
- **会议研讨**: 紫色背景 (`bg-purple-100 text-purple-800`)
- **形成任务**: 绿色背景 (`bg-green-100 text-green-800`)

### 显示位置
- **问题列表**: 作为独立列显示在解决结果和重要程度之间
- **问题详情**: 在顶部标签区域,显示在解决结果标签之后
- **创建/编辑表单**: 位于解决结果字段下方

## 📊 数据库结构

### 字段属性
- **字段名**: `solution`
- **类型**: String (可选)
- **可选值**: `'转交'` | `'会议研讨'` | `'形成任务'` | `undefined`
- **默认值**: `undefined` (未选择)

### 示例数据

```json
  "priority": "非常重要",
  "urgency": "及时解决",
  // ... 其他字段
}
```

## ✅ 功能特性

### 1. 可选字段
- 解决方式是可选字段,可以不选择
- 未选择时显示为 "-"

### 2. 三种解决方式
- **转交**: 适用于需要转交给其他部门或人员处理的问题
- **会议研讨**: 适用于需要多方讨论决策的复杂问题
- **形成任务**: 适用于需要转化为具体执行任务的问题

### 3. 视觉标识
- 每种解决方式都有独特的颜色标识
- 在列表和详情中保持一致的显示风格

## 🔧 使用方式

### 创建问题时设置
1. 在创建问题表单中找到"解决方式"字段
2. 从下拉菜单中选择合适的方式(或保持未选择)
3. 保存问题

### 编辑问题时修改
1. 打开问题详情
2. 点击"编辑"按钮
3. 在"解决方式"下拉菜单中修改选项
4. 保存更改

### 查看解决方式
- **列表视图**: 在问题列表的"解决方式"列中查看
- **详情视图**: 在问题详情页面顶部的标签区域查看

## 📝 注意事项

1. **向后兼容**: 现有问题数据会显示 "-" (未设置),不影响现有功能
2. **类型安全**: 所有组件都使用 TypeScript 类型定义,确保类型安全
3. **UI 一致性**: 与现有字段保持一致的显示风格和交互方式
4. **可扩展性**: 如需添加新的解决方式,只需更新类型定义和选项列表
