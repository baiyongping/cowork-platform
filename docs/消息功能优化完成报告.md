## 🎯 核心功能详解

### 1. **完善的消息界面**

#### 头部区域
- **消息中心标题** + 未读消息徽章
- **关闭按钮**（可选，支持作为弹窗使用）

#### 工具栏区域
- **批量删除按钮**（选中时显示，显示选中数量）
- **全部标记已读按钮**（有未读消息时显示）
- **只看未读按钮**（切换过滤模式）
- **全选/取消全选按钮**

#### 类型筛选区域
- **全部** - 显示所有消息（含总数）
- **任务分配** - 只显示任务分配消息
- **任务更新** - 只显示任务更新消息
- **商机动态** - 只显示商机相关消息
- **项目动态** - 只显示项目相关消息

#### 消息列表区域
- **选择框** - 支持多选消息
- **消息图标** - 根据消息类型显示不同图标和颜色
- **消息内容** - 标题、内容、时间、类型标签
- **操作按钮** - 标记已读、删除

**按类型筛选**:

---

### 3. **标记已读功能**

**单条标记已读**:
- 点击消息卡片上的"✓✓"图标
- 点击消息内容自动标记已读
- 调用云函数: `message-read`，参数: `{ messageId }`

**全部标记已读**:
- 点击工具栏的"全部已读"按钮
- 调用云函数: `message-read`，参数: `{ markAll: true }`

**已读状态视觉区分**:
- **未读消息**: 蓝色背景(`bg-blue-50`)，蓝色边框
- **已读消息**: 白色背景，灰色边框

---

### 4. **删除消息功能**

**单条删除**:
- 点击消息卡片上的"🗑️"图标
- 二次确认提示
- 调用云函数: `message-delete`，参数: `{ messageId }`

**批量删除**:
1. 勾选要删除的消息（支持全选）
2. 点击工具栏的"删除 (N)"按钮
3. 二次确认提示（显示删除数量）
4. 调用云函数: `message-delete`，参数: `{ messageIds: [...] }`

**删除后自动更新**:
- 删除成功后自动从列表移除
- 更新未读计数

### 5. **消息详情跳转**

**自动跳转规则**:

| 消息类型 | 跳转页面 | 说明 |
|---------|---------|------|
| `task_assign` | `/tasks` | 任务分配消息 |
| `task_update` | `/tasks` | 任务更新消息 |
| `task_due` | `/tasks` | 任务到期提醒 |
| `opportunity_update` | `/opportunities` | 商机动态消息 |
| `project_update` | `/projects` | 项目动态消息 |
| `goal_update` | `/goals` | 目标更新消息 |

**跳转流程**:
1. 点击消息内容区域
2. 自动标记为已读
3. 路由跳转到对应页面
4. （未来可扩展）自动定位到具体数据项

## 🛠️ 技术实现

### 组件架构

```
MessageCenter.tsx (主组件)
├── 状态管理
│   ├── messages: Message[]           // 消息列表
│   ├── loading: boolean              // 加载状态
│   ├── selectedType: string          // 选中的类型筛选
│   ├── showUnreadOnly: boolean       // 是否只看未读
│   └── selectedMessages: Set<string> // 选中的消息ID集合
│
├── 数据加载
│   └── loadMessages() - 调用 message-list 云函数
│
├── 核心功能
│   ├── handleMarkRead(messageId)     // 标记单条已读
│   ├── handleMarkAllRead()           // 全部标记已读
│   ├── handleDelete(messageId)       // 删除单条
│   ├── handleBatchDelete()           // 批量删除
│   ├── toggleMessageSelect(id)       // 切换选择状态
│   ├── toggleSelectAll()             // 全选/取消全选
│   └── handleMessageClick(msg)       // 消息点击跳转
│
└── UI层级
    ├── 头部（标题 + 关闭）
    ├── 工具栏（批量操作 + 筛选）
    ├── 类型筛选（5种类型 + 计数）
    └── 消息列表（卡片展示）
```

## 📝 使用说明

### 如何访问消息中心

**方式一：通过个人信息菜单**
1. 点击 Sidebar 底部的"个人信息"
2. 在个人信息页面找到"消息中心"Tab
3. 查看和管理消息

**方式二：通过未读消息计数**
1. Sidebar 会显示未读消息计数（每30秒刷新）
2. 点击个人信息进入消息中心

### 常用操作

**查看未读消息**:
1. 点击工具栏的"只看未读"按钮
2. 列表只显示未读消息

**批量删除消息**:
1. 勾选要删除的消息
2. 点击工具栏的"删除 (N)"按钮
3. 确认删除

**按类型筛选**:
1. 点击类型筛选栏的按钮
2. 选择要查看的消息类型

**跳转到相关页面**:
1. 点击消息内容区域
2. 自动跳转到相关模块（任务/商机/项目等）
