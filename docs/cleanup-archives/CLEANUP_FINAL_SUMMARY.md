## 📝 后续维护建议

### 日常文件管理

**新建文档时:**
- 完成报告 → `docs/archived-reports/`
- 功能说明 → `docs/guides/`
- 部署文档 → `docs/deployment/`
- 版本发布 → `docs/releases/`
- 开发脚本 → `scripts/`

**临时文件:**
- 测试 HTML → 使用后立即删除
- 日志文件 → 不提交到 Git
- 临时脚本 → `scripts/tests/` 后删除
