# 📁 项目文件清理执行指南

## 🎯 清理目标

清理和归档项目中的临时文件、过期文档、重复脚本,保持项目目录整洁。

---

## ⚠️ 执行前准备

### 1. 备份重要文件

```bash
# 建议先创建 Git 提交,确保可以回滚
git add .
git commit -m "清理前备份"
```

### 2. 确认当前分支

```bash
git branch
# 确保在开发分支,不是 master/main
```

## 🚀 执行步骤

### 步骤 1: 查看清理计划

```bash

```

### 步骤 2: 执行清理和归档


**这个脚本会:**
1. ✅ 创建归档目录结构

6. 📦 归档部署配置文档(约15个文件)
7. 📦 归档版本发布文档(约10个文件)

9. 📦 归档测试脚本(约6个文件)

## 🔄 如果需要回滚

### 方案 1: Git 回滚

```bash
# 查看提交历史
git log --oneline

# 回滚到清理前
git reset --hard HEAD~1

# 或者使用特定提交ID
git reset --hard <commit-id>
```

### 方案 2: 从归档恢复

```bash
# 归档的文件仍然存在,可以手动移回
move docs\archived-reports\*.md .
move scripts\archived\*.bat .
# ...
```

## ❓ 常见问题

### Q: 清理会影响项目运行吗?

**A:** 不会。清理只涉及:
- ✅ 临时构建日志
- ✅ 过期的完成报告
- ✅ 临时测试文件
- ✅ 重复的部署脚本

核心代码、配置文件、依赖包都不受影响。

### Q: 归档的文件还能访问吗?

**A:** 可以。归档的文件移动到了结构化的目录:
- 完成报告 → `docs/archived-reports/`
- 功能说明 → `docs/guides/`
- 部署文档 → `docs/deployment/`
- 旧脚本 → `scripts/archived/`

### Q: 可以只归档不删除吗?

**A:** 可以。编辑 `clean-project.bat`,注释掉删除命令:
```batch
REM del /Q build*.log
```

### Q: 清理后项目大小会减少多少?

**A:** 预计减少:
- 文件数量: 约100-120个文件
- 磁盘空间: 约5-10MB (主要是文档)
