# 问题状态和解决结果字段更新说明

## 更新日期
2025-12-29

## 更新内容

### 1. 问题状态字段修改

**旧状态值**：
- 未开始
- 进行中
- 已完成
- 延期
- 取消
- 暂停

**新状态值**：
- 待接受
- 处理中
- 已处理
- 已确认

### 2. 新增解决结果字段

**字段名**：`result`

**数据类型**：可选字段（IssueResult）

**可选值**：
- 已解决
- 无法解决
- 暂缓解决
- 取消

### 数据库脚本

7. **database/update-issue-status.js**
   - 创建数据库更新脚本

   - 自动迁移现有数据

## 状态映射规则

数据库脚本会按照以下规则迁移现有数据：

```javascript
状态映射：
'未开始' → '待接受'
'进行中' → '处理中'
'已完成' → '已处理'
'延期' → '处理中'
'暂停' → '处理中'
'取消' → '已处理'，同时设置 result='取消'
```

## 使用说明

### 1. 执行数据迁移

在更新代码后，需要执行数据库迁移脚本：

```bash
node database/update-issue-status.js
```

### 2. 功能使用

#### 创建问题时
- 默认状态为"待接受"
- 解决结果默认为"未确定"

#### 编辑问题时
- 可以修改状态和解决结果
- 解决结果为可选字段

#### 问题列表显示
- 列表中新增"解决结果"列
- 未设置解决结果时显示"-"
- 不同解决结果有不同的颜色标识

#### 问题详情显示
- 详情页面显示当前状态和解决结果
- 解决结果与状态并列显示在标签区域

## 颜色方案

### 状态颜色
- **待接受**: 灰色 (bg-gray-100 text-gray-800)
- **处理中**: 蓝色 (bg-blue-100 text-blue-800)
- **已处理**: 绿色 (bg-green-100 text-green-800)
- **已确认**: 紫色 (bg-purple-100 text-purple-800)

### 解决结果颜色
- **已解决**: 绿色 (bg-green-100 text-green-800)
- **无法解决**: 红色 (bg-red-100 text-red-800)
- **暂缓解决**: 黄色 (bg-yellow-100 text-yellow-800)
- **取消**: 灰色 (bg-gray-100 text-gray-800)

## 注意事项

1. **数据迁移**：更新代码后必须执行数据库迁移脚本
2. **向后兼容**：旧版本创建的问题在迁移后仍然可以正常显示
3. **可选字段**：解决结果是可选字段，允许为空
4. **延期判断**：延期判断逻辑已更新，排除"已处理"和"已确认"状态
