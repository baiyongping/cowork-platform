## 💻 代码实现检查

### 4. 查询逻辑审查

**❌ 禁止的危险写法**：
```typescript
// ❌ 直接查询新字段（如果字段不存在，返回空结果）
const users = await db.collection('users')
  .where({ newField: someValue })
  .get();
```

**✅ 推荐的安全写法**：
```typescript
// ✅ 方案A：先查询所有，再在客户端筛选
const allUsers = await db.collection('users').get();
const filtered = allUsers.data.filter(user => {
  const fieldValue = user.newField || defaultValue;
  return fieldValue === someValue;
});

// ✅ 方案B：使用存在性检查
const users = await db.collection('users')
  .where({
    newField: db.command.exists(true).and(db.command.eq(someValue))
  })
  .get();

// ✅ 方案C：提供默认值查询
const users = await db.collection('users')
  .where({
    _: db.command.or([
      { newField: someValue },
      { newField: db.command.exists(false) }  // 包含字段不存在的记录
    ])
  })
  .get();
```

**检查项**：
- [ ] 是否直接使用 `where({ newField: value })`？
- [ ] 是否考虑字段不存在的情况？
- [ ] 查询逻辑是否能返回所有应该返回的数据？

// 数据迁移脚本示例
async function migrateApprovalStatus() {
  const users = await db.collection('users')
    .where({ approvalStatus: db.command.exists(false) })  // 找出没有该字段的记录
    .get();
  
  console.log(`找到 ${users.data.length} 条需要迁移的记录`);
  
  for (const user of users.data) {
    const status = user.username === 'admin' ? 'approved' : 'pending';
    await db.collection('users').doc(user._id).update({

      updatedAt: new Date()
    });
  }

}

## ⚠️ 常见陷阱和反模式

### 陷阱1：直接查询新字段
```typescript
// ❌ 危险！旧数据没有该字段，查询返回空
const users = await db.collection('users')
  .where({ newField: 'value' })
  .get();
// 结果：页面显示"暂无数据"，但数据库里其实有数据
```

### 陷阱2：忘记处理undefined
```typescript
// ❌ 危险！旧数据会显示undefined
<div>{user.newField}</div>

// ✅ 安全
<div>{user.newField || '默认值'}</div>
```

### 陷阱3：错误使用 || 处理false值
```typescript
// ❌ 当newField是false时，会错误地使用默认值
const value = user.newField || true;  // 如果newField是false，返回true

// ✅ 正确使用 ??
const value = user.newField ?? true;  // 只有null/undefined才用默认值
```

### 陷阱4：过度信任数据库约束
```typescript
// ❌ 假设字段一定存在
const status = user.approvalStatus;  // 可能undefined
if (status === 'pending') { ... }    // 会出错

// ✅ 防御性检查
const status = user.approvalStatus || 'pending';
if (status === 'pending') { ... }
```
