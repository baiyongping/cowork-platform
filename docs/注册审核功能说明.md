# 注册审核功能说明

## 功能概述

系统新增了完整的用户注册审核流程，确保只有经过管理员审核的用户才能登录使用系统。

## 核心功能

### 1. 手机号验证注册

**用户注册流程：**
1. 填写注册信息（用户名、姓名、手机号、密码）
2. 点击"发送验证码"按钮
3. 输入收到的6位数字验证码
4. 提交注册申请
5. 等待管理员审核

**验证码规则：**
- 验证码为6位数字
- 有效期5分钟
- 使用后自动失效
- 开发环境会直接显示验证码（生产环境需配置短信服务）

### 2. 审核状态管理

**审核状态类型：**
- `pending` - 待审核（注册后的默认状态）
- `approved` - 已通过（可以正常登录）
- `rejected` - 已拒绝（无法登录）

**登录限制：**
- 待审核用户：提示"账号正在审核中，请等待管理员审核"
- 已拒绝用户：提示"账号审核未通过（原因：xxx），请联系管理员"
- 已禁用用户：提示"账号已被禁用，请联系管理员"
- 只有状态为`approved`的用户才能正常登录

### 3. 管理员审核后台

**功能特性：**
- ✅ 查看待审核用户列表
- ✅ 查看用户注册信息（用户名、姓名、手机号、注册时间）
- ✅ 通过注册申请
- ✅ 拒绝注册申请（需填写拒绝原因）
- ✅ 状态筛选（待审核/已通过/已拒绝/全部）
- ✅ 搜索用户（支持用户名、姓名、手机号搜索）
- ✅ 查看历史审核记录

**访问权限：**
- 仅管理员（role: 'admin'）可以访问
- 侧边栏菜单中显示"用户审核"入口

## API更新

### 新增接口

#### 1. sendVerificationCode - 发送验证码
```typescript
sendVerificationCode(phone: string): Promise<{
  success: boolean;
  message: string;
}>
```

**参数：**
- `phone`: 手机号（11位数字，1开头）

**返回：**
- `success`: 是否成功
- `message`: 提示信息

**示例：**
```typescript
const result = await sendVerificationCode('13800138000');
if (result.success) {
  console.log('验证码已发送');
}
```

### 修改接口

#### 2. register - 用户注册
```typescript
register(userData: {
  username: string;
  password: string;
  phone: string;              // 新增：手机号（必填）
  verificationCode: string;   // 新增：验证码（必填）
  name?: string;
  role?: string;
}): Promise<LoginResult>
```

**新增验证：**
- 手机号格式验证
- 验证码验证
- 手机号唯一性检查

**返回变更：**
- 注册成功后不再直接返回token和user
- 只返回成功消息，提示等待审核
- 用户需要等待管理员审核通过后才能登录

#### 3. login - 用户登录
```typescript
login(username: string, password: string): Promise<LoginResult>
```

**新增检查：**
- 审核状态检查
- 只有`approvalStatus: 'approved'`的用户才能登录
- 返回明确的错误提示信息

## 使用指南

### 用户注册流程

1. **访问注册页面**
   - 打开系统，点击"注册"标签

2. **填写注册信息**
   ```
   用户名：testuser（必填）
   姓名：测试用户（可选）
   手机号：13800138000（必填）
   密码：123456（必填，至少6位）
   确认密码：123456（必填）
   ```

3. **获取验证码**
   - 点击"发送验证码"按钮
   - 开发环境会直接显示验证码
   - 生产环境会发送短信到手机

4. **输入验证码**
   - 输入收到的6位数字验证码

5. **提交注册**
   - 点击"注册"按钮
   - 显示"注册成功！您的账号正在等待管理员审核"

6. **等待审核**
   - 管理员会在后台审核您的注册申请
   - 审核通过后会收到通知（未来功能）

### 管理员审核流程

1. **登录管理员账号**
   ```
   用户名：admin
   密码：admin123
   ```

2. **进入用户审核页面**
   - 点击侧边栏"用户审核"菜单

3. **查看待审核用户**
   - 默认显示"待审核"状态的用户
   - 可以看到用户的基本信息和注册时间

4. **审核用户**

   **通过申请：**
   - 点击"通过"按钮
   - 确认操作
   - 用户即可正常登录

   **拒绝申请：**
   - 点击"拒绝"按钮
   - 填写拒绝原因（必填）
   - 确认操作
   - 用户登录时会看到拒绝原因

5. **查看历史记录**
   - 切换到"已通过"或"已拒绝"标签
   - 查看历史审核记录

## 常见问题

### Q1: 注册后无法登录？
**A:** 注册成功后，账号处于"待审核"状态，需要等待管理员审核通过后才能登录。

### Q2: 如何查看我的审核状态？
**A:** 尝试登录时，系统会提示您的账号状态：
- "账号正在审核中" = 待审核
- "账号审核未通过" = 已拒绝
- 成功登录 = 已通过

### Q3: 管理员账号需要审核吗？
**A:** 已存在的管理员账号（如admin）需要运行升级脚本更新为"已审核"状态。新创建的管理员账号也需要审核。

### Q4: 验证码收不到怎么办？
**A:** 
- 开发环境：验证码会直接弹窗显示
- 生产环境：检查手机号是否正确，或联系管理员

### Q5: 如何批量审核用户？
**A:** 当前需要逐个审核，未来可以添加批量操作功能。

### Q6: 审核记录可以删除吗？
**A:** 建议保留审核记录用于追溯，不提供删除功能。

## 技术细节

### 密码加密

使用SHA-256哈希算法：
```typescript
const SECRET_KEY = 'jihua-oa-platform-secret-key-2025';

async function hashPassword(password: string): Promise<string> {
  const encoder = new TextEncoder();
  const data = encoder.encode(password + SECRET_KEY);
  const hashBuffer = await crypto.subtle.digest('SHA-256', data);
  const hashArray = Array.from(new Uint8Array(hashBuffer));
  return hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
}
```

### 验证码生成

生成6位随机数字：
```typescript
const code = Math.floor(100000 + Math.random() * 900000).toString();
```

### 验证码验证逻辑

```typescript
async function verifyCode(phone: string, code: string): Promise<boolean> {
  const result = await db.collection('sms_codes')
    .where({ phone, code, used: false })
    .orderBy('createdAt', 'desc')
    .limit(1)
    .get();

  if (result.data.length === 0) return false;

  const smsCode = result.data[0];
  
  // 检查是否过期
  if (new Date(smsCode.expiresAt) < new Date()) return false;

  // 标记为已使用
  await db.collection('sms_codes').doc(smsCode._id).update({ used: true });

  return true;
}
```
