# 功能模块管理 - 数据库初始化指南

## 📋 目标

创建并配置功能模块管理所需的2个数据库集合：
1. `modulesConfig` - 功能模块配置集合
2. `moduleMetadata` - 模块元数据集合

---

## 🚀 快速开始

### 方式一：CloudBase 控制台手动创建（推荐）

#### 步骤1: 访问控制台

访问链接: https://tcb.cloud.tencent.com/dev?envId=cowork-9gg9oocb516be5fb#/db/doc

#### 步骤2: 创建集合

##### 2.1 创建 `modulesConfig` 集合

1. 点击 **[新建集合]** 按钮
2. 输入集合名称: `modulesConfig`
3. 点击确定创建

##### 2.2 创建 `moduleMetadata` 集合

1. 点击 **[新建集合]** 按钮
2. 输入集合名称: `moduleMetadata`
3. 点击确定创建

---

#### 步骤3: 创建索引

##### 3.1 为 `modulesConfig` 创建索引

进入 `modulesConfig` 集合详情页，点击 **[索引管理]** → **[新建]**

**索引1**: 排序索引
```json
{
  "IndexName": "idx_order",
  "MgoKeySchema": {
    "MgoIndexKeys": [{ "Name": "order", "Direction": "1" }],
    "MgoIsUnique": false
  }
}
```

**索引2**: 父模块复合索引
```json
{
  "IndexName": "idx_parent",
  "MgoKeySchema": {
    "MgoIndexKeys": [
      { "Name": "parentId", "Direction": "1" },
      { "Name": "order", "Direction": "1" }
    ],
    "MgoIsUnique": false
  }
}
```

**索引3**: 启用状态索引
```json
{
  "IndexName": "idx_enabled",
  "MgoKeySchema": {
    "MgoIndexKeys": [
      { "Name": "isEnabled", "Direction": "1" },
      { "Name": "order", "Direction": "1" }
    ],
    "MgoIsUnique": false
  }
}
```

**索引4**: 自定义模块索引
```json
{
  "IndexName": "idx_custom",
  "MgoKeySchema": {
    "MgoIndexKeys": [
      { "Name": "isCustom", "Direction": "1" },
      { "Name": "isEnabled", "Direction": "1" }
    ],
    "MgoIsUnique": false
  }
}
```

##### 3.2 为 `moduleMetadata` 创建索引

进入 `moduleMetadata` 集合详情页，点击 **[索引管理]** → **[新建]**

**索引1**: 模块类型复合索引
```json
{
  "IndexName": "idx_module_type",
  "MgoKeySchema": {
    "MgoIndexKeys": [
      { "Name": "moduleId", "Direction": "1" },
      { "Name": "type", "Direction": "1" }
    ],
    "MgoIsUnique": false
  }
}
```

**索引2**: 活跃状态索引
```json
{
  "IndexName": "idx_active",
  "MgoKeySchema": {
    "MgoIndexKeys": [
      { "Name": "isActive", "Direction": "1" },
      { "Name": "lastUsedAt", "Direction": "-1" }
    ],
    "MgoIsUnique": false
  }
}
```

**索引3**: 使用频率索引
```json
{
  "IndexName": "idx_usage",
  "MgoKeySchema": {
    "MgoIndexKeys": [
      { "Name": "moduleId", "Direction": "1" },
      { "Name": "usageCount", "Direction": "-1" }
    ],
    "MgoIsUnique": false
  }
}
```

---

#### 步骤4: 配置权限规则

##### 4.1 `modulesConfig` 权限规则

进入集合详情页 → **[权限设置]** → **[自定义安全规则]**

```javascript
{
  "read": "auth != null",
  "write": false,
  "create": false,
  "delete": false
}
```

**说明**: 
- 所有登录用户可读
- 写入/创建/删除操作仅通过云函数执行（避免直接操作）

##### 4.2 `moduleMetadata` 权限规则

```javascript
{
  "read": "auth != null",
  "write": false,
  "create": false,
  "delete": false
}
```

**说明**:
- 所有登录用户可读
- 所有写入操作由系统自动执行

## ✅ 验证步骤

### 验证1: 检查集合是否创建成功

访问控制台，确认2个集合存在：
- ✅ `modulesConfig`
- ✅ `moduleMetadata`

### 验证2: 检查索引是否创建成功

点击每个集合的 **[索引管理]**，确认索引数量：
- `modulesConfig`: 4个索引 + 1个默认 `_id` 索引 = 共5个
- `moduleMetadata`: 3个索引 + 1个默认 `_id` 索引 = 共4个

### 验证3: 测试读取权限

在前端项目中测试：
```typescript
import { db } from '@/lib/cloudbase';

// 测试读取
const { data } = await db.collection('modulesConfig').limit(1).get();
console.log('读取成功:', data);
```

## ❓ 常见问题

**Q1: 为什么不能通过代码自动创建集合？**
A: CloudBase Node SDK 不支持通过代码创建集合，需要在控制台手动创建。

**Q2: 索引创建失败怎么办？**
A: 确认字段名和类型正确，如果已有数据，确保数据格式符合索引要求。

**Q3: 权限规则如何生效？**
A: 权限规则立即生效，建议先在测试环境验证。
