### 3. 具体优化细节

#### 商机阶段卡片 (紫色系)
```
✨ 配色: 紫色→靛蓝渐变
✨ 状态指示: 白色脉冲点 (animate-pulse)
✨ 阶段显示: 白色标签 + 紫色文字
✨ 交互: 下拉菜单选项高亮改为紫色
✨ 图标: 无额外图标,保持简洁
```

**设计特点**:
- 紫色代表转换和流动,符合阶段切换的含义
- 白色脉冲点增加动态感和实时状态感
- 与靛蓝色形成渐变,过渡自然

#### 重要程度卡片 (橙红色系)
```
✨ 配色: 橙色→红色渐变
✨ 图标: ⭐ 星星emoji
✨ 显示: 直接展示级别名称
✨ 字体: 2xl超大字号
✨ 特点: 突出重要性和紧迫感
```

**设计特点**:
- 橙红渐变营造紧迫感和重要性
- 星星图标直观表达优先级
- 与其他卡片保持统一的布局结构

## 🎨 设计系统

### 配色方案: 彩虹渐变
```
🔵 蓝色系 (预计金额)   → 稳定、增长
🟣 紫色系 (商机阶段)   → 转换、流动
🟠 橙红系 (重要程度)   → 紧迫、重要
🟢 绿色系 (成交机会)   → 成功、希望
```

### 统一的视觉元素
- **圆角**: `rounded-2xl` (16px)
- **内边距**: `p-6` (24px)
- **阴影**: `shadow-lg` → `hover:shadow-xl`
- **动画**: `hover:-translate-y-1` (悬停上浮)
- **过渡**: `transition-all duration-300`
- **文字**: 白色 (高对比度)
