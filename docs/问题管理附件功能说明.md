# 问题管理附件功能说明

## 功能概述

为问题管理模块新增了附件上传和预览功能,支持上传多个文件并可以直接点击打开查看。

## 核心功能

### 1. 附件上传 ✅

**功能特性**:
- 支持上传多个附件(最多10个)
- 单个文件大小限制: 50MB
- 支持各种文件类型(图片、文档、PDF等)
- 实时显示上传进度
- 上传后可预览和删除

**使用场景**:
- 创建问题时上传相关截图、文档
- 编辑问题时补充附件材料
- 提供问题证据和参考资料

### 2. 附件预览 ✅

**功能特性**:
- 点击附件即可在新窗口打开
- 自动获取临时访问链接(有效期2小时)
- 图片文件提供缩略图预览
- 显示文件名、大小、类型等信息

**文件类型图标**:
- 🖼️ 图片文件 - Image 图标
- 📄 文档/PDF - FileText 图标  
- 📎 其他文件 - File 图标

### 3. 云存储集成 ✅

**技术实现**:
- 使用 CloudBase 云存储服务
- 文件存储路径: `issues/attachments/`
- 自动生成唯一文件名(时间戳 + 随机字符串)
- 支持获取临时下载链接

## 数据结构

### IssueAttachment 类型

```typescript
interface IssueAttachment {
  fileID: string;        // 云存储文件ID
  fileName: string;      // 文件名
  fileSize: number;      // 文件大小(字节)
  fileType: string;      // 文件类型(MIME)
  uploadedAt: Date | string;  // 上传时间
  tempUrl?: string;      // 临时访问链接
}
```

### Issue 类型更新

```typescript
interface Issue {
  // ... 其他字段
  attachments?: IssueAttachment[];  // 🆕 附件列表
}
```

## 组件说明

### AttachmentUploader 组件

**职责**: 附件上传和管理

**Props**:
- `attachments`: 当前附件列表
- `onChange`: 附件变更回调
- `maxFiles`: 最大文件数量(默认10)
- `maxSize`: 单文件最大大小MB(默认50)

**功能**:
- 文件选择和上传
- 上传进度提示
- 附件列表展示
- 删除附件

**使用示例**:
```tsx
<AttachmentUploader
  attachments={formData.attachments || []}
  onChange={(attachments) => setFormData(prev => ({ ...prev, attachments }))}
  maxFiles={10}
  maxSize={50}
/>
```

### AttachmentViewer 组件

**职责**: 附件展示和预览

**Props**:
- `attachments`: 附件列表

**功能**:
- 附件列表显示
- 点击打开文件
- 图片缩略图预览
- 临时链接生成

**使用示例**:
```tsx
<AttachmentViewer attachments={issue.attachments || []} />
```

## 使用流程

### 创建问题时上传附件

1. 点击"选择文件"按钮
2. 选择要上传的文件(可多选)
3. 等待上传完成(显示上传进度)
4. 查看已上传的附件列表
5. 可删除不需要的附件
6. 提交问题表单

### 编辑问题时管理附件

1. 打开问题编辑界面
2. 查看已有附件
3. 可以新增附件
4. 可以删除现有附件
5. 保存修改

### 查看问题附件

1. 打开问题详情
2. 查看"附件"区块
3. 点击附件名称打开文件
4. 图片附件会显示缩略图预览

## 文件存储说明

### 云存储路径结构

```
issues/
  attachments/
    {timestamp}-{random}-{filename}
```

**示例**:
```
issues/attachments/1735478400000-abc123-screenshot.png
issues/attachments/1735478401000-def456-report.pdf
```

### 文件命名规则

- 时间戳(毫秒): 确保唯一性
- 随机字符串: 增加安全性
- 原始文件名: 保留用户识别

## 安全性说明

### 上传限制

- **文件数量**: 最多10个附件
- **文件大小**: 单个文件不超过50MB
- **文件类型**: 无限制(建议上传常见格式)

### 访问控制

- 临时访问链接有效期: 2小时
- 只有有权限查看问题的用户才能访问附件
- 删除问题时附件会从云存储删除

### 数据存储

- 使用 CloudBase 云存储服务
- 数据安全可靠,自动备份
- 支持大文件存储

## 注意事项

### 上传文件

1. 确保网络连接稳定
2. 大文件上传可能需要较长时间
3. 上传失败后可重试
4. 建议压缩大文件后上传

### 文件管理

1. 删除附件后无法恢复
2. 编辑问题时修改附件需要保存才生效
3. 临时链接过期后需重新获取

### 兼容性

1. 支持所有现代浏览器
2. 移动端需确保存储权限
3. 部分文件类型可能无法直接预览(如特殊格式)

## 技术实现

### CloudBase SDK 使用

**上传文件**:
```typescript
const result = await app.uploadFile({
  cloudPath: `issues/attachments/${timestamp}-${random}-${filename}`,
  filePath: file
});
```

**获取临时链接**:
```typescript
const tempUrlResult = await app.getTempFileURL({
  fileList: [fileID]
});
```

**删除文件**:
```typescript
await app.deleteFile({
  fileList: [fileID]
});
```
