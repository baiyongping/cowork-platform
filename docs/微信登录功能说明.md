# 微信登录功能说明

## 功能概述

系统已集成微信扫码登录功能,为用户提供更便捷的登录方式。

## 技术实现

### 核心技术
- **CloudBase微信开放平台登录** - 基于腾讯云CloudBase的微信登录能力
- **自动用户创建** - 首次登录自动创建系统账号
- **OpenID绑定** - 通过微信OpenID关联用户身份

### 代码文件
1. **`lib/wechat-login-service.ts`** - 微信登录核心服务
   - `initWechatLogin()` - 初始化微信登录,跳转扫码页面
   - `handleWechatCallback()` - 处理微信授权回调
   - `findOrCreateUserByWechat()` - 查询或创建微信用户
   - `bindWechatToAccount()` - 绑定微信到已有账号
   - `unbindWechat()` - 解绑微信

2. **`components/LoginPage.tsx`** - 登录页面组件
   - 添加微信登录按钮
   - 自动检测微信回调
   - 处理登录状态

3. **`database/migrations/add-wechat-login-fields.js`** - 数据库迁移脚本
   - 添加`wechatOpenId`字段
   - 添加`loginType`字段

## 用户体验

### 登录流程

#### 首次登录 (未绑定微信)
```
1. 用户点击"微信扫码登录"按钮
2. 跳转到微信授权页面
3. 用户使用微信扫描二维码
4. 用户确认授权
5. 系统自动创建账号(username: wx_xxx)
6. 登录成功,跳转到系统首页
```

#### 再次登录 (已绑定微信)
```
1. 用户点击"微信扫码登录"按钮
2. 跳转到微信授权页面
3. 用户使用微信扫描二维码
4. 自动识别已绑定账号
5. 登录成功,跳转到系统首页
```

## 安全设计

### 1. 自动审核机制
- **微信登录用户**: `approvalStatus = 'approved'` (自动通过)
- **原因**: 微信已完成实名认证,可信度高
- **管理**: 管理员可后续在"员工管理"中禁用或修改权限

### 2. 用户名生成规则
```typescript
username = `wx_${Date.now().toString(36)}`
// 示例: wx_lm3k9f2x (时间戳转36进制)
```
- 确保唯一性(基于时间戳)
- 易于识别(wx_前缀)
- 用户可后续修改

### 3. 权限控制
- **默认角色**: `user`
- **默认部门**: 空(需管理员分配)
- **权限管理**: 通过RBAC系统控制

### 4. 账号绑定
- **绑定检查**: 防止一个微信绑定多个账号
- **解绑功能**: 支持解除微信绑定
- **重新绑定**: 解绑后可绑定其他账号

## 优势与局限

### 优势
✅ **便捷性**: 无需记忆密码,扫码即可登录  
✅ **安全性**: 基于微信实名认证,可信度高  
✅ **用户体验**: 减少注册流程,降低使用门槛  
✅ **维护性**: 无需管理大量密码重置请求  

### 局限
⚠️ **域名备案**: 生产环境需要已备案域名  
⚠️ **微信依赖**: 需要用户有微信账号  
⚠️ **认证费用**: 微信开放平台需要300元/年认证费  
⚠️ **网络依赖**: 需要访问微信服务器

## 常见问题

### Q: 为什么本地测试失败?
A: 微信登录要求HTTPS协议,本地HTTP环境无法完成回调。建议在生产环境测试。

### Q: 微信用户如何修改用户名?
A: 管理员可在"员工管理"中修改用户信息,包括用户名、姓名、部门等。

### Q: 微信用户如何设置密码?
A: 微信登录用户默认无密码。如需密码登录,可在个人设置中设置密码。

### Q: 一个微信可以绑定多个账号吗?
A: 不可以。一个微信OpenID只能绑定一个系统账号,确保账号唯一性。
