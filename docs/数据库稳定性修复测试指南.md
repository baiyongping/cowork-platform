## 🐛 问题排查指南

### 问题1: 保存时提示"数据库访问被拒绝"

**可能原因**:
- CloudBase安全规则配置问题
- 用户未登录或登录状态过期

**排查步骤**:
1. 运行 `window.checkDbHealth()` 检查 `authReady` 是否为 true
2. 检查用户是否已登录
3. 查看CloudBase控制台的安全规则配置

**解决方案**:
```javascript
// 重新登录
// 或检查 CloudBase 控制台的安全规则
```

### 问题2: 控制台显示 "数据库连接测试失败"

**可能原因**:
- 网络连接问题
- CloudBase环境ID配置错误
- 安全域名未配置

**排查步骤**:
1. 检查网络连接
2. 确认 `.env` 文件中的 `VITE_CLOUDBASE_ENV_ID` 正确
3. 检查CloudBase控制台的安全域名配置

**解决方案**:
1. 在CloudBase控制台添加当前域名到安全域名列表
2. 确认环境ID正确: `jihua-oa-dev-3goht9irae4d949f`

### 问题3: 保存后刷新页面，数据未更新

**可能原因**:
- 浏览器缓存
- 更新操作实际失败但未报错
- 查询条件有问题

**排查步骤**:
1. 强制刷新浏览器 (Ctrl + F5)
2. 检查控制台日志中的"部门是否一致"字段
3. 直接查询数据库验证

**解决方案**:
```javascript
// 在控制台直接查询
const result = await db.collection('users').doc('员工ID').get();
console.log(result.data[0].departments);
```
