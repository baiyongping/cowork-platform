## 🎯 功能说明

功能模块管理系统是一个**元数据管理平台**，用于：

1. **集中管理所有业务模块** - 统一管理系统的所有功能模块配置
2. **自动元数据采集** - 自动扫描数据库集合、字段、路由、API
3. **权限自动同步** - 新增/删除模块时自动同步到所有角色权限
4. **可视化配置界面** - 直观的表格和表单操作界面

1. 调用 `updateFunctionCode` 或 `createFunction` 工具

## 🐛 故障排除

### 问题1: 云函数部署失败
**症状**: 部署时报错  
**解决**:
1. 检查云函数目录结构是否完整
2. 确认 `config.json` 和 `package.json` 存在
3. 查看云函数日志

### 问题2: 导入数据失败
**症状**: 点击导入按钮后报错  
**解决**:
1. 检查环境ID是否正确
2. 打开浏览器控制台查看详细错误
3. 确认 CloudBase SDK 已加载

### 问题3: 菜单不显示
**症状**: 侧边栏没有"功能模块"菜单  
**解决**:
1. 确认当前登录用户是管理员
2. 清除浏览器缓存，强制刷新（Ctrl+F5）
3. 检查 `App.tsx` 和 `Sidebar.tsx` 是否正确修改

### 问题4: 操作报错"权限不足"
**症状**: 任何操作都提示权限不足  
**解决**:
1. 确认登录用户是管理员
2. 检查云函数权限验证逻辑
3. 查看云函数日志

### 问题5: 元数据同步失败
**症状**: 点击同步按钮后报错或无响应  
**解决**:
1. 检查模块配置的 `dbCollection` 是否正确
2. 确认集合在数据库中存在
3. 查看云函数日志中的详细错误
