# 创建问题模态框保存按钮遮挡修复

## 📋 问题描述

**问题现象**：
- 创建问题页面的保存按钮被窗口遮挡
- 在小屏幕或者内容较多时，底部按钮无法显示或者滚动不到

**原因分析**：
- 原来的布局中，表单内容区域设置了 `max-h-[calc(90vh-140px)]`
- 底部按钮没有包含在滚动区域内，而是固定在外部
- 导致在内容较多时，底部按钮可能被遮挡或者无法访问

---

## ✅ 解决方案

### 核心改动

**使用 Flexbox 布局，将模态框分为三部分：**

1. **头部（固定）** - `flex-shrink-0`
2. **表单内容（可滚动）** - `overflow-y-auto flex-1`
3. **底部按钮（固定）** - `flex-shrink-0`

---

## 📝 具体修改

### 文件：`components/CreateIssueModal.tsx`

#### 1. **修改模态框容器** (第 189 行)

**修改前：**
```tsx
<div className="bg-white rounded-lg shadow-xl max-w-3xl w-full max-h-[90vh] overflow-hidden">
```

**修改后：**
```tsx
<div className="bg-white rounded-lg shadow-xl max-w-3xl w-full max-h-[90vh] overflow-hidden flex flex-col">
```

**说明：**
- 添加 `flex flex-col`，让容器变为垂直 Flexbox 布局

---

#### 2. **修改头部区域** (第 191 行)

**修改前：**
```tsx
<div className="flex items-center justify-between p-6 border-b border-gray-200">
```

**修改后：**
```tsx
<div className="flex items-center justify-between p-6 border-b border-gray-200 flex-shrink-0">
```

**说明：**
- 添加 `flex-shrink-0`，防止头部被压缩

---

#### 3. **修改表单内容区域** (第 210 行)

**修改前：**
```tsx
<form onSubmit={handleSubmit} className="p-6 overflow-y-auto max-h-[calc(90vh-140px)]">
```

**修改后：**
```tsx
<form onSubmit={handleSubmit} className="p-6 overflow-y-auto flex-1">
```

**说明：**
- 移除 `max-h-[calc(90vh-140px)]`，使用 `flex-1` 让表单内容占据剩余空间
- 保留 `overflow-y-auto`，让内容可以滚动

---

#### 4. **修改底部按钮区域** (第 516 行)

**修改前：**
```tsx
<div className="flex items-center justify-end space-x-3 p-6 border-t border-gray-200 bg-gray-50">
```

**修改后：**
```tsx
<div className="flex items-center justify-end space-x-3 p-6 border-t border-gray-200 bg-gray-50 flex-shrink-0">
```

**说明：**
- 添加 `flex-shrink-0`，确保底部按钮始终固定在底部，不会被压缩

## 🎯 修复效果

### 修复前：
```
┌────────────────────────┐
│ 头部                    │
├────────────────────────┤
│ 表单内容 (固定高度)      │
│ ...                    │
│ ...                    │
│ ... (内容超出时无法滚动) │
└────────────────────────┘
  底部按钮 (可能被遮挡)
```

### 修复后：
```
┌────────────────────────┐
│ 头部 (固定)             │ ← flex-shrink-0
├────────────────────────┤
│ 表单内容 (可滚动)       │ ← flex-1 + overflow-y-auto
│ ▼ 滚动条               │
│ ...                    │
├────────────────────────┤
│ 底部按钮 (固定)         │ ← flex-shrink-0
└────────────────────────┘
```

---

## 🔧 技术说明

### Flexbox 布局关键属性

| 属性 | 作用 |
|------|------|
| `flex` | 使容器变为 Flexbox 布局 |
| `flex-col` | 垂直方向排列 |
| `flex-1` | 占据剩余空间，自动扩展 |
| `flex-shrink-0` | 不压缩，保持原始大小 |
| `overflow-y-auto` | 内容溢出时显示垂直滚动条 |

### 布局逻辑

```tsx
<div className="flex flex-col max-h-[90vh]">
  {/* 头部 - 不压缩 */}
  <div className="flex-shrink-0">头部</div>
  
  {/* 内容 - 占据剩余空间，可滚动 */}
  <div className="flex-1 overflow-y-auto">表单内容</div>
  
  {/* 底部 - 不压缩 */}
  <div className="flex-shrink-0">底部按钮</div>
</div>
```

## 📱 响应式说明

修复后的布局在不同屏幕尺寸下均能正常工作：

- **大屏幕**: 内容充足，滚动条不显示
- **小屏幕**: 内容超出，滚动条自动显示
- **任何尺寸**: 底部按钮始终可见且可访问
