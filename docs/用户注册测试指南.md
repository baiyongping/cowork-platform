# 用户注册测试指南

## 📱 快速测试流程

### 1. 启动开发服务器

```bash
npm run dev
```

访问: http://localhost:5173

### 2. 进入注册页面

1. 打开登录页面
2. 点击"注册"按钮

### 3. 填写注册信息

```
用户名: testuser123
密码: 123456
确认密码: 123456
姓名: 测试用户
手机号: 13800138000
```

### 4. 获取验证码 🆕

**点击"发送验证码"按钮**

**⚠️ 测试环境下会弹出验证码窗口**:

```
📱 测试环境 - 验证码已生成

手机号: 13800138000
验证码: 123456

有效期: 5分钟

💡 生产环境将通过短信真实发送
```

### 5. 输入验证码

将弹窗显示的验证码输入到"验证码"输入框中。

例如: `123456`

### 6. 提交注册

点击"注册"按钮，系统会：
- ✅ 验证验证码是否正确
- ✅ 验证验证码是否过期
- ✅ 创建用户账号（待审核状态）

### 7. 等待审核

提示信息：
```
注册成功，等待管理员审核
```

### 8. 管理员审核

1. 使用管理员账号登录
2. 进入"用户管理"
3. 找到待审核用户
4. 点击"审核通过"

### 9. 用户登录

审核通过后，用户即可使用账号密码登录。

## 🔧 测试技巧

### 1. 查看验证码

**方式1: 弹窗查看**（推荐）
- 点击"发送验证码"后自动弹出

**方式2: 控制台查看**
- 打开浏览器开发者工具（F12）
- 查看Console标签
- 搜索"验证码已生成"

**方式3: 数据库查看**
- 登录CloudBase控制台
- 进入数据库
- 查看 `sms_codes` 集合
- 按创建时间倒序排列

### 2. 快速测试多个用户

```javascript
// 批量测试数据
const testUsers = [
  { username: 'test001', phone: '13800138001' },
  { username: 'test002', phone: '13800138002' },
  { username: 'test003', phone: '13800138003' },
];
```

### 3. 测试验证码过期

临时修改过期时间为30秒：

```typescript
// lib/auth-service.ts 第87行
expiresAt: new Date(Date.now() + 30 * 1000), // 改为30秒
```

测试完成后记得改回5分钟：

```typescript
expiresAt: new Date(Date.now() + 5 * 60 * 1000), // 5分钟
```

## 💡 常见问题

### Q1: 弹窗没有出现？

**原因**: 
- 浏览器可能阻止了弹窗
- 开发服务器未启动

**解决方案**:
1. 检查浏览器是否允许弹窗
2. 查看浏览器控制台是否有错误
3. 确认 `npm run dev` 正在运行

### Q2: 验证码总是错误？

**原因**: 
- 输入的验证码与生成的不一致
- 验证码已过期（超过5分钟）
- 验证码已被使用

**解决方案**:
1. 仔细核对弹窗显示的验证码
2. 重新获取新的验证码
3. 在5分钟内完成注册

### Q3: 如何查看生成的验证码？

**方法1**: 查看弹窗（自动弹出）

**方法2**: 查看控制台日志
```
🧪 测试环境 - 验证码已生成: 123456
```

**方法3**: 查看数据库
- CloudBase控制台 → 数据库 → `sms_codes`

### Q4: 生产环境如何切换？

构建生产版本时会自动切换：
```bash
npm run build  # MODE=production
```

系统会自动检测环境并切换到真实短信发送。
