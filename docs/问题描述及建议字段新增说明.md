# 问题描述及建议字段新增说明

## 修改概述
为问题管理功能新增了"问题描述及建议"字段，提供多行文本框供用户填写详细的问题描述和解决建议。

## 新增字段说明

### 字段定义
- **字段名称**: `suggestions`
- **字段类型**: `string` (可选)
- **UI组件**: 多行文本框 (textarea)
- **行数**: 5行
- **占位符**: "请填写问题的详细描述和建议..."

### 字段用途
1. **详细描述**: 补充问题的具体背景和详情
2. **解决建议**: 记录针对问题的建议方案
3. **经验总结**: 保存问题处理过程中的经验

## 修改的文件清单

### 1. 类型定义
- **文件**: `types/issue.ts`
- **修改**: 在 `Issue` 接口中新增 `suggestions?: string` 字段

### 2. 创建问题模态框
- **文件**: `components/CreateIssueModal.tsx`
- **修改**:
  - `CreateIssueDto` 接口新增 `suggestions?: string` 字段
  - 表单初始化添加 `suggestions: ''`
  - UI新增多行文本框输入组件

### 3. 编辑问题模态框
- **文件**: `components/EditIssueModal.tsx`
- **修改**: 在问题描述后新增"问题描述及建议"多行文本框

### 4. 问题详情模态框
- **文件**: `components/IssueDetailModal.tsx`
- **修改**: 在问题描述区域后新增"问题描述及建议"显示块

## UI布局说明

### 创建/编辑问题界面
```

问题类型

```

### 问题详情界面
```
基本信息

问题描述及建议  (如有内容则显示) ← 新增
评论区
```

## 字段特点

1. **可选字段**: 用户可以选择是否填写
2. **多行输入**: 5行高度，支持换行
3. **保留格式**: 使用 `whitespace-pre-wrap` 保持换行格式
4. **条件显示**: 详情界面只在有内容时显示

## 数据库兼容性

- **新问题**: 可以填写 suggestions 字段
- **旧问题**: suggestions 字段为空或 undefined，不影响显示
- **向后兼容**: 不会影响现有数据和功能

## 使用示例

### 创建问题时填写
```
问题名称: 生产系统数据库性能下降

问题描述:
最近一周生产环境数据库响应时间明显变慢,
部分查询超过5秒才能返回结果。

问题描述及建议:
1. 经过初步排查,发现orders表数据量已达500万
2. 建议对常用查询字段添加索引
3. 考虑实施数据归档策略,移除历史订单
4. 评估是否需要升级数据库服务器配置
```

### 查看问题详情
详情页面会分别显示两个区块:
- 问题描述 (简短描述)
- 问题描述及建议 (详细说明和建议方案)

## 注意事项

1. **字段长度**: 前端无长度限制,建议合理控制内容长度
2. **格式保留**: 输入的换行和空格会在显示时保留
3. **数据迁移**: 无需数据迁移,新字段对旧数据完全兼容
4. **权限控制**: 遵循原有的权限规则,只有有权限的用户可编辑
