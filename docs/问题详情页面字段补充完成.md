## 🛠️ 核心改动

### 1. 字段展示布局（6行分组）

```
第一行：发起人 + 创建时间
第二行：问题解决人（多标签展示）
第三行：紧急程度 + 问题级别
第四行：开始日期 + 截止日期
第五行：解决方式 + 解决结果
第六行：公开性
```

### 2. 字段样式设计

**紧急程度：**
- 及时解决：红色标签 `bg-red-50 text-red-700`
- 近期解决：黄色标签 `bg-yellow-50 text-yellow-700`

**问题级别：**
- 公司级：紫色标签 `bg-purple-50 text-purple-700`
- 团队级：蓝色标签 `bg-blue-50 text-blue-700`
- 个人级：灰色标签 `bg-gray-50 text-gray-700`

**解决方式：**
- 绿色标签 `bg-green-50 text-green-700`

**解决结果：**
- 已解决：绿色标签 `bg-green-50 text-green-700`
- 未解决：红色标签 `bg-red-50 text-red-700`
- 未确定：灰色标签 `bg-gray-50 text-gray-700`

**公开性：**
- 公开：绿色标签 `bg-green-50 text-green-700`
- 不公开：灰色标签 `bg-gray-50 text-gray-700`

## 📝 代码实现

### 修改文件
- **`components/IssueDetailModal.tsx`** ✅

### 关键代码段

```tsx
{/* 问题解决人 - 支持多个 */}
{issue.solvers && issue.solvers.length > 0 && (
  <div className="flex items-start gap-2">
    <User className="h-4 w-4 mt-0.5" />
    <span className="font-medium">问题解决人:</span>
    <div className="flex flex-wrap gap-2">
      {issue.solvers.map((solver, index) => (
        <span key={index} className="px-2 py-1 bg-blue-50 text-blue-700 rounded-md">
          {solver.name || solver}
        </span>
      ))}
    </div>
  </div>
)}

{/* 紧急程度 */}
{issue.urgency && (
  <div className="flex items-center gap-2">
    <span className="font-medium">紧急程度:</span>
    <span className={`px-3 py-1 rounded-full font-medium ${
      issue.urgency === '及时解决' ? 'bg-red-50 text-red-700' :
      'bg-yellow-50 text-yellow-700'
    }`}>
      {issue.urgency}
    </span>
  </div>
)}

{/* 问题级别 */}
{issue.level && (
  <div className="flex items-center gap-2">
    <span className="font-medium">问题级别:</span>
    <span className={`px-3 py-1 rounded-full font-medium ${
      issue.level === '公司级' ? 'bg-purple-50 text-purple-700' :
      issue.level === '团队级' ? 'bg-blue-50 text-blue-700' :
      'bg-gray-50 text-gray-700'
    }`}>
      {issue.level}
    </span>
  </div>
)}

{/* 日期范围 */}
{issue.startDate && (
  <div className="flex items-center gap-2">
    <Calendar className="h-4 w-4" />
    <span className="font-medium">开始日期:</span>
    <span>{new Date(issue.startDate).toLocaleDateString('zh-CN')}</span>
  </div>
)}

{/* 解决方式 + 解决结果 */}
{issue.solution && (
  <div className="flex items-center gap-2">
    <span className="font-medium">解决方式:</span>
    <span className="px-3 py-1 bg-green-50 text-green-700 rounded-full font-medium">
      {issue.solution}
    </span>
  </div>
)}

{/* 公开性 */}
{issue.isPublic !== undefined && (
  <div className="flex items-center gap-2">
    <span className="font-medium">公开性:</span>
    <span className={`px-3 py-1 rounded-full font-medium ${
      issue.isPublic ? 'bg-green-50 text-green-700' : 'bg-gray-50 text-gray-700'
    }`}>
      {issue.isPublic ? '公开' : '不公开'}
    </span>
  </div>
)}
```
