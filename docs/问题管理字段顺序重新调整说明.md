# 问题管理字段顺序重新调整说明

## 📋 调整概述

重新调整了**问题新建页**、**问题编辑页**和**问题详情页**的字段显示顺序，使三个页面保持统一。

## 🎯 新的字段顺序

### 统一字段顺序（新建页/编辑页/详情页）

1. ✅ **问题标题** - 必填
2. ✅ **问题类型 + 问题状态** - 并排显示
3. ✅ **重要程度 + 紧急程度** - 并排显示
4. ✅ **开始日期 + 截止日期** - 并排显示，必填
5. ✅ **发起人 + 问题解决人** - 并排显示，都是**单一选择**
6. ✅ **问题描述及建议** - 多行文本
7. ✅ **附件上传**
8. ✅ **解决方式 + 解决结果** - 并排显示
9. ✅ **公开性** - 单选框（团队公开/所有人公开/不公开）

## 🔑 关键改进点

### 1. 问题解决人字段优化
**之前：**
- 新建页：点击"选择解决人"按钮 → 弹出选择器 → 显示带头像的标签
- 编辑页：点击"添加解决人"按钮 → 弹出选择器 → 显示带头像的标签

**现在：**
- 新建页和编辑页：直接使用下拉选择框（单一选择）
- 简化了操作流程，与发起人字段保持一致的交互方式
- 去除了 `CollaboratorSelector` 组件的使用

### 2. 公开性字段改进
**之前：**
- 使用复选框："公开问题（所有人可见）"

**现在：**
- 使用单选框，三个选项：
  - **团队公开** - 团队成员可见
  - **所有人公开** - 所有人可见
  - **不公开** - 仅创建人和解决人可见

### 3. 字段布局优化
- ✅ 相关字段并排显示，减少垂直滚动
- ✅ 必填字段清晰标注
- ✅ 字段顺序符合用户填写逻辑

## ⚠️ 注意事项

1. **问题解决人现在是单一选择**
   - 数据库中 `solvers` 字段仍然是数组
   - 但前端只允许选择一个解决人
   - 在 `validateForm` 中已添加验证：`solvers.length > 1` 会报错

2. **公开性字段变更**
   - 新增了 `publicType` 状态管理
   - 目前只使用 `isPublic` 存储到数据库（true/false）
   - 后续如需支持"团队公开"，需要扩展数据库字段

3. **未移除的导入**
   - `CollaboratorSelector` 组件虽然不再使用，但导入语句暂时保留
   - `UserPlus` 图标不再使用，但导入语句暂时保留
   - 后续可以清理这些未使用的导入
