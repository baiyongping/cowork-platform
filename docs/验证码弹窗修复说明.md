# 验证码弹窗修复说明

## 问题描述

用户在注册时点击"发送验证码"按钮后，没有弹出验证码提示窗口。

## 问题原因

在 `lib/auth-service.ts` 中的 `sendVerificationCode` 函数，开发环境下验证码发送成功时使用的是 `console.info()` 而不是 `alert()`，导致验证码只在控制台输出，用户看不到。

**原代码**:
```typescript
if (process.env.NODE_ENV === 'development') {
  console.info(`开发环境验证码: ${code}`);  // ❌ 只在控制台输出
}
```

## 修复方案

将 `console.info()` 改为 `alert()`，并使用 `setTimeout` 确保在UI更新后显示弹窗。

**修复后代码**:
```typescript
if (process.env.NODE_ENV === 'development') {
  // 使用setTimeout确保在UI更新后显示alert
  setTimeout(() => {
    alert(`📱 验证码: ${code}\n\n（开发环境提示，生产环境将通过短信发送）`);
  }, 100);
}
```

## 技术细节

### 为什么使用 setTimeout?

```typescript
setTimeout(() => {
  alert(message);
}, 100);
```

**原因**:
- `alert()` 会阻塞JavaScript执行
- 如果立即调用，可能会阻止UI状态更新（如按钮loading状态）
- 使用 `setTimeout` 延迟100ms，确保UI先更新，再显示弹窗
- 提升用户体验，避免界面"卡住"的感觉

### 开发环境 vs 生产环境

| 环境 | 验证码来源 | 用户体验 |
|------|-----------|---------|
| **开发环境** | alert弹窗 | 弹窗显示验证码，方便测试 |
| **生产环境** | 真实短信 | 用户手机收到短信验证码 |

**环境检测**:
```typescript
if (process.env.NODE_ENV === 'development') {
  // 开发环境特殊处理
}
```
