# 创建问题时解决方式和解决结果字段只读说明

**版本**: v1.0.0  
**日期**: 2025-12-29  
**状态**: ✅ 完成

---

## 📋 需求说明

**核心要求**：在**创建问题**时，`解决方式` 和 `解决结果` 字段应该是**只读（禁用）状态**，不允许操作者或创建者编辑。

**原因**：
- 这两个字段属于**问题解决阶段**的信息
- 应该由**问题解决人**在处理问题时填写
- 创建问题时无需填写这些字段

---

## ✅ 实现方案

### 1. **创建问题模态框（CreateIssueModal）**

#### 字段状态
- ✅ `解决方式` 字段：**禁用（disabled）**

- ✅ 使用 `checkIssuePermission` 函数检查权限

## 🔧 技术细节

### TypeScript 类型定义
```typescript
interface CreateIssueDto {
  solution?: IssueSolution; // 可选字段
  result?: IssueResult; // 可选字段
  // ... 其他字段
}

type IssueSolution = '自己解决' | '协同解决' | '他人解决' | '部门解决' | '外部解决';
type IssueResult = '已解决' | '部分解决' | '未解决' | '待确认' | '无需解决' | '未确定';
```

### 权限检查函数
```typescript
// utils/permission.ts
export function checkIssuePermission(userId: string, issue: Issue) {
  const isAdmin = currentUser?.role === 'admin';
  const isOwner = issue.owner?._id === userId;
  const isSolver = issue.solvers?.some(s => s._id === userId);

  return {
    canEditDetails: isOwner || isSolver || isAdmin,
    canEditSolution: isSolver || isAdmin, // 只有解决人和管理员可以编辑
  };
}
```
