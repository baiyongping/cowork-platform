# 问题管理功能说明

## 功能概述

问题管理功能旨在提升团队沟通效率,通过系统化的问题跟踪和解决机制,保障任务推进的顺畅性。

### 设计理念

- **任务驱动**: 通过任务管理驱动目标完成
- **问题保障**: 通过问题管理保障任务推进
- **协同解决**: 促进团队协作,快速解决阻碍

## 功能特点

### 1. 问题分类管理

- **级别分类**: 公司级、团队级、个人级
  - 公司级: 影响全公司的重大问题
  - 团队级: 影响团队协作的问题
  - 个人级: 个人工作中的具体问题

- **类型分类**: 从系统设置中动态获取
  - 默认类型: 技术问题、流程问题、资源问题、沟通问题、质量问题、进度问题、其他
  - 可在"系统设置 → 状态设置 → 问题类型"中自定义

- **优先级**: 低、中、高、紧急
  - 帮助团队快速识别需要优先处理的问题

### 2. 问题生命周期管理

#### 状态流转

从系统设置中动态获取问题状态,默认包括:

1. **未开始**: 问题已记录,待开始处理
2. **进行中**: 正在处理中
3. **已完成**: 问题已解决
4. **延期**: 问题处理时间延期
5. **取消**: 问题取消不再处理
6. **暂停**: 问题处理暂停

#### 进度跟踪

- 支持0-100%的进度跟踪
- 实时更新问题解决进度
- 可视化进度条展示

### 3. 协同功能

#### 负责人与协同人

- **负责人**: 问题的主要责任人
- **协同人**: 参与问题解决的团队成员
- 支持多人协同解决问题

#### 评论交流

- 问题详情中支持评论
- 实时沟通问题处理进展
- @提及功能(待开发)

### 4. 与任务关联

- 可以关联到具体任务
- 帮助识别任务推进中的障碍
- 统计任务相关问题数量

### 5. 数据统计

#### 基础统计

- 问题总数
- 进行中问题数
- 已完成问题数
- 延期问题数

#### 筛选查询

- 按级别筛选
- 按类型筛选
- 按关键词搜索

### 6. 回收站功能

- 软删除机制
- 支持恢复误删除的问题
- 支持永久删除

## 使用场景

### 场景1: 任务推进受阻

当任务执行过程中遇到阻碍时:

1. 创建问题,选择"进度问题"类型
2. 关联到受阻的任务
3. 指定负责人和协同人
4. 设置优先级为"高"或"紧急"
5. 通过评论跟进解决进展

### 场景2: 技术难题

遇到技术难题时:

1. 创建问题,选择"技术问题"类型
2. 详细描述问题现象和已尝试的方案
3. 添加技术专家为协同人
4. 通过评论讨论解决方案
5. 更新解决进度

### 场景3: 跨部门协作问题

跨部门协作中的沟通问题:

1. 创建问题,选择"沟通问题"或"流程问题"
2. 设置级别为"团队级"或"公司级"
3. 添加相关部门负责人为协同人
4. 通过评论澄清责任和流程
5. 达成共识后解决问题

## 权限控制

### 查看权限

- **公司级问题**: 所有人可见
- **团队级问题**: 团队成员可见
- **个人级问题**: 负责人、协同人和管理员可见

### 操作权限

- **创建**: 所有用户
- **编辑**: 负责人、创建人和管理员
- **删除**: 创建人和管理员
- **评论**: 有查看权限的用户

## 配置管理

### 初始化问题类型

首次使用前,需要初始化问题类型配置:

```bash
npm run init-issue-types
```

这将创建:
- 问题类型配置(issueType)
- 问题状态配置(issueStatus)
- 问题优先级配置(issuePriority)

### 自定义类型

管理员可以在"系统设置 → 状态设置"中:

1. 添加新的问题类型
2. 修改问题状态
3. 调整问题优先级
4. 启用/禁用特定类型

## 最佳实践

### 1. 及时记录

- 发现问题时立即记录
- 不要等到问题扩大再处理

### 2. 明确责任

- 每个问题必须有明确的负责人
- 复杂问题添加协同人

### 3. 定期跟进

- 每天查看进行中的问题
- 及时更新问题状态和进度

### 4. 经验总结

- 问题解决后在评论中记录解决方案
- 相似问题可以参考历史记录

### 5. 分级处理

- 根据优先级和级别合理分配资源
- 紧急问题优先处理

## 常见问题

### Q: 问题类型如何自定义?

A: 在"系统设置 → 状态设置"中找到"问题类型",可以添加、修改或禁用类型。

### Q: 如何批量处理问题?

A: 当前版本暂不支持批量操作,计划在后续版本中添加。

### Q: 问题删除后可以恢复吗?

A: 可以。问题删除后会进入回收站,30天内可以恢复,超过30天会自动永久删除。

### Q: 问题通知如何设置?

A: 当前版本的通知功能正在开发中,计划支持:
- 问题指派通知
- 问题状态变更通知
- @提及通知
- 评论回复通知

## 总结

问题管理功能是任务管理的重要补充,通过系统化的问题跟踪和协同解决机制,帮助团队:

1. **快速发现**: 及时记录工作中的问题
2. **明确责任**: 清晰的责任人和协同人
3. **协同解决**: 团队协作解决复杂问题
4. **经验积累**: 建立问题解决知识库
5. **提升效率**: 减少因问题导致的任务延期

正确使用问题管理功能,将显著提升团队的执行效率和沟通质量。
