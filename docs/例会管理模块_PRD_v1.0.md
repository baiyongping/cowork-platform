## 1. 模块概述

### 1.1 功能定位

**例会管理模块**是际华协同办公平台的**执行驱动引擎**，通过周例会和月度例会，建立**"目标→措施→任务→商机/项目"**的执行闭环，确保战略目标通过定期复盘和问题解决落地执行。

**核心价值**:
- 🎯 **驱动目标达成**: 通过定期回顾季度目标和措施，确保战略执行不偏航
- ✅ **推动任务完成**: 周/月任务回顾和计划，形成执行压力和动力
- 🔍 **聚焦重点业务**: 重点商机和项目专项分析，资源聚焦关键业务
- 🛠️ **问题快速解决**: 问题专栏机制，确保阻碍及时消除

### 1.2 业务背景

**现状问题**:
- ❌ 任务执行缺乏定期回顾，延期任务无人跟进
- ❌ 季度目标只有年初制定，缺乏过程监控
- ❌ 商机和项目推进问题无处反馈，进展缓慢
- ❌ 团队协作问题积压，缺乏解决机制

**解决方案**:
```
周例会（团队级/公司级）
    ↓ 驱动
上周任务回顾 + 下周任务计划
    ↓ 聚焦
重点商机分析 + 重点项目分析
    ↓ 解决
问题专栏问题集中讨论
    ↓ 输出
会议纪要（自动生成）
```

### 1.3 与现有模块的关系

**核心定位**: 例会管理是**"执行监督层"**，连接战略层（目标管理）和执行层（任务/商机/项目管理）

```
目标管理 (战略层)
    ↓ 提供数据
例会管理 (执行监督层)
    ↓ 驱动执行
任务管理 + 商机管理 + 项目管理 (执行层)
```

**数据流向**:
```
例会召开前:
  目标管理 → 季度目标数据 → 例会内容
  任务管理 → 上周/月任务 → 例会内容
  商机管理 → 重点商机 → 例会内容
  项目管理 → 重点项目 → 例会内容
  问题专栏 → 待解决问题 → 例会内容

例会召开后:
  例会决议 → 新增任务 → 任务管理
  问题解决方案 → 更新问题 → 问题专栏
  会议纪要 → 存档 → 例会纪要
```

## 2. 功能架构

### 2.1 子功能组成

```
例会管理 (Meeting Management)
│
├── 📅 例会召开 (Meeting Schedule)
│   ├── 新建例会
│   ├── 例会类型（周例会/月例会）
│   ├── 例会级别（团队级/公司级）
│   ├── 参会人管理
│   ├── 会议内容配置
│   └── 会议状态管理
│
├── 📝 例会纪要 (Meeting Minutes)
│   ├── 自动生成纪要
│   ├── 纪要编辑和审核
│   ├── 纪要查询和筛选
│   ├── 纪要导出（Word/PDF）
│   └── 纪要归档
│
└── 🔧 问题专栏 (Issue Board)
    ├── 问题提交
    ├── 问题分类和优先级
    ├── 问题解决人指定
    ├── 问题状态流转
    ├── 问题升级到例会
    └── 问题解决跟踪
```

### 2.2 Tab页签设计

**例会管理模块界面**采用Tab切换设计:

| Tab顺序 | Tab名称 | 对应页面 | 核心功能 |
|--------|---------|---------|---------|
| 1 | 例会召开 | MeetingScheduleView | 新建例会、例会列表、例会详情 |
| 2 | 例会纪要 | MeetingMinutesView | 纪要查询、编辑、导出 |
| 3 | 问题专栏 | IssueBoardView | 问题提交、跟踪、解决 |

**默认Tab**: 例会召开

## 3. 子功能详细设计

### 3.1 例会召开 (Meeting Schedule)

**功能定位**: 例会管理的**核心功能**，负责例会的创建、内容配置、召开和状态管理。

#### 3.1.1 新建例会

**数据结构**:
```typescript
interface Meeting {
  _id?: string;
  
  // 基本信息
  meetingType: '周例会' | '月例会';           // 例会类型
  meetingLevel: '团队级' | '公司级';          // 例会级别
  
  // 会议信息
  meetingName: string;                       // 会议名称（自动生成或手动输入）
                                             // 如："2025年第1周团队周例会"
  meetingTime: Date;                         // 会议时间
  meetingLocation: string;                   // 会议地点（线下/线上会议室链接）
  duration: number;                          // 预计时长（分钟）
  
  // 人员信息
  host: string;                              // 主持人ID
  hostName?: string;                         // 主持人姓名
  participants: string[];                    // 参会人ID数组
  participantNames?: string[];               // 参会人姓名数组
  requiredParticipants?: string[];           // 必须参加的人员
  optionalParticipants?: string[];           // 可选参加的人员
  
  // 会议内容
  agenda: MeetingAgenda;                     // 会议议程
  
  // 状态管理
  status: '待召开' | '进行中' | '已结束' | '已取消';
  
  // 关联信息
  teamId?: string;                           // 团队ID（团队级例会）
  teamName?: string;                         // 团队名称
  
  // 会议产出
  minutesId?: string;                        // 关联的会议纪要ID
  tasksCreated?: string[];                   // 会后新建的任务ID数组
  issuesResolved?: string[];                 // 会上解决的问题ID数组
  
  // 元数据
  createdBy: string;
  createdAt: Date;
  updatedAt: Date;
}

// 会议议程
interface MeetingAgenda {
  // 1. 季度目标回顾（月例会必选，周例会可选）
  goalReview?: {
    enabled: boolean;
    quarterlyGoals: string[];                // 选定的季度目标ID
    quarterlyMeasures: string[];             // 选定的季度措施ID
  };
  
  // 2. 上周/月任务回顾
  taskReview: {
    enabled: boolean;
    period: {                                // 回顾周期
      startDate: Date;
      endDate: Date;
    };
    tasks: string[];                         // 选定的任务ID（提前选出）
    reviewType: '团队任务' | '个人任务' | '全部';
  };
  
  // 3. 下周/月工作计划
  workPlan: {
    enabled: boolean;
    period: {                                // 计划周期
      startDate: Date;
      endDate: Date;
    };
    plannedTasks: string[];                  // 计划完成的任务ID
    newTasksToCreate: {                      // 待新建的任务（会后创建）
      name: string;
      assignee: string;
      deadline: Date;
    }[];
  };
  
  // 4. 重点商机分析
  opportunityAnalysis?: {
    enabled: boolean;
    opportunities: string[];                 // 选定的商机ID
    focusPoints: string[];                   // 关注要点（如"签约进度"、"客户需求"）
  };
  
  // 5. 重点项目分析
  projectAnalysis?: {
    enabled: boolean;
    projects: string[];                      // 选定的项目ID
    focusPoints: string[];                   // 关注要点（如"进度偏差"、"资源需求"）
  };
  
  // 6. 问题解决
  issueResolution?: {
    enabled: boolean;
    issues: string[];                        // 从问题专栏选出的问题ID
    urgentIssues: string[];                  // 紧急问题ID（优先讨论）
  };
}
```

### 3.2 例会纪要 (Meeting Minutes)

**功能定位**: 会议产出的**正式文档**，记录会议讨论内容、决议事项、待办任务，支持查询、编辑、审核、导出。

#### 3.2.1 数据结构

```typescript
interface MeetingMinutes {
  _id?: string;
  
  // 关联信息
  meetingId: string;                         // 关联的例会ID
  meetingName: string;                       // 会议名称
  meetingTime: Date;                         // 会议时间
  
  // 基本信息
  minutesTitle: string;                      // 纪要标题（如"2025年第52周团队周例会纪要"）
  minutesNumber?: string;                    // 纪要编号（如"2025-W52-001"）
  
  // 会议信息
  host: string;                              // 主持人
  hostName?: string;
  participants: string[];                    // 实际参会人
  participantNames?: string[];
  absentees?: string[];                      // 缺席人员
  absenteeNames?: string[];
  
  // 纪要内容
  content: MinutesContent;
  
  // 状态管理
  status: '草稿' | '待审核' | '已审核' | '已发布';
  
  // 审核信息
  reviewer?: string;                         // 审核人
  reviewerName?: string;
  reviewTime?: Date;
  reviewComments?: string;                   // 审核意见
  
  // 分发范围
  recipients?: string[];                     // 抄送人员
  recipientNames?: string[];
  
  // 附件
  attachments?: {
    fileName: string;
    fileUrl: string;
    fileSize: number;
  }[];
  
  // 元数据
  createdBy: string;
  createdAt: Date;
  updatedAt: Date;
  publishedAt?: Date;                        // 发布时间
}

// 纪要内容
interface MinutesContent {
  // 会议概况
  summary: string;                           // 会议概要
  
  // 1. 季度目标回顾（如果有）
  goalReview?: {
    quarterlyGoals: {
      goalId: string;
      goalName: string;
      progress: number;                      // 完成进度
      discussion: string;                    // 讨论要点
    }[];
    measures: {
      measureId: string;
      measureName: string;
      progress: number;
      status: string;
      discussion: string;
    }[];
  };
  
  // 2. 任务回顾
  taskReview: {
    completedTasks: {
      taskId: string;
      taskName: string;
      assignee: string;
      completionRate: number;
      highlights?: string;                   // 亮点
    }[];
    delayedTasks: {
      taskId: string;
      taskName: string;
      assignee: string;
      reason: string;                        // 延期原因
      solution: string;                      // 解决方案
      newDeadline?: Date;                    // 新截止日期
    }[];
  };
  
  // 3. 工作计划
  workPlan: {
    plannedTasks: {
      taskId: string;
      taskName: string;
      assignee: string;
      deadline: Date;
      priority: string;
    }[];
    newTasks: {
      taskName: string;
      assignee: string;
      deadline: Date;
      description?: string;
    }[];
  };
  
  // 4. 商机分析（如果有）
  opportunityAnalysis?: {
    opportunities: {
      oppId: string;
      oppName: string;
      customer: string;
      amount: number;
      stage: string;
      discussion: string;                    // 讨论内容
      actionItems: string[];                 // 行动事项
    }[];
  };
  
  // 5. 项目分析（如果有）
  projectAnalysis?: {
    projects: {
      projectId: string;
      projectName: string;
      phase: string;
      progress: number;
      discussion: string;
      actionItems: string[];
    }[];
  };
  
  // 6. 问题解决
  issueResolution?: {
    resolvedIssues: {
      issueId: string;
      issueTitle: string;
      solution: string;                      // 解决方案
      assignee: string;                      // 负责人
      deadline: Date;                        // 解决期限
    }[];
    escalatedIssues: {
      issueId: string;
      issueTitle: string;
      reason: string;                        // 升级原因
      escalateTo: string;                    // 升级给谁
    }[];
  };
  
  // 7. 决议事项
  resolutions: {
    item: string;                            // 决议内容
    assignee: string;                        // 负责人
    deadline: Date;                          // 完成期限
    status: '待执行' | '执行中' | '已完成';
  }[];
  
  // 8. 其他事项
  otherMatters?: string;
}
```

### 3.3 问题专栏 (Issue Board)

**功能定位**: **全员问题反馈和解决平台**，任何人都可以提交工作中遇到的问题，通过指定解决人或升级到例会的方式快速解决。

#### 3.3.1 数据结构

```typescript
interface Issue {
  _id?: string;

  title: string;                             // 问题标题

  category: string;                          // 问题分类
                                             // 如: "技术问题"、"流程问题"、"资源问题"、"协作问题"
  
  // 优先级
  priority: '紧急' | '重要' | '一般' | '低';

  relatedType?: '商机' | '项目' | '任务' | '其他';

  submitterName?: string;
  assignee?: string;                         // 指定解决人ID
  assigneeName?: string;
  actualResolver?: string;                   // 实际解决人ID（可能在例会上由他人解决）

  escalatedToMeeting?: boolean;              // 是否升级到例会

  meetingName?: string;
  escalationReason?: string;                 // 升级原因
  
  // 进展记录
  progressLog?: {
    timestamp: Date;
    operator: string;
    operatorName?: string;
    action: string;                          // 如"更新状态"、"添加评论"、"指定解决人"

  comments?: {
    commentId: string;

  }[];
  
  // 附件
  attachments?: {
    fileName: string;
    fileUrl: string;
    fileSize: number;
  }[];
  
  // 元数据

  createdAt: Date;
  updatedAt: Date;
```

## 4. 数据模型

### 4.1 集合列表

| 集合名称 | 用途 | 关键字段 |
|---------|------|---------|
| `meetings` | 例会信息 | meetingType, meetingLevel, status, agenda |
| `meeting_minutes` | 会议纪要 | meetingId, content, status |
| `issues` | 问题专栏 | title, priority, status, assignee, escalatedToMeeting |

### 4.2 集合关联关系

```
meetings (例会)
    ├── 1:1 → meeting_minutes (纪要)
    ├── N:N → tasks (任务)
    ├── N:N → opportunities (商机)
    ├── N:N → projects (项目)
    ├── N:N → quarterly_goals (季度目标)
    ├── N:N → quarterly_measures (季度措施)
    └── N:N → issues (问题)

meeting_minutes (纪要)
    ├── N:1 → meetings (例会)
    └── N:N → tasks (决议事项关联的任务)

issues (问题)
    ├── N:1 → users (提交人)
    ├── N:1 → users (解决人)
    ├── N:1 → meetings (升级到的例会)
    └── N:1 → opportunities/projects/tasks (关联业务)
```

## 6. 权限控制

### 6.1 权限模块定义

```
meeting (例会管理)
  ├── meeting.schedule (例会召开)
  ├── meeting.minutes (例会纪要)
  └── meeting.issue (问题专栏)
```

### 6.2 角色权限矩阵

| 角色 | 例会召开 | 例会纪要 | 问题专栏 |
|------|---------|---------|---------|
| **系统管理员** | 全部 | 全部 | 全部 |
| **总经理** | 创建公司级+查看全部 | 审核+编辑+查看全部 | 查看全部+处理 |
| **部门经理** | 创建团队级+查看本团队 | 编辑本团队+查看全部 | 查看全部+处理 |
| **员工** | 查看参与的例会 | 查看参与的纪要 | 提交+查看+处理指定给自己的 |

### 6.3 数据权限

**例会数据权限**:
- 公司级例会: 所有人可见
- 团队级例会: 只有团队成员可见
- 参会人: 可编辑会议内容（会前）

**纪要数据权限**:
- 主持人: 可编辑纪要
- 总经理: 可审核所有纪要
- 部门经理: 可审核本团队纪要
- 参会人: 可查看纪要

**问题数据权限**:
- 提交人: 可编辑、关闭自己提交的问题
- 解决人: 可更新状态、添加解决方案
- 管理层: 可查看所有问题

## 7. 业务流程

### 7.1 周例会流程

```
每周固定时间（如周一下午）
    ↓
会前准备（提前1天）
    ├─ 创建例会
    ├─ 选择上周任务（自动提取上周任务）
    ├─ 选择下周计划任务
    ├─ 选择重点商机/项目
    └─ 选择待解决问题
    ↓
发送会议通知
    ↓
会议召开
    ├─ 上周任务回顾（重点关注延期任务）
    ├─ 下周工作计划（明确任务和负责人）
    ├─ 重点商机分析（跟进策略）
    ├─ 重点项目分析（进度和风险）
    └─ 问题解决（集中解决问题）
    ↓
会议结束 → 自动生成纪要
    ↓
主持人编辑纪要
    ↓
提交审核 → 部门经理审核
    ↓
发布纪要 → 通知相关人员
    ↓
执行决议事项（纳入任务管理）
```

### 7.2 月度例会流程

```
每月最后一周（如月底周五）
    ↓
会前准备（提前3天）
    ├─ 创建例会
    ├─ 回顾季度目标和措施
    ├─ 选择本月任务（团队级+个人级）
    ├─ 选择下月计划任务
    ├─ 选择重点商机/项目（金额大、周期长）
    └─ 选择重要问题（升级问题）
    ↓
发送会议通知（提前2天）
    ↓
会议召开（时间较长，2-3小时）
    ├─ 季度目标回顾（进度和偏差分析）
    ├─ 本月任务回顾（整体完成情况）
    ├─ 下月工作计划（月度重点工作）
    ├─ 重点商机分析（大客户、大订单）
    ├─ 重点项目分析（关键项目）
    └─ 重大问题解决（跨部门问题）
    ↓
会议结束 → 自动生成纪要
    ↓
主持人编辑纪要
    ↓
提交审核 → 总经理审核
    ↓
发布纪要 → 全员通知
    ↓
执行决议事项 → 跨部门协作
```

### 7.3 问题升级流程

```
员工提交问题
    ↓
指定解决人
    ↓
解决人尝试解决
    ├─ 成功 → 更新状态为"已解决"
    └─ 失败/超出权限
        ↓
        升级到例会
        ↓
        例会讨论
            ├─ 分析原因
            ├─ 制定方案
            └─ 明确负责人和期限
        ↓
        纪要记录决议
        ↓
        会后执行
        ↓
        更新问题状态
```

## 8. 集成方案

### 8.1 与目标管理集成

**数据流向**:
```
目标管理 (季度目标和措施)
    ↓ 提供数据
例会管理 (季度目标回顾)
    ↓ 驱动
任务管理 (季度措施关联的团队任务)
```

**集成点**:
- 月例会自动提取当前季度目标和措施
- 显示目标完成进度和偏差
- 支持在例会上调整措施和任务

### 8.2 与任务管理集成

**数据流向**:
```
任务管理 (上周/月任务)
    ↓ 提供数据
例会管理 (任务回顾)
    ↓ 驱动
任务管理 (下周/月计划任务)
```

**集成点**:
- 自动提取指定周期的任务（按时间筛选）
- 支持在例会上标记延期任务的原因
- 会后自动创建下周/月计划任务

### 8.3 与商机管理集成

**数据流向**:
```
商机管理 (重点商机)
    ↓ 提供数据
例会管理 (商机分析)
    ↓ 驱动
商机管理 (跟进任务)
```

**集成点**:
- 自动筛选重点商机（按金额、阶段、风险）
- 在例会上讨论商机跟进策略
- 会后创建商机跟进任务

### 8.4 与项目管理集成

**数据流向**:
```
项目管理 (重点项目)
    ↓ 提供数据
例会管理 (项目分析)
    ↓ 驱动
项目管理 (项目任务)
```

**集成点**:
- 自动筛选重点项目（按金额、阶段、风险）
- 在例会上讨论项目进度和问题
- 会后创建项目任务
