## 核心组件

### 1. PermissionButton - 权限按钮

自动根据权限显示/隐藏/禁用按钮。

**Props:**
- `currentUser` - 当前登录用户
- `module` - 模块key（如: 'tasks', 'opportunities'）
- `action` - 操作类型（'create' | 'edit' | 'delete' | 'export' | 'import'）
- `dataItem` - 数据项（编辑/删除按钮需要）
- `hideWhenNoPermission` - 无权限时是否隐藏（默认true）
- `disableWhenNoPermission` - 无权限时是否禁用（默认true）

**示例:**

```tsx
import { PermissionButton } from '@/components/PermissionButton';

// 创建按钮（只需要功能权限）
<PermissionButton
  currentUser={currentUser}
  module="tasks"
  action="create"
  onClick={handleCreate}
>
  新建任务
</PermissionButton>

// 编辑按钮（需要功能权限 + 数据权限）
<PermissionButton
  currentUser={currentUser}
  module="tasks"
  action="edit"
  dataItem={task}
  onClick={handleEdit}
  variant="outline"
>
  编辑
</PermissionButton>

// 删除按钮
<PermissionButton
  currentUser={currentUser}
  module="tasks"
  action="delete"
  dataItem={task}
  onClick={handleDelete}
  variant="destructive"
>
  删除
</PermissionButton>
```

### 2. PermissionWrapper - 权限容器

包裹任意元素,根据权限显示/隐藏。

**Props:**
- `currentUser` - 当前登录用户
- `module` - 模块key
- `action` - 操作类型
- `hideWhenNoPermission` - 无权限时是否隐藏（默认true）
- `fallback` - 无权限时显示的内容

**示例:**

```tsx
import { PermissionWrapper } from '@/components/PermissionButton';

// 隐藏整个操作区域
<PermissionWrapper
  currentUser={currentUser}
  module="tasks"
  action="edit"
>
  <div className="flex gap-2">
    <button>编辑</button>
    <button>删除</button>
  </div>
</PermissionWrapper>

// 无权限时显示提示
<PermissionWrapper
  currentUser={currentUser}
  module="tasks"
  action="export"
  hideWhenNoPermission={false}
  fallback={<span className="text-gray-400">无导出权限</span>}
>
  <button>导出数据</button>
</PermissionWrapper>
```

### 3. PermissionRoute - 路由守卫

自动检查路由访问权限。

**Props:**
- `currentUser` - 当前登录用户
- `path` - 路由路径
- `redirectTo` - 无权限时跳转的路径（默认'/403'）
- `fallback` - 无权限时显示的内容

**示例:**

```tsx
import { PermissionRoute } from '@/components/PermissionRoute';

// 在路由配置中使用
<Route 
  path="/tasks" 
  element={
    <PermissionRoute currentUser={currentUser} path="/tasks">
      <TasksPage />
    </PermissionRoute>
  } 
/>

// 自定义无权限页面
<Route 
  path="/system" 
  element={
    <PermissionRoute 
      currentUser={currentUser} 
      path="/system"
      fallback={<CustomNoPermissionPage />}
    >
      <SystemPage />
    </PermissionRoute>
  } 
/>
```

### 4. usePermissionContext - 权限Hook

在组件中直接使用权限检查函数。

**返回值:**
- `checkPermission(module, action)` - 检查功能权限
- `checkViewPermission(dataItem)` - 检查查看权限
- `checkEditPermission(dataItem)` - 检查编辑权限
- `checkDeletePermission(dataItem)` - 检查删除权限
- `filterData(dataList)` - 过滤可访问的数据
- `attachPermissions(dataList)` - 为数据附加权限标识
- `checkRoutePermission(path)` - 检查路由权限
- `filterMenus(allMenus)` - 过滤可访问的菜单

**示例:**

```tsx
import { usePermissionContext } from '@/contexts/PermissionContext';

function TaskList() {
  const { 
    checkPermission, 
    filterData, 
    attachPermissions 
  } = usePermissionContext();

  // 检查是否有创建权限
  const canCreate = checkPermission('tasks', 'create');

  // 过滤用户可访问的任务
  const accessibleTasks = filterData(allTasks);

  // 为任务列表附加权限标识
  const tasksWithPermissions = attachPermissions(allTasks);

  return (
    <div>
      {canCreate && (
        <button onClick={handleCreate}>新建任务</button>
      )}
      
      {tasksWithPermissions.map(task => (
        <div key={task._id}>
          <h3>{task.name}</h3>
          {task.canEdit && <button>编辑</button>}
          {task.canDelete && <button>删除</button>}
        </div>
      ))}
    </div>
  );
}
```

### 5. withPermission - 权限HOC

高阶组件,为组件添加权限检查。

**示例:**

```tsx
import { withPermission } from '@/contexts/PermissionContext';

// 原始组件
function TaskExportPanel() {
  return <div>导出任务数据...</div>;
}

// 添加权限检查
export default withPermission(TaskExportPanel, {
  module: 'tasks',
  action: 'export',
  fallback: () => <div>您没有导出权限</div>
});
```

## 使用示例

### 示例1: 任务列表页面

```tsx
import React, { useState, useEffect } from 'react';
import { PermissionButton } from '@/components/PermissionButton';
import { usePermissionContext } from '@/contexts/PermissionContext';

function TaskListPage() {
  const [tasks, setTasks] = useState([]);
  const { filterData, attachPermissions } = usePermissionContext();
  const currentUser = useCurrentUser(); // 假设有这个hook

  useEffect(() => {
    loadTasks();
  }, []);

  const loadTasks = async () => {
    const allTasks = await fetchTasks();
    
    // 过滤用户可访问的任务
    const accessibleTasks = filterData(allTasks);
    
    // 附加权限标识
    const tasksWithPerms = attachPermissions(accessibleTasks);
    
    setTasks(tasksWithPerms);
  };

  return (
    <div>
      <div className="mb-4">
        <PermissionButton
          currentUser={currentUser}
          module="tasks"
          action="create"
          onClick={handleCreate}
        >
          新建任务
        </PermissionButton>
      </div>

      <table>
        <thead>
          <tr>
            <th>任务名称</th>
            <th>负责人</th>
            <th>状态</th>
            <th>操作</th>
          </tr>
        </thead>
        <tbody>
          {tasks.map(task => (
            <tr key={task._id}>
              <td>{task.name}</td>
              <td>{task.ownerName}</td>
              <td>{task.status}</td>
              <td>
                <PermissionButton
                  currentUser={currentUser}
                  module="tasks"
                  action="edit"
                  dataItem={task}
                  onClick={() => handleEdit(task)}
                  size="sm"
                  variant="outline"
                >
                  编辑
                </PermissionButton>
                
                <PermissionButton
                  currentUser={currentUser}
                  module="tasks"
                  action="delete"
                  dataItem={task}
                  onClick={() => handleDelete(task)}
                  size="sm"
                  variant="destructive"
                >
                  删除
                </PermissionButton>
              </td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  );
}
```

### 示例2: 菜单权限过滤

```tsx
import React from 'react';
import { usePermissionContext } from '@/contexts/PermissionContext';

function Sidebar() {
  const { filterMenus } = usePermissionContext();

  const allMenus = [
    {
      key: 'tasks',
      label: '任务管理',
      path: '/tasks',
      icon: 'TaskIcon'
    },
    {
      key: 'opportunities',
      label: '商机管理',
      path: '/opportunities',
      icon: 'OpportunityIcon'
    },
    {
      key: 'projects',
      label: '项目管理',
      path: '/projects',
      icon: 'ProjectIcon'
    },
    {
      key: 'system',
      label: '系统设置',
      path: '/system',
      icon: 'SettingsIcon',
      children: [
        {
          key: 'system-roles',
          label: '角色管理',
          path: '/system/roles'
        },
        {
          key: 'system-types',
          label: '类型管理',
          path: '/system/types'
        }
      ]
    }
  ];

  // 根据用户权限过滤菜单
  const accessibleMenus = filterMenus(allMenus);

  return (
    <nav>
      {accessibleMenus.map(menu => (
        <div key={menu.key}>
          <a href={menu.path}>{menu.label}</a>
          {menu.children && (
            <div className="sub-menu">
              {menu.children.map(child => (
                <a key={child.key} href={child.path}>
                  {child.label}
                </a>
              ))}
            </div>
          )}
        </div>
      ))}
    </nav>
  );
}
```

### 示例3: 详情页面权限控制

```tsx
import React, { useState, useEffect } from 'react';
import { useParams } from 'react-router-dom';
import { PermissionButton, PermissionWrapper } from '@/components/PermissionButton';
import { usePermissionContext } from '@/contexts/PermissionContext';

function TaskDetailPage() {
  const { id } = useParams();
  const [task, setTask] = useState(null);
  const { checkViewPermission } = usePermissionContext();
  const currentUser = useCurrentUser();

  useEffect(() => {
    loadTask();
  }, [id]);

  const loadTask = async () => {
    const taskData = await fetchTask(id);
    
    // 检查是否有查看权限
    if (!checkViewPermission(taskData)) {
      alert('您没有权限查看此任务');
      navigate('/tasks');
      return;
    }
    
    setTask(taskData);
  };

  if (!task) return <div>加载中...</div>;

  return (
    <div>
      <h1>{task.name}</h1>
      
      <div className="task-info">
        <p>负责人: {task.ownerName}</p>
        <p>状态: {task.status}</p>
        <p>进度: {task.progress}%</p>
      </div>

      {/* 操作按钮区域 */}
      <div className="actions">
        <PermissionButton
          currentUser={currentUser}
          module="tasks"
          action="edit"
          dataItem={task}
          onClick={handleEdit}
        >
          编辑任务
        </PermissionButton>

        <PermissionButton
          currentUser={currentUser}
          module="tasks"
          action="delete"
          dataItem={task}
          onClick={handleDelete}
          variant="destructive"
        >
          删除任务
        </PermissionButton>
      </div>

      {/* 高级功能区域（需要特定权限） */}
      <PermissionWrapper
        currentUser={currentUser}
        module="tasks"
        action="export"
      >
        <div className="advanced-section">
          <h2>数据导出</h2>
          <button onClick={handleExport}>导出任务数据</button>
        </div>
      </PermissionWrapper>
    </div>
  );
}
```

## 最佳实践

### 1. 统一使用PermissionProvider

在App根组件中使用`PermissionProvider`包裹,确保所有子组件都能访问权限上下文。

```tsx
<PermissionProvider currentUser={currentUser}>
  <App />
</PermissionProvider>
```

---

### 2. 优先使用组件而不是Hook

对于按钮和UI元素,优先使用`PermissionButton`和`PermissionWrapper`组件,而不是手动调用Hook。

✅ **推荐:**
```tsx
<PermissionButton module="tasks" action="create">
  新建
</PermissionButton>
```

❌ **不推荐:**
```tsx
const canCreate = checkPermission('tasks', 'create');
{canCreate && <button>新建</button>}
```

---

### 3. 服务端过滤 + 前端再检查

虽然前端已经有权限过滤,但服务端也应该做权限检查,前端权限只是UI控制。

```tsx
// 前端过滤显示
const accessibleTasks = filterData(allTasks);

// 服务端API也要检查权限
```

---

### 4. 数据权限与功能权限结合

编辑/删除按钮需要同时检查功能权限和数据权限。

```tsx
// 自动组合检查
<PermissionButton
  module="tasks"
  action="edit"
  dataItem={task}  // 提供dataItem会自动检查数据权限
/>
```

---

### 5. 性能优化

使用`useMemo`缓存权限检查结果,避免重复计算。

```tsx
const tasksWithPerms = useMemo(() => {
  return attachPermissions(tasks);
}, [tasks, currentUser]);
```

## 权限规则汇总

### 功能权限（F规则）
- **F-001**: 系统管理员拥有所有权限
- **F-002**: 总经理拥有所有业务模块权限
- **F-003**: 部门经理拥有部门级权限
- **F-004**: 普通员工只有基础权限

### 数据权限（D规则）
- **D-001**: 系统管理员可访问所有数据
- **D-002**: 总经理可访问所有业务数据
- **D-003**: 数据所有者有完全权限
- **D-004**: 参与者有查看权限
- **D-005**: 公开数据所有人可见
- **D-006**: 被锁定数据不能编辑/删除
- **D-007**: 部门经理可访问本部门数据

## 常见问题

### Q1: 权限检查失败怎么办?

**A:** 检查以下几点:
1. `PermissionProvider`是否正确配置
2. `currentUser`是否正确传递
3. 角色权限配置是否正确
4. 数据项是否包含必要的权限字段

---

### Q2: 如何调试权限问题?

**A:** 使用浏览器控制台:
```tsx
const { userPermissions } = usePermissionContext();
console.log('用户权限:', userPermissions);
console.log('检查结果:', checkPermission('tasks', 'create'));
```

---

### Q3: 无权限时如何友好提示?

**A:** 使用`fallback`或`hideWhenNoPermission={false}`:
```tsx
<PermissionWrapper
  module="tasks"
  action="export"
  hideWhenNoPermission={false}
  fallback={
    <div className="text-gray-400">
      ℹ️ 您没有导出权限,请联系管理员
    </div>
  }
>
  <ExportButton />
</PermissionWrapper>
```
