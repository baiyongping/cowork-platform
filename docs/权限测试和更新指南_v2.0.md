## ⚠️ 注意事项

### 1. 数据安全

- **备份数据**: 更新前建议备份 `roles` 集合
- **测试环境**: 建议先在测试环境验证
- **回滚方案**: 准备好回滚脚本

### 2. 权限冲突

- **保留现有权限**: 更新时只添加缺失的权限,不覆盖现有配置
- **管理员权限**: 确保管理员角色拥有所有权限
- **特殊角色**: 检查特殊角色的权限是否符合预期

### 3. 功能影响

更新后可能影响:
- **权限检查逻辑**: 前端权限判断
- **菜单显示**: 侧边栏菜单项
- **页面访问**: 路由权限控制

## 🔄 回滚方案

如果更新出现问题,可以执行回滚:

### 方式1: 手动回滚

1. 打开 CloudBase 控制台
2. 进入 `roles` 集合
3. 手动删除新增的权限字段

### 方式2: 脚本回滚

```javascript
// rollback-permissions.js
const db = app.database();

async function rollback() {
  const roles = await db.collection('roles').get();
  
  for (const role of roles.data) {
    const permissions = role.permissions;
    
    // 删除新增的权限
    if (permissions.goal) {
      delete permissions.goal.outcome;
      delete permissions.goal.decomposition;
      delete permissions.goal.executionMap;
      delete permissions.goal.dimensionSettings;
    }
    
    if (permissions.budget) {
      delete permissions.budget.cashFlow;
    }
    
    delete permissions.profile;
    
    await db.collection('roles').doc(role._id).update({
      permissions: permissions
    });
  }
}
```
