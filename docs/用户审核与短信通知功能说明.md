# 用户审核与短信通知功能说明

## 功能概述

优化了系统设置中的用户管理功能，实现了完整的用户注册审核流程，并在审核通过/拒绝时自动发送短信通知。

## 核心功能

### 1. 用户管理列表

**位置**: 系统设置 → 用户审核

**功能特性**:
- ✅ 显示所有系统用户（包括admin和已注册用户）
- ✅ 用户头像（自动生成首字母头像）
- ✅ 完整的用户信息展示：
  - 用户名、姓名
  - 角色、部门
  - 手机号、邮箱
  - 注册时间、上次登录时间
  - 审核状态、审核时间
- ✅ 多维度筛选：
  - 待审核
  - 已通过
  - 已拒绝
  - 全部
- ✅ 关键词搜索（支持用户名、姓名、手机号）
- ✅ 统计信息显示（总用户数）

### 2. 用户审核功能

#### 审核通过
1. 点击"通过"按钮
2. 确认审核操作
3. 系统自动：
   - 更新数据库状态为 `approved`
   - 记录审核人和审核时间
   - **发送短信通知用户**
4. 显示操作结果

**短信内容示例**:
```
【际华协同办公】尊敬的张三，您的注册申请已审核通过，现在可以登录系统了。如有疑问请联系管理员。
```

#### 审核拒绝
1. 点击"拒绝"按钮
2. 弹出对话框，填写拒绝原因（必填）
3. 确认拒绝操作
4. 系统自动：
   - 更新数据库状态为 `rejected`
   - 保存拒绝原因
   - 记录审核人和审核时间
   - **发送短信通知用户**
5. 显示操作结果

**短信内容示例**:
```
【际华协同办公】尊敬的张三，您的注册申请未通过审核。原因：信息不完整。如有疑问请联系管理员。
```

#### 重新审核
- 对于已拒绝的用户，可以点击"重新审核"按钮
- 重新审核通过后，会再次发送通过通知短信

### 3. 短信通知服务

**文件**: `lib/sms-service.ts`

#### 支持的短信类型
```typescript
enum SmsType {
  VERIFICATION_CODE = 'verification_code',  // 验证码
  APPROVAL_SUCCESS = 'approval_success',    // 审核通过
  APPROVAL_REJECT = 'approval_reject',      // 审核拒绝
  PASSWORD_RESET = 'password_reset',        // 密码重置
}
```

#### 核心API

**发送审核通过通知**:
```typescript
import { sendApprovalSuccessSms } from '@/lib/sms-service';

const result = await sendApprovalSuccessSms(phone, name);
// result: { success: boolean, message: string, messageId?: string }
```

**发送审核拒绝通知**:
```typescript
import { sendApprovalRejectSms } from '@/lib/sms-service';

const result = await sendApprovalRejectSms(phone, name, reason);
// result: { success: boolean, message: string, messageId?: string }
```

**发送验证码**:
```typescript
import { sendVerificationCodeSms } from '@/lib/sms-service';

const result = await sendVerificationCodeSms(phone, code);
```

#### 短信发送机制

**开发环境**:
- 使用模拟发送
- 短信内容输出到控制台
- 便于开发调试

**生产环境**:
- 需要集成腾讯云短信服务
- 配置 SecretId、SecretKey、AppId、签名、模板ID
- 详见 `sms-service.ts` 中的 `sendSmsViaTencentCloud` 函数

#### 短信记录
```typescript
// 查询短信发送历史
import { getSmsRecords } from '@/lib/sms-service';

const records = getSmsRecords(phone, 50); // 查询指定手机号的最近50条记录
```

## 完整流程

### 用户注册流程
```
1. 用户填写注册信息（含手机号）
   ↓
2. 接收短信验证码
   ↓
3. 验证码验证通过
   ↓
4. 创建用户，状态为 pending（待审核）
   ↓
5. 提示"注册成功，等待管理员审核"
```

### 管理员审核流程
```
1. 管理员登录系统
   ↓
2. 进入"用户审核"页面
   ↓
3. 查看待审核用户列表
   ↓
4. 点击"通过"或"拒绝"
   ↓
5. 系统更新数据库
   ↓
6. 自动发送短信通知用户
   ↓
7. 完成审核
```

### 用户登录流程
```
1. 输入用户名密码
   ↓
2. 系统检查审核状态
   ↓
3a. pending → 提示"账号正在审核中"
3b. rejected → 提示"账号审核未通过（原因：xxx）"
3c. approved → 允许登录
```

## 使用示例

### 审核用户（管理员）

```typescript
// 在 UserApprovalPage.tsx 中

// 审核通过
const handleApprove = async (user) => {
  // 1. 更新数据库
  await db.collection('users').doc(user._id).update({
    approvalStatus: 'approved',
    approvedBy: currentUser.userId,
    approvedAt: new Date()
  });
  
  // 2. 发送短信通知
  const smsResult = await sendApprovalSuccessSms(user.phone, user.name);
  
  // 3. 提示结果
  if (smsResult.success) {
    alert('审核通过成功！已发送短信通知。');
  }
};

// 审核拒绝
const handleReject = async (user, reason) => {
  // 1. 更新数据库
  await db.collection('users').doc(user._id).update({
    approvalStatus: 'rejected',
    approvedBy: currentUser.userId,
    approvedAt: new Date(),
    rejectReason: reason
  });
  
  // 2. 发送短信通知
  const smsResult = await sendApprovalRejectSms(user.phone, user.name, reason);
  
  // 3. 提示结果
  if (smsResult.success) {
    alert('审核拒绝成功！已发送短信通知。');
  }
};
```

## 测试步骤

### 1. 测试用户注册
1. 退出登录
2. 点击"注册"
3. 填写信息（含手机号）
4. 接收验证码（开发环境会弹窗显示）
5. 完成注册
6. 验证是否提示"等待管理员审核"

### 2. 测试审核通过
1. 使用admin账号登录
2. 进入"系统设置" → "用户审核"
3. 找到待审核用户
4. 点击"通过"按钮
5. 确认操作
6. **查看控制台是否显示短信发送日志**
7. 验证用户状态是否变为"已通过"

### 3. 测试审核拒绝
1. 找到另一个待审核用户
2. 点击"拒绝"按钮
3. 填写拒绝原因
4. 确认操作
5. **查看控制台是否显示短信发送日志**
6. 验证用户状态是否变为"已拒绝"
7. 验证是否显示拒绝原因

### 4. 测试重新审核
1. 找到已拒绝的用户
2. 点击"重新审核"按钮
3. 验证状态是否变为"已通过"
4. 验证是否再次发送通知短信

### 5. 测试登录限制
1. 退出登录
2. 使用待审核用户登录 → 应提示"账号正在审核中"
3. 使用已拒绝用户登录 → 应提示"账号审核未通过"

## 生产环境部署

### 集成腾讯云短信服务

1. **开通腾讯云短信服务**
   - 访问：https://console.cloud.tencent.com/smsv2
   - 创建应用、配置签名、创建模板

2. **配置环境变量**
   ```bash
   TENCENT_SMS_SECRET_ID=xxx
   TENCENT_SMS_SECRET_KEY=xxx
   TENCENT_SMS_APP_ID=xxx
   TENCENT_SMS_SIGN=际华协同办公
   ```

3. **修改 sms-service.ts**
   - 实现 `sendSmsViaTencentCloud` 函数
   - 替换 `sendSmsSimulated` 为真实发送

4. **配置短信模板**
   - 验证码模板：`您的验证码是：{1}，{2}分钟内有效`
   - 审核通过模板：`尊敬的{1}，您的注册申请已审核通过`
   - 审核拒绝模板：`尊敬的{1}，您的注册申请未通过审核。原因：{2}`

## 注意事项

1. **短信签名**: 需在腾讯云控制台配置并审核通过
2. **短信模板**: 需提前创建并审核通过
3. **费用控制**: 
   - 建议设置每日短信发送上限
   - 对同一手机号限制发送频率
4. **隐私保护**: 
   - 手机号脱敏显示（138****0001）
   - 短信内容不包含敏感信息
5. **异常处理**: 
   - 短信发送失败不影响审核操作
   - 记录发送失败日志便于排查
