# 数据丢失问题修复报告 - v3.5.3

## 📋 问题描述

**用户反馈**：营业收入、营业成本和毛利润三个一级科目的属性设置保存后，几分钟后就会回到初始状态。

**影响范围**：所有一级科目的属性配置（金额单位、系统参数、公式等）

---

## 🔍 根源分析

### 问题1: 保存时缺少`amountUnit`字段

**位置**: `handleSavePrimaryEdit` 函数 (1513-1520行)

**原因**: 在更新数据库时，`updateData`对象只包含了部分字段，**遗漏了`amountUnit`字段**：

```typescript
// ❌ 修复前 - 缺少amountUnit
const updateData = {
  name: updatedAccount.name,
  isSystemParam: updatedAccount.isSystemParam,
  totalUnit: updatedAccount.totalUnit,
  // ❌ 缺少 amountUnit
  formula: updatedAccount.formula,
  children: updatedAccount.children
};
```

**后果**: 
- 编辑保存后，`amountUnit`字段被数据库自动删除或重置为`undefined`
- 下次加载数据时，金额单位信息丢失
- 界面显示回到初始状态

### 问题2: 添加时也缺少`amountUnit`字段

**位置**: `handleAddPrimary` 函数 (1389-1400行)

**原因**: 创建新科目对象时，没有包含`amountUnit`字段：

```typescript
// ❌ 修复前 - 缺少amountUnit
const newAccount: PrimaryAccount = {
  id: `primary_${Date.now()}`,
  name: newAccountName.trim(),
  isSystemParam: newIsSystemParam,
  total: 0,
  totalUnit: newTotalUnit,
  // ❌ 缺少 amountUnit
  order: accounts.length,
  ...
};
```

**后果**:
- 新添加的科目从一开始就没有`amountUnit`字段
- 导致数据不完整

---

## ✅ 修复方案

### 修复1: 添加科目时包含`amountUnit`

```typescript
// ✅ 修复后
const newAccount: PrimaryAccount = {
  id: `primary_${Date.now()}`,
  name: newAccountName.trim(),
  isSystemParam: newIsSystemParam,
  total: 0,
  totalUnit: newTotalUnit,
  amountUnit: newAmountUnit, // ✅ 新增：保存金额单位
  order: accounts.length,
  children: showFormulaEditor ? [] : [],
  isExpanded: true,
  year: selectedYear,
  formula: showFormulaEditor ? newFormula : undefined
};
```

### 修复2: 编辑保存时包含`amountUnit`

```typescript
// ✅ 修复后
const updateData = {
  name: updatedAccount.name,
  isSystemParam: updatedAccount.isSystemParam,
  totalUnit: updatedAccount.totalUnit,
  amountUnit: updatedAccount.amountUnit, // ✅ 新增：保存金额单位
  formula: updatedAccount.formula,
  children: updatedAccount.children
};
```

3. **数据迁移**: 可选择运行数据迁移脚本统一修复

## 💡 经验总结

### 问题启示
1. **字段完整性**: 数据库保存时必须确保所有业务字段都被保存
2. **数据验证**: 添加和编辑时应使用相同的字段列表
3. **日志跟踪**: 保存时应打印完整的数据对象，便于调试

### 预防措施
1. **类型定义**: 严格使用TypeScript接口定义
2. **统一函数**: 抽取公共的数据构建函数
3. **单元测试**: 为关键数据操作添加测试用例
