## 🔧 技术细节

### 遇到的问题及解决方案

#### 问题1：CloudBase SDK 加载失败
- **原因**：HTML页面的CDN链接不稳定或版本不兼容
- **解决**：直接使用CloudBase工具API插入数据

#### 问题2：Node SDK 需要认证
- **原因**：`@cloudbase/node-sdk` 需要 secretId 和 secretKey
- **解决**：使用CloudBase工具API代替

#### 问题3：数据库权限
- **原因**：初始权限设置为PRIVATE，无法直接插入
- **解决**：临时设置为CUSTOM（允许读写）
