# 人力费用编辑按钮位置优化

## 📋 需求说明

将人力费用预算模块的"编辑"按钮从表格上方移至数据汇总栏的右侧，使操作更加便捷和直观。

## 🎨 设计方案

### 采用方案：右上角悬浮式按钮

将编辑/保存/取消按钮放置在预算汇总卡片的右上角，使用绝对定位实现悬浮效果。

**设计效果预览：**

```
┌────────────────────────────────────────────────────────────┐
│  [💰 年度预算总额]  [📊 实际支出总额]  [✅ 预算执行率]  [编辑] │
│   1,234.56万元      987.65万元         80.12%               │
└────────────────────────────────────────────────────────────┘
```

**编辑模式下：**

```
┌───────────────────────────────────────────────────────────────┐
│  [💰 年度预算总额]  [📊 实际支出总额]  [✅ 预算执行率]  [保存] [取消] │
│   1,234.56万元      987.65万元         80.12%                    │
└───────────────────────────────────────────────────────────────┘
```

## ✨ 设计优势

### 1. 视觉关联性强
- ✅ 编辑按钮与数据汇总在同一视觉区域
- ✅ 用户查看汇总数据时自然注意到操作按钮
- ✅ 符合"数据+操作"的常见布局模式

### 2. 操作便捷性
- ✅ 按钮位置固定，不会随内容滚动
- ✅ 编辑、保存、取消操作在同一位置
- ✅ 减少鼠标移动距离

### 3. 界面美观性
- ✅ 不破坏原有3列汇总数据的对称布局
- ✅ 按钮采用圆角设计，与卡片风格一致
- ✅ 使用阴影效果，增加按钮的视觉层次

### 4. 响应式设计
- ✅ 使用绝对定位，适应不同屏幕尺寸
- ✅ 按钮组自适应排列
- ✅ 保持良好的视觉平衡

## 🔧 技术实现

### 核心代码结构

```tsx
<div className="bg-gray-50 border border-gray-200 rounded-lg p-6 mb-4 relative">
  {/* 编辑/保存按钮组 - 右上角 */}
  <div className="absolute top-4 right-4 flex items-center gap-3">
    {isEditMode ? (
      <>
        <button onClick={...} className="...">保存</button>
        <button onClick={...} className="...">取消</button>
      </>
    ) : (
      <button onClick={...} className="...">编辑</button>
    )}
  </div>

  {/* 数据汇总内容 */}
  <div className="grid grid-cols-3 gap-6">
    ...
  </div>
</div>
```

### 关键样式说明

1. **父容器**：`relative` - 为绝对定位的按钮提供定位上下文
2. **按钮容器**：`absolute top-4 right-4` - 固定在右上角
3. **按钮间距**：`flex items-center gap-3` - 保持按钮之间的间距
4. **按钮样式**：
   - 编辑：蓝色 (`bg-blue-600`)
   - 保存：绿色 (`bg-green-600`)
   - 取消：灰色 (`bg-gray-600`)

## 📱 响应式适配

### 大屏幕 (≥1024px)
- ✅ 按钮显示完整文字
- ✅ 汇总数据3列布局
- ✅ 按钮位于右上角

### 中等屏幕 (768px - 1023px)
- ✅ 按钮保持右上角位置
- ✅ 汇总数据可能自适应为2列
- ✅ 按钮文字保持可见

### 小屏幕 (<768px)
- ⚠️ 建议使用移动端专用布局
- 可考虑将按钮移至汇总卡片下方

## 🎯 用户体验提升

### 操作流程优化

**修改前：**
1. 滚动到页面顶部找编辑按钮
2. 点击编辑
3. 滚动回数据区域编辑
4. 滚动回顶部找保存按钮

**修改后：**
1. 在数据汇总区域直接点击编辑
2. 编辑数据
3. 在同一位置点击保存

### 减少操作步骤
- 🔽 滚动次数：4次 → 0次
- ⏱️ 操作时间：~10秒 → ~3秒
- 👆 点击距离：~800px → ~200px
