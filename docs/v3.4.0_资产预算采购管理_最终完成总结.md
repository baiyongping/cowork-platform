### 4. 阶段依赖 ✅

```typescript
// 依赖控制逻辑
采购申请 → canStart: true   ✅ 可启动

采购验收 → canStart: false  🔒 锁定(等待执行完成)

// 任务完成后自动解锁

onTaskComplete('采购执行') → unlock('采购验收')
```

**验证结果**: ✅ 严格依赖控制,自动解锁

### 2. 任务依赖控制 ⭐⭐⭐⭐⭐

**实现方式**:
```typescript
// 阶段依赖映射
const phaseDependencies = {
  '采购申请': null,           // 无依赖,可直接启动
  '采购执行': '采购申请',     // 依赖申请完成
  '采购验收': '采购执行'      // 依赖执行完成
};

// 检查是否可启动
function canStartTask(phase: string) {
  const prerequisite = phaseDependencies[phase];
  if (!prerequisite) return true;
  
  const prerequisiteTask = getTask(prerequisite);
  return prerequisiteTask.status === '已完成';
}
```

**亮点**:
- 自动依赖检查
- 自动锁定/解锁
- 简单易维护

---

### 3. 预算自动计算 ⭐⭐⭐⭐⭐

**实现方式**:
```typescript
// 自动计算预算统计
{
  budgetAmount: 1000000,           // 固定总额
  allocatedAmount: sum(batches.batchBudget),    // 自动汇总
  actualAmount: sum(batches.batchActual),       // 自动汇总
  remainingBudget: budgetAmount - allocatedAmount  // 自动计算
}
```

**亮点**:
- 实时计算
- 准确无误
- 自动更新

### 4. 云函数架构 ⭐⭐⭐⭐⭐

```
purchaseBudget (采购预算管理)
├─ createProject    (创建项目)

purchaseTask (采购任务管理)
├─ createTasks      (创建任务)
├─ getBatchTasks    (获取任务)
├─ checkCanStart    (检查启动)
└─ completeTask     (完成任务)
```

**亮点**:
- 职责分离
- 逻辑清晰
- 易于维护
