# 微信登录审核流程说明

## 业务逻辑

系统已调整为: **首次微信登录需要审核,审核通过后扫码即可登录**

## 详细步骤

### 1. 用户首次扫码登录

**用户操作**:
```
1. 打开登录页面
2. 点击"微信扫码登录"按钮
3. 跳转到微信扫码页面
4. 使用微信扫描二维码
5. 在微信中确认授权
```

**系统处理**:
```typescript
// lib/wechat-login-service.ts - findOrCreateUserByWechat()

const newUser = {
  username: `wx_${Date.now().toString(36)}`,  // 自动生成用户名
  password: '',                                // 微信登录无密码
  name: wechatInfo.nickname,                  // 微信昵称
  avatar: wechatInfo.avatar,                  // 微信头像
  wechatOpenId: '用户的微信OpenID',            // 绑定微信
  loginType: 'wechat',                        // 标记为微信登录
  approvalStatus: 'pending',                  // 🔴 待审核状态
  isActive: true,
  role: 'user',
  createdAt: new Date()
};

// 保存到数据库
await db.collection('users').add(newUser);

// 返回提示
return {
  success: false,
  message: '首次微信登录注册成功,请等待管理员审核后再次登录'
};
```

**用户看到的提示**:
```

│ ✅ 注册成功!                    │

│ 审核通过后,扫码即可登录         │

```

### 2. 管理员审核

**管理员操作**:
```
1. 登录管理员账号
2. 进入"用户管理"页面
3. 查看"待审核"用户列表
4. 找到新注册的微信用户
   - 登录方式: 微信
   - 用户名: wx_xxxxx
   - 昵称: (微信昵称)
5. 点击"审核通过"按钮
```

**系统处理**:
```typescript
// 更新用户状态
await db.collection('users').doc(userId).update({
  approvalStatus: 'approved',     // ✅ 审核通过
  approvedBy: adminUserId,       // 记录审核人
  approvedAt: new Date(),        // 记录审核时间
  updatedAt: new Date()
});
```

**审核完成后**:
```
用户状态:
approvalStatus: 'pending' → 'approved' ✅
```

### 3. 用户再次扫码登录

**用户操作**:
```
1. 再次打开登录页面
2. 点击"微信扫码登录"
3. 扫码
4. 自动登录成功 ✅
```

**系统处理**:
```typescript
// lib/wechat-login-service.ts - findOrCreateUserByWechat()

// 查询已存在的用户
const existingUser = await db.collection('users')
  .where({ wechatOpenId })
  .get();

// 检查用户状态
if (user.approvalStatus !== 'approved') {
  return { 
    success: false, 
    message: '账号审核未通过,无法登录' 
  };
}

// ✅ 审核已通过,生成token
const token = btoa(JSON.stringify({
  userId: user._id,
  username: user.username,
  role: user.role,
  timestamp: Date.now()
}));

return {
  success: true,
  user: user,
  token: token,
  message: '登录成功'
};
```

**用户体验**:
```
扫码 → 1秒后 → 自动跳转到系统首页 ✅
```

### 4. 后续登录

**每次登录**:
```
点击"微信扫码登录" → 扫码 → 自动登录 ✅
```

**无需**:
- ❌ 输入账号密码
- ❌ 重复审核
- ❌ 短信验证码
- ❌ 忘记密码

## 状态流转

```
pending (待审核)
    ↓
  [管理员审核]
    ↓
approved (已审核) → 可以登录 ✅
    ↓
rejected (已拒绝) → 无法登录 ❌
```

## 权限控制

### 登录检查逻辑

```typescript
// 1. 检查审核状态
if (user.approvalStatus !== 'approved') {
  return { success: false, message: '账号审核未通过' };
}

// 2. 检查账号状态
if (!user.isActive) {
  return { success: false, message: '账号已被禁用' };
}

// 3. 检查员工状态
if (user.status === '离职') {
  return { success: false, message: '账号已离职' };
}

// 4. 检查暂停状态
if (user.status === '暂停使用') {
  return { success: false, message: '账号已暂停使用' };
}

// ✅ 所有检查通过,允许登录
```

## 常见问题

### Q1: 首次登录为什么需要审核?

**原因**:
- 确保企业内部人员才能使用系统
- 防止未授权人员随意注册
- 保证数据安全

### Q2: 审核需要多长时间?

**回答**:
- 取决于管理员审核速度
- 一般1小时内完成
- 如需加急,可联系管理员

### Q3: 审核通过后还需要再次审核吗?

**回答**:
- ❌ 不需要
- 审核通过后,扫码即可登录
- 除非账号被管理员禁用

### Q4: 可以跳过审核吗?

**回答**:
- ❌ 不可以
- 这是系统安全策略
- 所有新用户都需要审核

### Q5: 微信登录和账号密码登录有什么区别?

**对比**:

| 特性 | 微信登录 | 账号密码登录 |
|------|---------|-------------|
| 首次登录 | 需审核 | 需审核+设置密码 |
| 后续登录 | 扫码即可 | 输入账号密码 |
| 忘记密码 | 无此问题 | 需要重置 |
| 安全性 | 微信实名 | 密码强度 |
| 便捷性 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
