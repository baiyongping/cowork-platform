# 数据库访问规范

## 📋 核心原则

**整个项目统一使用 `lib/cloudbase.ts` 作为数据库访问入口，不使用CDN引入SDK。**

## ✅ 正确用法

### 1. 基本数据库操作

```typescript
import { db } from '../lib/cloudbase';

// 查询
const result = await db.collection('users').get();

// 新增
await db.collection('users').add({
  name: '张三',
  email: 'zhangsan@example.com'
});

// 更新
await db.collection('users').doc(userId).update({
  name: '新名字'
});

// 删除
await db.collection('users').doc(userId).remove();
```

### 2. 使用安全的数据库包装器（推荐）

```typescript
import { safeDbOperation } from '../lib/db-safe';

// 自动处理初始化和错误
const users = await safeDbOperation(
  async (db) => {
    const result = await db.collection('users').get();
    return result.data;
  },
  '查询用户列表'
);
```

### 3. 手动检查数据库状态

```typescript
import { ensureDbReady, isDbReady } from '../lib/db-safe';

// 确保数据库就绪后再操作
async function loadData() {
  await ensureDbReady();
  
  // 现在可以安全地访问数据库
  const result = await db.collection('users').get();
}

// 检查是否就绪
if (isDbReady()) {
  // 数据库已就绪
}
```

### 4. 健康检查

```typescript
// 在浏览器控制台运行
window.checkDbHealth();

// 或在代码中
import { checkDbHealth, printHealthCheck } from '../lib/db-health';

const health = await checkDbHealth();
printHealthCheck(health);
```

## ❌ 错误用法

### 1. 不要使用CDN引入SDK

```html
<!-- ❌ 错误：不要在HTML中引入CDN -->
<script src="https://web.sdk.qcloud.com/cloudbase-js-sdk/2.7.1/cloudbase.full.js"></script>
```

### 2. 不要直接初始化新的CloudBase实例

```typescript
// ❌ 错误：不要创建新实例
import cloudbase from '@cloudbase/js-sdk';
const app = cloudbase.init({ env: 'xxx' });
const db = app.database();

// ✅ 正确：使用统一的实例
import { db } from '../lib/cloudbase';
```

### 3. 不要在数据库未就绪时访问

```typescript
// ❌ 错误：可能在初始化前访问
const result = await db.collection('users').get();

// ✅ 正确：确保就绪后再访问
await ensureDbReady();
const result = await db.collection('users').get();
```

## 🚨 常见问题排查

### 问题1: "cloudbase is not defined"

**原因**: 使用了CDN引入，但SDK未加载

**解决**: 
1. 删除HTML中的CDN引入
2. 使用 `import { db } from '../lib/cloudbase'`

### 问题2: "Cannot access 'db' before initialization"

**原因**: 在数据库初始化完成前访问

**解决**:
1. 使用 `await ensureDbReady()` 确保初始化完成
2. 或使用 `safeDbOperation()` 包装器

### 问题3: "permission denied" 或 CORS 错误

**原因**: 安全域名未配置或认证失败

**解决**:
1. 在CloudBase控制台添加安全域名
2. 检查匿名登录是否启用
3. 查看控制台错误日志

### 问题4: 数据库操作无响应

**诊断步骤**:
1. 运行 `window.checkDbHealth()` 检查状态
2. 查看控制台是否有错误日志
3. 检查网络连接
4. 确认CloudBase环境ID正确

## 📝 迁移指南

### 从CDN迁移到本地SDK

**旧代码** (HTML测试页面):
```html
<script src="https://web.sdk.qcloud.com/cloudbase-js-sdk/2.7.1/cloudbase.full.js"></script>
<script>
  const app = cloudbase.init({ env: 'xxx' });
  const db = app.database();
</script>
```

**新代码** (React组件):
```typescript
import { db } from '../lib/cloudbase';
import { safeDbOperation } from '../lib/db-safe';

async function loadData() {
  const users = await safeDbOperation(
    async (db) => db.collection('users').get(),
    '查询用户'
  );
}
```

## 🎯 最佳实践

1. **统一入口**: 始终从 `lib/cloudbase.ts` 导入
2. **安全包装**: 优先使用 `safeDbOperation()`
3. **错误处理**: 使用 try-catch 捕获错误
4. **健康检查**: 定期检查数据库状态
5. **日志记录**: 关键操作记录日志

- `main.tsx` - 应用入口，自动初始化
