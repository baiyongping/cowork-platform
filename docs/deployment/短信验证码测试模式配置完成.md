## 🧪 测试流程

### 快速测试（5步）

1. **启动开发服务器**
   ```bash
   npm run dev
   ```

2. **打开注册页面**
   - 访问 http://localhost:5173
   - 点击"注册"按钮

3. **填写注册信息**
   ```
   用户名: testuser
   密码: 123456
   手机号: 13800138000
   ```

4. **获取验证码**
   - 点击"发送验证码"
   - 自动弹出验证码窗口
   - 记录弹窗显示的6位数字

5. **完成注册**
   - 输入验证码
   - 点击"注册"
   - 提示"注册成功，等待管理员审核"

**自动切换**（无需手动操作）:

```typescript
const isDevelopment = import.meta.env.DEV || import.meta.env.MODE === 'development';
```

**前提条件**:
1. 注册腾讯云账号
2. 开通短信服务（需实名认证）
3. 申请短信签名（如："际华定制"）
4. 申请短信模板（验证码类型）
5. 获取 SecretId 和 SecretKey

**配置文件**: `lib/sms-service.ts`

