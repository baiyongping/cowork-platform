## 🛠️ 故障排查

### 问题 1: 无法访问
```
解决方案:
1. 清除浏览器缓存（Ctrl+Shift+Delete）
2. 使用 Ctrl+F5 强制刷新
3. 等待 1-2 分钟后重试
4. 检查 Nginx 服务状态
```

### 问题 2: 功能异常
```
解决方案:
1. 按 F12 打开控制台查看错误
2. 检查 Network 标签的请求状态
3. 对比本地版本（http://localhost:4173）
4. 验证 CloudBase 配置
```

### 问题 3: 性能问题
```
解决方案:
1. 检查网络连接
2. 清除浏览器缓存
3. 使用无痕模式测试
4. 检查服务器资源
```
