# 功能模块名称配置说明

## 功能概述

系统现已支持在"系统设置"中自定义左侧导航菜单的功能模块名称。管理员可以根据企业实际需求修改模块名称，使系统更贴合业务场景。

## 配置位置

**路径：** 系统设置 → 类型设置 → 功能模块名称

## 功能模块对应关系

左侧导航菜单的功能模块与系统设置中的配置按**顺序**对应：

| 序号 | 默认名称 | 对应功能 | 是否可配置 |
|------|----------|----------|-----------|
| 1 | 工作台 | 首页看板 | ✅ 可配置 |
| 2 | 任务管理 | 任务管理模块 | ✅ 可配置 |
| 3 | 商机管理 | 商机管理模块 | ✅ 可配置 |
| 4 | 项目管理 | 项目管理模块 | ✅ 可配置 |
| 5 | 目标管理 | 目标与战略管理 | ✅ 可配置 |
| 6 | 账户设置 | 个人账户设置 | ✅ 可配置 |
| 7 | 系统设置 | 系统管理（仅管理员可见） | ❌ 系统默认，不可配置 |

## 使用方法

### 1. 进入配置页面

1. 使用**管理员账户**登录系统
2. 点击左侧菜单"系统设置"
3. 切换到"类型设置"标签页
4. 找到"功能模块名称"设置项

### 2. 修改模块名称

1. 点击"功能模块名称"右侧的**展开按钮**
2. 点击要修改的模块名称旁的**编辑按钮**
3. 输入新的模块名称
4. 点击**保存**按钮

### 3. 添加新模块名称（可选）

1. 点击"功能模块名称"右侧的 **+ 添加** 按钮
2. 输入新的模块名称
3. 点击**保存**

> **注意：** 添加的新模块名称不会立即显示在左侧菜单，因为前6个已固定对应现有功能。

### 4. 删除或禁用模块名称

- **系统默认的6个模块名称**：可编辑，**不可删除**
- **新增的模块名称**：可编辑、可删除

### 5. 保存全局配置

- 修改完成后，点击页面顶部的 **保存所有修改** 按钮
- 系统将保存所有类型设置的变更

## 技术说明

### 数据存储

- **集合名称：** `type_settings`
- **类型标识：** `moduleNames`
- **数据格式：** 
  ```json
  {
    "type": "moduleNames",
    "name": "功能模块名称",
    "values": [
      { "value": "工作台", "enabled": true, "isSystem": true },
      { "value": "任务管理", "enabled": true, "isSystem": true },
      { "value": "商机管理", "enabled": true, "isSystem": true },
      { "value": "项目管理", "enabled": true, "isSystem": true },
      { "value": "目标管理", "enabled": true, "isSystem": true },
      { "value": "账户设置", "enabled": true, "isSystem": true }
    ]
  }
  ```

### 前端实现

- **Sidebar组件：** 自动从数据库读取`moduleNames`配置
- **实时更新：** 使用`useEffect`监听，配置修改后刷新页面即可生效
- **降级处理：** 如果数据库读取失败，自动使用默认名称

### 系统默认保护

- "系统设置"菜单项名称**固定为"系统设置"**，不受配置影响
- 确保管理员始终能找到系统配置入口

## 常见问题

### Q1: 修改后没有立即生效？

**A:** 配置修改后需要刷新页面（F5）才能看到变化。建议：
1. 保存配置后
2. 刷新浏览器（F5或Ctrl+R）
3. 查看左侧菜单变化

### Q2: 可以删除默认的6个模块名称吗？

**A:** 不可以。系统默认的6个模块名称标记为`isSystem: true`，只能编辑，不能删除。这是为了确保系统功能正常运行。

### Q3: 我添加了第7个模块名称，为什么没显示？

**A:** 左侧菜单当前只支持6个业务功能模块（+ 1个系统设置）。新添加的模块名称会保存在数据库中，但不会显示在菜单。未来版本可能支持动态模块扩展。

### Q4: 修改模块名称会影响已有数据吗？

**A:** 不会。修改的只是显示名称，不影响任何业务数据和功能逻辑。所有任务、商机、项目数据都保持不变。

### Q5: 非管理员可以修改模块名称吗？

**A:** 不可以。只有**系统管理员（admin角色）**才能访问"系统设置"并修改配置。

  - **问题原因**：保存后没有重新加载数据，导致内存state和数据库数据不同步
  - **解决方案**：在所有修改操作后添加 `await loadTypeSettings()` 重新加载数据

    - `handleToggleTypeEnabled` - 切换启用状态
    - `handleToggleSystemParam` - 切换系统参数标记
    - `handleDeleteType` (固定类型部分) - 删除类型
  - **附加修复**：修正了类型判断条件中遗漏 `moduleNames` 的问题
  - ✅ 现在编辑保存后界面立即刷新，显示最新数据
  - ✅ 所有操作（编辑、切换、删除）都能正确同步数据

- **2025-12-13 (修订2)**
  - 🐛 修复：修改功能模块名称后被还原的问题

    - `handleToggleSystemParam` - 切换系统参数标记
