## 🔧 下一步操作建议

### 步骤1: 登录服务器
通过腾讯云控制台或SSH客户端登录：
```bash
ssh root@152.136.183.181
# 或使用腾讯云控制台的"登录"按钮
```

### 步骤2: 检查服务器系统信息
```bash
# 查看操作系统版本
cat /etc/os-release

# 查看系统资源
free -h
df -h
```

### 步骤3: 配置防火墙
```bash
# 检查防火墙状态
sudo ufw status

# 开放必要端口
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# 启用防火墙
sudo ufw enable
```

### 步骤4: 安装必要软件
```bash
# 更新软件源
sudo apt update

# 安装Nginx
sudo apt install nginx -y

# 启动Nginx
sudo systemctl start nginx
sudo systemctl enable nginx

# 检查Nginx状态
sudo systemctl status nginx
```

### 步骤5: 再次测试
完成上述配置后，从本地再次访问：
```bash
# 测试HTTP
curl http://152.136.183.181

# 或在浏览器中打开
http://152.136.183.181
```

应该能看到Nginx的默认欢迎页面。

## 🔍 故障排查

如果端口仍无法访问，请检查：

### 1. 腾讯云安全组配置
登录腾讯云控制台 → 轻量应用服务器 → 防火墙

确保已添加以下规则：
```
协议端口: TCP:22     来源: 0.0.0.0/0     策略: 允许
协议端口: TCP:80     来源: 0.0.0.0/0     策略: 允许
协议端口: TCP:443    来源: 0.0.0.0/0     策略: 允许
```

### 2. 服务器内部防火墙
```bash
# 检查防火墙状态
sudo ufw status verbose

# 检查iptables规则
sudo iptables -L -n
```

### 3. Nginx服务状态
```bash
# 检查Nginx是否运行
sudo systemctl status nginx

# 检查Nginx配置是否正确
sudo nginx -t

# 查看Nginx错误日志
sudo tail -f /var/log/nginx/error.log
```

### 4. 端口监听状态
```bash
# 检查端口是否被监听
sudo netstat -tlnp | grep -E ':(22|80|443)'

# 或使用ss命令
sudo ss -tlnp | grep -E ':(22|80|443)'
```
