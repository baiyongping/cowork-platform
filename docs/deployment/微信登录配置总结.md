## 🎯 核心代码说明

### 首次登录逻辑 (lib/wechat-login-service.ts)

```typescript
// 创建新用户(待审核状态)
const newUser = {
  username: `wx_${Date.now().toString(36)}`,
  password: '',
  name: wechatInfo.nickname,
  avatar: wechatInfo.avatar,
  wechatOpenId: wechatOpenId,        // 绑定微信OpenID
  loginType: 'wechat',               // 标记为微信登录
  approvalStatus: 'pending',         // 🔴 待审核状态
  isActive: true,
  role: 'user',
  createdAt: new Date()
};

await db.collection('users').add(newUser);

// 返回提示
return {
  success: false,  // false表示需要审核
  message: '首次微信登录注册成功,请等待管理员审核后再次登录'
};
```

### 审核通过后登录逻辑

```typescript
// 查询已存在的用户
const existingUser = await db.collection('users')
  .where({ wechatOpenId })
  .get();

// 检查审核状态
if (user.approvalStatus !== 'approved') {
  return { 
    success: false, 
    message: '账号审核未通过,无法登录' 
  };
}

// ✅ 审核已通过,生成token
const token = btoa(JSON.stringify({
  userId: user._id,
  username: user.username,
  role: user.role,
  timestamp: Date.now()
}));

return {
  success: true,
  user: user,
  token: token,
  message: '登录成功'
};
```

## 📊 数据库结构

### 微信用户字段

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| wechatOpenId | String | 微信OpenID(唯一标识) | oXX-XXXxxxx |
| loginType | String | 登录类型 | 'wechat' 或 'password' |
| approvalStatus | String | 审核状态 | 'pending'(待审核) / 'approved'(已审核) / 'rejected'(已拒绝) |
| approvedBy | String | 审核人ID | admin-001 |
| approvedAt | Date | 审核时间 | 2025-12-14T11:00:00Z |

## ❓ 常见问题

### Q: 首次登录为什么需要审核?

**A**: 确保企业内部人员才能使用系统,防止未授权人员随意注册。

### Q: 审核需要多长时间?

**A**: 取决于管理员审核速度,一般1小时内完成。如需加急,可联系管理员。

### Q: 审核通过后还需要再次审核吗?

**A**: 不需要。审核通过后,扫码即可登录,无需重复审核。

### Q: 可以跳过审核吗?

**A**: 不可以。这是系统安全策略,所有新用户都需要审核。

### Q: 微信登录和账号密码登录有什么区别?

**A**: 
- 微信登录: 首次需审核,审核后扫码即可,无需密码
- 账号密码: 首次需审核+设置密码,后续需输入账号密码
