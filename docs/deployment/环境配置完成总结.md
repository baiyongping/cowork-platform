**步骤**：

#### 1. 安装 CloudBase CLI（如果未安装）
```bash

```

#### 2. 登录 CloudBase
```bash
cloudbase login
```

#### 3. 部署云函数
```bash
cd e:\cowork
cloudbase functions:deploy initDatabase
```

#### 4. 初始化数据库
```bash
cloudbase functions:invoke initDatabase
```

**预期输出**：
```json
{
  "success": true,
  "message": "数据库初始化完成",
  "data": {
```

```bash
npm run dev
```
