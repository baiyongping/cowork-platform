# 问题管理模块字段顺序调整说明

## 更新日期
2025-12-29

## 调整内容

### 字段显示顺序与必填状态

按照业务逻辑重新调整了问题管理表单的字段顺序和必填状态:

| 序号 | 字段名称 | 必填状态 | 默认值 | 说明 |
|------|---------|---------|--------|------|
| 1 | 问题标题 | ✅ 必填 | - | 问题的简要描述 |
| 2 | 问题类型 | ✅ 必填 | 第一个类型 | 销售/产品/财务/管理/系统BUG |
| 3 | 问题状态 | ✅ 必填 | 待接受 | 待接受/处理中/已处理/已确认 |
| 4 | 重要程度 | ✅ 必填 | 一般重要 | 一般重要/非常重要 |
| 5 | 紧急程度 | ✅ 必填 | 近期解决 | 近期解决/及时解决 |
| 6 | 开始日期 | ✅ 必填 | 今天 | 问题开始处理日期 |
| 7 | 截止日期 | ✅ 必填 | 7天后 | 问题需要完成的日期 |
| 8 | 发起人 | ✅ 必填 | 当前操作者 | 自动设置,不可修改 |
| 9 | 问题描述及建议 | ✅ 必填 | - | 详细描述问题和建议(多行文本) |
| 10 | 附件 | ❌ 非必填 | - | 支持上传相关文件 |
| 11 | 问题解决人 | ✅ 必填 | - | **仅能选择一个解决人** |
| 12 | 解决方式 | ✅ 必填 | 空 | 转交/会议研讨/形成任务 |
| 13 | 解决结果 | ✅ 必填 | 未确定 | 未确定/已解决/无法解决/暂缓解决/取消 |

## 关键变更

### 1. 必填字段验证增强
- 新增了所有必填字段的验证逻辑
- 错误提示清晰明确
- 未通过验证时显示红色边框

### 2. 问题解决人限制
- **只能选择一个解决人**(单一选择)
- 选择多个时自动保留第一个
- UI显示优化,不再使用标签组

### 3. 解决方式必填
- 解决方式从可选改为必填
- 默认值为空,需要手动选择
- 新增验证逻辑

### 4. 解决结果调整
- 新增"未确定"选项作为默认值
- 解决结果改为必填字段
- 更符合实际业务场景

### 5. 发起人字段优化
- 发起人默认为当前操作者
- 下拉框设置为禁用状态
- 添加说明文字"发起人默认为当前操作者"

## 业务逻辑说明

### 字段顺序设计原则
1. **基础信息在前**: 问题标题、类型、状态
2. **优先级信息**: 重要程度、紧急程度
3. **时间信息**: 开始日期、截止日期
4. **人员信息**: 发起人、解决人
5. **详细信息**: 问题描述、附件
6. **处理信息**: 解决方式、解决结果

### 必填字段设计原则
- 关键业务信息必填
- 可后续补充的信息不必填(如附件)
- 有默认值的字段可简化填写
