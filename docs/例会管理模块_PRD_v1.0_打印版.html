1. 模块概述

1.1 功能定位

例会管理模块是际华协同办公平台的执行驱动引擎，通过周例会和月度例会，建立"目标→措施→任务→商机/项目"的执行闭环，确保战略目标通过定期复盘和问题解决落地执行。

核心价值:

  • 🎯 驱动目标达成: 通过定期回顾季度目标和措施，确保战略执行不偏航
  • ✅ 推动任务完成: 周/月任务回顾和计划，形成执行压力和动力
  • 🔍 聚焦重点业务: 重点商机和项目专项分析，资源聚焦关键业务
  • 🛠️ 问题快速解决: 问题专栏机制，确保阻碍及时消除

1.2 业务背景

现状问题:

  • ❌ 任务执行缺乏定期回顾，延期任务无人跟进
  • ❌ 季度目标只有年初制定，缺乏过程监控
  • ❌ 商机和项目推进问题无处反馈，进展缓慢
  • ❌ 团队协作问题积压，缺乏解决机制

解决方案:

周例会（团队级/公司级）
    ↓ 驱动
上周任务回顾 + 下周任务计划
    ↓ 聚焦
重点商机分析 + 重点项目分析
    ↓ 解决
问题专栏问题集中讨论
    ↓ 输出
会议纪要（自动生成）

1.3 与现有模块的关系

核心定位: 例会管理是"执行监督层"，连接战略层（目标管理）和执行层（任务/商机/项目管理）

目标管理 (战略层)
    ↓ 提供数据
例会管理 (执行监督层)
    ↓ 驱动执行
任务管理 + 商机管理 + 项目管理 (执行层)

3. 子功能详细设计

3.1 例会召开 (Meeting Schedule)

功能定位: 例会管理的核心功能，负责例会的创建、内容配置、召开和状态管理。

3.1.1 新建例会表单（分步填写）

第一步:基本信息

  • 会议类型: 周例会 / 月例会
  • 会议级别: 团队级 / 公司级
  • 会议名称: 自动生成，可修改（如"2025年第1周团队周例会"）
  • 会议时间、地点、预计时长
  • 所属团队（团队级例会必填）

第二步:参会人员

  • 主持人（必填）
  • 必须参加人员（勾选）
  • 可选参加人员（勾选）

第三步:会议内容配置（核心步骤）

会议内容模块：

  1. 季度目标回顾（月例会推荐）
  2. 上周/月任务回顾（必选）
  3. 下周/月工作计划（必选）
  4. 重点商机分析
  5. 重点项目分析
  6. 问题解决

每个模块可跳转到对应的选择界面，从现有数据中选出作为会议交流内容。

第四步:内容明细确认

  • 预览会议信息和内容
  • 确认无误后创建会议
  • 自动发送通知给参会人

3.1.2 任务选择界面

从任务管理模块中，按时间周期自动提取任务：

  • 上周任务回顾: 提取上周（周一至周日）的任务
  • 支持筛选: 全部状态、已完成、延期
  • 重点关注延期任务（需讨论延期原因和解决方案）
  • 建议选择15-20条重点任务

3.1.3 商机选择界面

从商机管理模块中选择重点商机：

  • 按金额排序（优先选择大金额商机）
  • 按阶段筛选（关注关键阶段的商机）
  • 标注商机状态: 进展顺利 / 存在风险 / 长期未跟进
  • 建议选择3-5个重点商机

3.1.4 问题选择界面

从问题专栏选择待解决问题：

  • 按优先级排序（紧急问题优先）
  • 筛选状态: 待解决 / 升级至例会
  • 显示问题提交人、指定解决人、提交时间
  • 建议选择5-8个问题

3.1.5 例会状态流转

状态 触发操作 说明
待召开 创建例会 会议已创建，等待开始
进行中 点击"开始会议" 会议正在召开
已结束 点击"结束会议" 会议结束，自动生成纪要
已取消 点击"取消会议" 会议取消

3.2 例会纪要 (Meeting Minutes)

功能定位: 会议产出的正式文档，记录会议讨论内容、决议事项、待办任务，支持查询、编辑、审核、导出。

3.2.1 自动生成纪要

触发时机: 点击"结束会议"按钮

自动生成逻辑：

  1. 从会议议程中提取会议信息（时间、地点、参会人）
  2. 从任务管理提取上周任务（已完成、延期）
  3. 从任务管理提取下周计划任务
  4. 从商机管理提取选定的重点商机
  5. 从项目管理提取选定的重点项目
  6. 从问题专栏提取选定的待解决问题
  7. 生成纪要草稿（待主持人编辑补充）

3.2.2 纪要内容结构

纪要包含以下章节：

  1. 会议概况: 时间、地点、主持人、参会人员
  2. 季度目标回顾（月例会）: 目标完成进度、偏差分析
  3. 任务回顾: 已完成任务、延期任务（原因和解决方案）
  4. 工作计划: 下周/月计划任务、新增任务
  5. 商机分析: 重点商机讨论要点、行动事项
  6. 项目分析: 重点项目进度、风险、行动事项
  7. 问题解决: 已解决问题、升级问题
  8. 决议事项: 会议决定的行动事项、负责人、期限

3.2.3 纪要审核流程

主持人编辑纪要（草稿）
    ↓
提交审核
    ↓
部门经理审核（团队级例会）/ 总经理审核（公司级例会）
    ├─ 通过 → 发布纪要
    └─ 驳回 → 退回修改
    ↓
发布纪要
    ↓
通知参会人和抄送人员

3.2.4 纪要导出

支持导出格式：

  • Word格式: 正式会议纪要格式，带签字栏
  • PDF格式: 归档和分发

3.3 问题专栏 (Issue Board)

功能定位: 全员问题反馈和解决平台，任何人都可以提交工作中遇到的问题，通过指定解决人或升级到例会的方式快速解决。

3.3.1 问题提交

提交表单字段：

  • 问题标题（必填）: 简明扼要
  • 问题分类: 技术问题、流程问题、资源问题、协作问题、其他
  • 优先级: 紧急、重要、一般、低
  • 关联业务（可选）: 商机、项目、任务
  • 问题描述（必填）: 详细描述背景、现状、影响
  • 指定解决人（可选）: 如果知道谁能解决
  • 期望解决日期（可选）
  • 附件（可选）

3.3.2 问题看板视图

看板列：

状态列 说明
待解决 问题已提交，等待处理
处理中 解决人正在处理
已解决 问题已解决
升级至例会 无法直接解决，升级到例会讨论
已关闭 问题关闭（不再需要解决）

3.3.3 问题升级到例会

升级条件：

  • 问题复杂，需要多人讨论
  • 涉及跨部门协作
  • 超出个人权限范围
  • 长时间无法解决

升级流程：

解决人判断无法直接解决
    ↓
点击"升级到例会"
    ↓
选择例会（待召开的例会）
    ↓
填写升级原因
    ↓
确认升级
    ↓
问题自动添加到例会议程
    ↓
例会讨论 → 确定解决方案
    ↓
会后更新问题状态

4. 数据模型

4.1 集合列表

集合名称 用途 关键字段
meetings 例会信息 meetingType, meetingLevel, status, agenda
meeting_minutes 会议纪要 meetingId, content, status
issues 问题专栏 title, priority, status, assignee, escalatedToMeeting

4.2 集合关联关系

meetings (例会)
    ├── 1:1 → meeting_minutes (纪要)
    ├── N:N → tasks (任务)
    ├── N:N → opportunities (商机)
    ├── N:N → projects (项目)
    ├── N:N → quarterly_goals (季度目标)
    ├── N:N → quarterly_measures (季度措施)
    └── N:N → issues (问题)

meeting_minutes (纪要)
    ├── N:1 → meetings (例会)
    └── N:N → tasks (决议事项关联的任务)

issues (问题)
    ├── N:1 → users (提交人)
    ├── N:1 → users (解决人)
    ├── N:1 → meetings (升级到的例会)
    └── N:1 → opportunities/projects/tasks (关联业务)

    ↓

    ├─ 选择下周/月计划任务
    ├─ 选择重点商机
    ├─ 选择重点项目
    └─ 选择待解决问题
    ↓

5.2 消息通知

例会相关通知：

  • 新建例会 → 通知参会人
  • 例会开始前1小时 → 提醒参会人
  • 例会结束 → 通知参会人查看纪要
  • 纪要发布 → 通知抄送人员

问题相关通知：

  • 问题被指定 → 通知解决人
  • 问题升级到例会 → 通知例会主持人
  • 问题解决 → 通知提交人

7. 业务流程

7.1 周例会流程

每周固定时间（如周一下午）
    ↓
会前准备（提前1天）
    ├─ 创建例会
    ├─ 选择上周任务（自动提取上周任务）
    ├─ 选择下周计划任务
    ├─ 选择重点商机/项目
    └─ 选择待解决问题
    ↓
发送会议通知
    ↓
会议召开
    ├─ 上周任务回顾（重点关注延期任务）
    ├─ 下周工作计划（明确任务和负责人）
    ├─ 重点商机分析（跟进策略）
    ├─ 重点项目分析（进度和风险）
    └─ 问题解决（集中解决问题）
    ↓
会议结束 → 自动生成纪要
    ↓
主持人编辑纪要
    ↓
提交审核 → 部门经理审核
    ↓
发布纪要 → 通知相关人员
    ↓
执行决议事项（纳入任务管理）

7.2 月度例会流程

每月最后一周（如月底周五）
    ↓
会前准备（提前3天）
    ├─ 创建例会
    ├─ 回顾季度目标和措施
    ├─ 选择本月任务（团队级+个人级）
    ├─ 选择下月计划任务
    ├─ 选择重点商机/项目（金额大、周期长）
    └─ 选择重要问题（升级问题）
    ↓
发送会议通知（提前2天）
    ↓
会议召开（时间较长，2-3小时）
    ├─ 季度目标回顾（进度和偏差分析）
    ├─ 本月任务回顾（整体完成情况）
    ├─ 下月工作计划（月度重点工作）
    ├─ 重点商机分析（大客户、大订单）
    ├─ 重点项目分析（关键项目）
    └─ 重大问题解决（跨部门问题）
    ↓
会议结束 → 自动生成纪要
    ↓
主持人编辑纪要
    ↓
提交审核 → 总经理审核
    ↓
发布纪要 → 全员通知
    ↓
执行决议事项 → 跨部门协作

7.3 问题升级流程

员工提交问题
    ↓
指定解决人
    ↓
解决人尝试解决
    ├─ 成功 → 更新状态为"已解决"
    └─ 失败/超出权限
        ↓
        升级到例会
        ↓
        例会讨论
            ├─ 分析原因
            ├─ 制定方案
            └─ 明确负责人和期限
        ↓
        纪要记录决议
        ↓
        会后执行
        ↓
        更新问题状态

8. 集成方案

8.1 与目标管理集成

目标管理 (季度目标和措施)
    ↓ 提供数据
例会管理 (季度目标回顾)
    ↓ 驱动
任务管理 (季度措施关联的团队任务)

集成点:

  • 月例会自动提取当前季度目标和措施
  • 显示目标完成进度和偏差
  • 支持在例会上调整措施和任务

8.2 与任务管理集成

任务管理 (上周/月任务)
    ↓ 提供数据
例会管理 (任务回顾)
    ↓ 驱动
任务管理 (下周/月计划任务)

集成点:

  • 自动提取指定周期的任务（按时间筛选）
  • 支持在例会上标记延期任务的原因
  • 会后自动创建下周/月计划任务

8.3 与商机管理集成

商机管理 (重点商机)
    ↓ 提供数据
例会管理 (商机分析)
    ↓ 驱动
商机管理 (跟进任务)

集成点:

  • 自动筛选重点商机（按金额、阶段、风险）
  • 在例会上讨论商机跟进策略
  • 会后创建商机跟进任务
