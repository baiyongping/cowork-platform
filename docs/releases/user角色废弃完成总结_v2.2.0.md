## ⚠️ 注意事项

### 已知问题

1. **zhangkun和baiyp02的roles数组中包含无效值**:
   - `roles: ["user", ...]` - "user"是字符串,不是角色ID
   - `roles: [..., "assa"]` - "assa"疑似无效角色ID

2. **解决方法**:
   - 在员工管理界面重新分配角色时,系统会自动清理无效值
   - 或者手动修改数据库,删除无效值
