# 认证系统完整修复说明

## 🔍 问题分析

### 原始问题
- **症状**：登录和注册时报错 `登录失败: undefined` / `注册失败: undefined`
- **原因1**：密码哈希算法不一致

## ✅ 完整修复方案

### 1. 统一密码哈希算法

**问题**：初始化脚本和认证服务使用不同的哈希算法

**修复**：
```typescript
// 使用统一的 SHA-256 + SECRET_KEY
const SECRET_KEY = 'jihua-oa-platform-secret-key-2025';

async function hashPassword(password: string): Promise<string> {
  const encoder = new TextEncoder();
  const data = encoder.encode(password + SECRET_KEY);
  const hashBuffer = await crypto.subtle.digest('SHA-256', data);
  const hashArray = Array.from(new Uint8Array(hashBuffer));
  return hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
}
```

### 2. 添加 CloudBase 匿名认证

**问题**：CloudBase Web SDK 需要先登录才能访问数据库

**修复**：

     const hash = crypto.createHash('sha256')
       .update(password + SECRET_KEY)
       .digest('hex');
     return { hash };
   };
