### 2.2 推荐后端技术栈

**方案一：Node.js生态**
```
- 框架：NestJS（推荐）或 Express
- 数据库ORM：TypeORM 或 Prisma
- 验证：class-validator
- 认证：Passport.js + JWT
```

**方案二：Python生态**
```
- 框架：Django（推荐）或 FastAPI
- 数据库ORM：Django ORM 或 SQLAlchemy
- 验证：Pydantic
- 认证：Django REST framework + JWT
```

**方案三：Java生态**
```
- 框架：Spring Boot
- 数据库ORM：MyBatis 或 JPA
- 验证：Hibernate Validator
- 认证：Spring Security + JWT
```

### 2.3 数据库设计

**主数据库：PostgreSQL 14+**
- 优点：开源、成熟、支持复杂查询、JSON字段支持
- 用途：存储所有业务数据

**缓存：Redis 6+**
- 用途：会话管理、热点数据缓存、分布式锁

## 五、数据模型详解

### 5.1 任务表（tasks）

```sql
CREATE TABLE tasks (
  id VARCHAR(36) PRIMARY KEY,
  name VARCHAR(255) NOT NULL COMMENT '任务名称',
  level ENUM('公司级', '团队级', '个人级') NOT NULL COMMENT '任务级别',
  type ENUM('日常工作', '商机跟进', '项目任务') NOT NULL COMMENT '任务类型',
  status VARCHAR(50) NOT NULL COMMENT '任务状态（动态）',
  progress INT DEFAULT 0 COMMENT '完成进度 0-100',
  owner_id VARCHAR(36) NOT NULL COMMENT '负责人ID',
  team VARCHAR(100) COMMENT '所属团队',
  start_date DATE NOT NULL COMMENT '开始日期',
  end_date DATE NOT NULL COMMENT '截止日期',
  description TEXT COMMENT '任务描述',
  is_public BOOLEAN DEFAULT TRUE COMMENT '是否公开',
  opportunity_action_type VARCHAR(50) COMMENT '商机跟进动作类型',
  project_phase VARCHAR(50) COMMENT '项目任务环节',
  related_to VARCHAR(36) COMMENT '关联内容ID（商机/项目）',
  created_by VARCHAR(36) NOT NULL COMMENT '创建人ID',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  
  INDEX idx_owner (owner_id),
  INDEX idx_level (level),
  INDEX idx_status (status),
  INDEX idx_end_date (end_date),
  FOREIGN KEY (owner_id) REFERENCES users(id),
  FOREIGN KEY (created_by) REFERENCES users(id)
);
```

**字段说明**

| 字段 | 类型 | 必填 | 说明 | 业务规则 |
|-----|------|------|------|---------|
| status | VARCHAR | ✓ | 任务状态 | 日常工作/商机跟进：未开始/进行中/已完成/延期/取消/暂停<br>项目任务：未开始/准备期/制造期/交付期/已完成/暂停 |
| progress | INT | ✓ | 进度 | 0-100，默认0 |
| opportunity_action_type | VARCHAR | ✗ | 商机动作 | type='商机跟进'时必填 |
| project_phase | VARCHAR | ✗ | 项目环节 | type='项目任务'时必填 |

### 5.2 任务协同人关联表（task_collaborators）

```sql
CREATE TABLE task_collaborators (
  id VARCHAR(36) PRIMARY KEY,
  task_id VARCHAR(36) NOT NULL COMMENT '任务ID',
  user_id VARCHAR(36) NOT NULL COMMENT '协同人ID',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  
  UNIQUE KEY uk_task_user (task_id, user_id),
  FOREIGN KEY (task_id) REFERENCES tasks(id) ON DELETE CASCADE,
  FOREIGN KEY (user_id) REFERENCES users(id)
);
```

### 5.4 商机表（opportunities）

```sql
CREATE TABLE opportunities (
  id VARCHAR(36) PRIMARY KEY,
  name VARCHAR(255) NOT NULL COMMENT '商机名称',
  customer_name VARCHAR(255) NOT NULL COMMENT '客户名称',
  stage ENUM('跟进线索', '方案咨询', '商务谈判', '成功转化') NOT NULL COMMENT '商机阶段',
  amount DECIMAL(15, 2) NOT NULL COMMENT '预计金额',
  owner_id VARCHAR(36) NOT NULL COMMENT '负责人ID',
  expected_close_date DATE NOT NULL COMMENT '预计成交日期',
  contact_person VARCHAR(100) COMMENT '客户联系人',
  contact_phone VARCHAR(20) COMMENT '联系电话',
  source VARCHAR(100) COMMENT '商机来源',
  description TEXT COMMENT '商机描述',
  competitors TEXT COMMENT '竞争对手分析',
  status ENUM('进行中', '已转化', '已失败') DEFAULT '进行中' COMMENT '商机状态',
  converted_project_id VARCHAR(36) COMMENT '转化后的项目ID',
  created_by VARCHAR(36) NOT NULL COMMENT '创建人ID',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  
  INDEX idx_owner (owner_id),
  INDEX idx_stage (stage),
  INDEX idx_status (status),
  FOREIGN KEY (owner_id) REFERENCES users(id),
  FOREIGN KEY (converted_project_id) REFERENCES projects(id)
);
```

### 5.5 商机阶段变更历史表（opportunity_stage_history）

);
```

// ✅ 推荐：使用interface定义对象类型
interface Task {
  id: string;
  name: string;
  status: TaskStatus;
}

// ✅ 推荐：使用type定义联合类型
type TaskStatus = '未开始' | '进行中' | '已完成';

// ❌ 避免：使用any
const data: any = {}; // 不推荐

// ✅ 推荐：显式类型或使用unknown
const data: Task = {};
const data: unknown = {};
```

**2. 函数类型**
```typescript
// ✅ 推荐：显式声明参数和返回值类型
function getTask(id: string): Promise<Task> {
  return fetch(`/api/tasks/${id}`).then(res => res.json());
}

// ✅ 推荐：使用箭头函数
const handleClick = (e: React.MouseEvent): void => {
  console.log(e.target);
};
```

**3. 组件Props**
```typescript
// ✅ 推荐：定义Props接口
interface TaskCardProps {
  task: Task;
  onEdit: (task: Task) => void;
  onDelete: (id: string) => void;
}

export function TaskCard({ task, onEdit, onDelete }: TaskCardProps) {
  // ...
}
```

### 8.4 React规范

**1. 组件结构**
```typescript
// ✅ 推荐的组件结构顺序
export function MyComponent(props: MyComponentProps) {
  // 1. Props解构
  const { data, onUpdate } = props;
  
  // 2. Hooks（useState, useEffect等）
  const [state, setState] = useState(initialState);
  
  // 3. 自定义Hooks
  const { data, loading } = useData();
  
  // 4. 事件处理函数
  const handleClick = () => {
    // ...
  };
  
  // 5. 副作用
  useEffect(() => {
    // ...
  }, []);
  
  // 6. 渲染逻辑
  if (loading) return <Loading />;
  
  // 7. 返回JSX
  return (
    <div>
      {/* ... */}
    </div>
  );
}
```

**2. 状态管理**
```typescript
// ✅ 推荐：使用函数式更新
setCount(prev => prev + 1);

// ❌ 避免：直接使用当前值
setCount(count + 1);
```

**3. useEffect依赖**
```typescript
// ✅ 推荐：明确依赖项
useEffect(() => {
  fetchData(id);
}, [id]);

// ❌ 避免：遗漏依赖项
useEffect(() => {
  fetchData(id);
}, []); // id变化时不会重新执行
```

**2. 构建**

构建产物位于 `dist/` 目录。

**3. Nginx配置**
```nginx
server {
    listen 80;
    server_name jihua-oa.com www.jihua-oa.com;
    
    root /var/www/jihua-oa/dist;
    index index.html;
    
    # SPA路由配置
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # API代理
    location /api {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
    
    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
    
    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    
    # Gzip压缩
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_types text/plain text/css text/xml text/javascript application/javascript application/json application/xml+rss;
}

# HTTPS重定向（推荐）
server {
    listen 80;
    server_name jihua-oa.com www.jihua-oa.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name jihua-oa.com www.jihua-oa.com;
    
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    
    # ... 其他配置同上
}
```

## 十一、常见问题FAQ

### 11.1 开发环境问题

**Q1: npm install失败**

A: 尝试以下方法：
```bash
# 清除缓存
npm cache clean --force

# 删除node_modules和package-lock.json
rm -rf node_modules package-lock.json

# 重新安装
npm install

# 如果还是失败，尝试使用yarn
yarn install
```

**Q2: Tailwind样式不生效**

A: 检查以下几点：
1. `styles/globals.css`是否正确导入
2. Tailwind配置是否正确
3. 类名是否拼写错误
4. 是否需要重启开发服务器

**Q3: TypeScript类型错误**

A: 
```bash
# 重新生成类型定义
npm run type-check

# 如果使用VSCode，重启TypeScript服务
# Cmd/Ctrl + Shift + P -> TypeScript: Restart TS Server
```

### 11.2 功能实现问题

**Q4: 任务状态切换不生效**

A: 检查formData.type是否正确设置，状态选项是否正确绑定：
```typescript
// 确保类型变更时更新状态选项
onChange={(e) => {
  const newType = e.target.value as TaskType;
  setFormData({...formData, type: newType});
  setSelectedTaskType(newType);
}}
```

**Q5: 编辑任务时数据丢失**

A: 确保handleEditTask函数正确填充所有formData字段：
```typescript
setFormData({
  name: task.name,
  level: task.level,
  type: task.type,
  status: task.status,
  progress: task.progress, // 不要遗漏
  // ... 其他字段
});
```

**Q6: 协同人选择后不显示**

A: 检查selectedCollaborators状态是否正确更新，确保协同人选择逻辑正确。

### 11.3 部署问题

**Q7: 生产环境白屏**

A: 
1. 检查控制台错误信息
2. 检查API_BASE_URL是否配置正确
3. 检查Nginx配置是否正确
4. 检查静态资源路径是否正确

**Q8: API请求跨域**

A: 在后端添加CORS配置：
```typescript
// NestJS示例
app.enableCors({
  origin: 'https://jihua-oa.com',
  credentials: true,
});
```

**Q9: 数据库连接失败**

A: 
1. 检查数据库是否启动
2. 检查数据库连接信息是否正确
3. 检查防火墙是否开放端口
4. 检查数据库用户权限

### 11.4 性能问题

**Q10: 任务列表加载慢**

A: 
1. 实现分页加载
2. 添加loading状态
3. 使用虚拟滚动（react-window）
4. 优化数据库查询（添加索引）

**Q11: 页面切换卡顿**

A: 
1. 使用React.lazy()懒加载路由组件
2. 减少不必要的state更新
3. 使用useMemo和useCallback优化渲染

### 11.5 数据安全问题

**Q12: 如何保护敏感数据**

A: 
1. 密码使用bcrypt加密
2. JWT Token设置合理过期时间
3. HTTPS加密传输
4. 敏感字段数据库加密
5. 实施RBAC权限控制

**Q13: 如何防止XSS攻击**

A: 
1. React自动转义输出
2. 避免使用dangerouslySetInnerHTML
3. 设置CSP (Content Security Policy)
4. 后端验证和过滤输入
