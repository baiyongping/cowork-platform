### 2. 新增处理函数

#### handleEditSecondary
- **功能**: 打开编辑表单并填充当前值
- **参数**: 
  - `parentId`: 父科目ID
  - `secondary`: 要编辑的二级科目对象
- **操作**: 
  - 设置编辑状态
  - 填充科目名称和单位到表单

#### handleSaveSecondaryEdit
- **功能**: 保存编辑后的二级科目
- **验证**: 名称不能为空
- **操作**:
  1. 更新内存中的科目数据
  2. 查询数据库获取父科目文档ID
  3. 更新数据库中的children数组
  4. 清空编辑表单并关闭

### 3. UI组件

#### 编辑按钮
- **位置**: 每个二级科目右侧
- **图标**: Edit2 (蓝色)
- **条件**: 非系统参数科目才显示
- **布局**: 与删除按钮并排

```tsx
<button
  onClick={() => handleEditSecondary(account.id, child)}
  className="p-1 text-blue-600 hover:bg-blue-100 rounded transition-colors"
  title="编辑子科目"
>
  <Edit2 className="w-3.5 h-3.5" />
</button>
```

#### 编辑表单
- **位置**: 在添加子科目表单和子科目列表之间
- **样式**: 蓝色背景主题 (区别于添加表单的灰色)
- **字段**:
  - 子科目名称 (文本输入)
  - 金额单位 (下拉选择: %, 元, 万元)
- **按钮**:
  - 保存 (蓝色)
  - 取消 (灰色)

### 4. 数据库操作

#### 更新逻辑
```typescript
// 1. 找到父科目
const updatedParent = updatedAccounts.find(a => a.id === parentId);

// 2. 查询数据库中的文档ID
const result = await db.collection('budget_accounts')
  .where({ 
    id: parentId,
    year: selectedYear 
  })
  .get();

// 3. 更新children数组
await db.collection('budget_accounts')
  .doc(result.data[0]._id)
  .update({
    children: updatedParent.children
  });
```

## 🔄 使用流程

### 编辑二级科目
1. 点击科目右侧的"编辑"按钮 (蓝色铅笔图标)
2. 在弹出的表单中修改科目名称和单位
3. 点击"保存"按钮提交修改
4. 表单自动关闭,科目列表刷新

### 取消编辑
- 点击"取消"按钮
- 表单关闭,不保存修改
