# 资产预算采购管理 v3.4.0 - 测试指南

## 📋 功能概述

本次更新实现了**项目化多批次采购预算管理系统**，核心特性：

1. ✅ 采购预算作为项目进行全生命周期管理
2. ✅ 支持多批次采购（一个预算可分多次采购）
3. ✅ 任务驱动（申请→执行→验收三阶段）
4. ✅ 阶段依赖控制（前置任务完成后才能启动）
5. ✅ 预算余额控制（新批次不超剩余预算）

---

## 🚀 测试流程

### Phase 1: 创建采购预算项目

#### 测试步骤
1. 打开**资产预算管理**页面
2. 点击 **[+ 新建采购预算]** 按钮
3. 填写表单：
   ```
   项目名称: 2025年办公设备采购
   年度: 2025
   资产类别: 办公设备
   预算金额: 100（万元）
   负责人: [选择当前用户]
   开始日期: 2025-01-01
   结束日期: 2025-12-31
   采购理由: 公司扩张需更新办公设备
   ```
4. 点击 **[提交创建]**

#### 预期结果
- ✅ 创建成功提示
- ✅ 采购预算列表中显示新项目
- ✅ 项目状态为"未开始"
- ✅ 进度为 0%
- ✅ 批次数量为 0

---

### Phase 2: 创建第1批次采购

#### 测试步骤
1. 点击刚创建的采购预算项目
2. 在详情页点击 **[+ 新建批次]**
3. 填写批次信息：
   ```
   批次名称: 第1批-笔记本电脑采购
   批次预算: 20（万元）
   采购明细:
     - 物品: 联想笔记本
     - 数量: 10
     - 单位: 台
     - 单价: 0.6（万元）
     - 小计: 6（万元）
     
     - 物品: 戴尔笔记本
     - 数量: 5
     - 单位: 台
     - 单价: 0.8（万元）
     - 小计: 4（万元）
   
   计划开始: 2025-01-10
   计划结束: 2025-02-28
   ```
4. 点击 **[提交创建]**

#### 预期结果
- ✅ 批次创建成功
- ✅ 采购预算的"已分配金额"更新为 20万
- ✅ 剩余预算显示为 80万
- ✅ 批次列表中显示第1批
- ✅ 自动创建3个关联任务：
  - `第1批-笔记本电脑采购-申请` (状态: 未开始, canStart: true)
  - `第1批-笔记本电脑采购-执行` (状态: 未开始, canStart: false, 锁定)
  - `第1批-笔记本电脑采购-验收` (状态: 未开始, canStart: false, 锁定)

---

### Phase 3: 执行采购申请任务

#### 测试步骤
1. 在批次详情页找到"采购申请"任务
2. 点击 **[开始]** 按钮
3. 任务状态变为"进行中"
4. 进行采购申请工作（如填写申请表、提交审批等）
5. 完成后点击 **[完成]** 按钮

#### 预期结果
- ✅ 任务状态更新为"已完成"
- ✅ 自动解锁"采购执行"任务 (canStart: true)
- ✅ 批次状态变为"执行中"
- ✅ "采购验收"任务仍然锁定

---

### Phase 4: 执行采购执行任务

#### 测试步骤
1. "采购执行"任务变为可启动状态
2. 点击 **[开始]** 按钮
3. 任务状态变为"进行中"
4. 进行实际采购工作
5. 完成后点击 **[完成]** 按钮

#### 预期结果
- ✅ 任务状态更新为"已完成"
- ✅ 自动解锁"采购验收"任务 (canStart: true)
- ✅ 批次状态变为"验收中"

---

### Phase 5: 执行采购验收任务

#### 测试步骤
1. "采购验收"任务变为可启动状态
2. 点击 **[开始]** 按钮
3. 任务状态变为"进行中"
4. 进行验收工作
5. 完成后点击 **[完成]** 按钮

#### 预期结果
- ✅ 任务状态更新为"已完成"
- ✅ 批次状态变为"已完成"
- ✅ 采购预算进度更新（根据批次完成情况）

---

### Phase 6: 创建第2批次采购（测试并行）

#### 测试步骤
1. 在第1批次执行过程中，创建第2批次
2. 填写信息：
   ```
   批次名称: 第2批-台式机采购
   批次预算: 30（万元）
   采购明细:
     - 物品: 戴尔台式机
     - 数量: 15
     - 单位: 台
     - 单价: 0.5（万元）
     - 小计: 7.5（万元）
   
   计划开始: 2025-03-01
   计划结束: 2025-04-30
   ```
3. 提交创建

#### 预期结果
- ✅ 第2批次创建成功
- ✅ 已分配金额更新为 50万 (20+30)
- ✅ 剩余预算显示为 50万
- ✅ 第1批和第2批可以同时进行
- ✅ 自动创建第2批的3个任务

---

### Phase 7: 测试预算余额控制

#### 测试步骤
1. 尝试创建第3批次，预算设为 60万（超过剩余50万）
2. 提交创建

#### 预期结果
- ✅ 创建失败
- ✅ 错误提示："批次预算(60万)超过剩余预算(50万)"
- ✅ 不允许创建

---

### Phase 8: 测试任务依赖锁定

#### 测试步骤
1. 在某个批次中，尝试直接启动"采购执行"任务（不完成"采购申请"）
2. 点击"采购执行"的 **[开始]** 按钮

#### 预期结果
- ✅ 按钮不可点击（锁定状态）
- ✅ 显示提示："等待前置任务完成"
- ✅ 图标显示锁定图标 🔒

---

### Phase 9: 统计汇总测试

#### 测试步骤
1. 查看采购预算详情页
2. 检查统计数据

#### 预期结果
- ✅ 预算总额: 100万
- ✅ 已分配: 50万 (第1批20万 + 第2批30万)
- ✅ 实际支出: [根据实际采购金额]
- ✅ 剩余预算: 50万
- ✅ 批次统计正确（总数/已完成/进行中）
