# 角色权限自动同步机制说明

## 📋 功能概述

优化了角色权限管理功能，实现了**功能模块的统一配置和自动同步**，解决了以下问题：
1. **补全功能模块**：新增`issues`(问题管理)和`meetings`(例会管理)模块到权限配置
2. **统一配置管理**：创建`constants/modules.ts`统一管理所有功能模块
3. **自动同步机制**：新增功能模块时自动加入角色权限列表

## 🎯 核心改进

### 1. 统一模块配置文件

**文件位置**: `constants/modules.ts`

**主要内容**:
- `SYSTEM_MODULES`: 所有功能模块的统一定义
- `generateDefaultPermissions()`: 自动生成默认权限配置
- `getModuleName()`: 获取模块显示名称
- `moduleExists()`: 检查模块是否存在

### 2. 自动同步机制

#### 新增功能模块步骤

只需在`constants/modules.ts`中添加模块定义：

```typescript
export const SYSTEM_MODULES: ModuleDefinition[] = [
  // ... 现有模块 ...
  
  // ✅ 新增模块示例
  {
    id: 'newModule',              // 模块ID(英文)
    name: '新功能模块',            // 模块名称(中文)
    description: '模块功能描述',   // 可选
    defaultPermission: VIEW_CREATE // 默认权限
  }
];
```

**无需修改其他文件**，系统会自动：
- ✅ 在角色权限界面显示新模块
- ✅ 新建角色时包含新模块权限
- ✅ 权限检查时识别新模块

#### 新增带子模块的功能

```typescript
{
  id: 'parentModule',
  name: '父级模块',
  hasChildren: true,
  children: [
    {
      id: 'childModule1',
      name: '子模块1',
      defaultPermission: VIEW_CREATE
    },
    {
      id: 'childModule2',
      name: '子模块2',
      defaultPermission: VIEW_ONLY
    }
  ]
}
```

## 🔧 技术实现细节

### 1. 权限数据结构

```typescript
interface ModulePermission {
  view: boolean;      // 查看权限
  create: boolean;    // 创建权限
  edit: boolean;      // 编辑权限
  delete: boolean;    // 删除权限
  export: boolean;    // 导出权限
}
```

### 2. 角色权限配置示例

```typescript
{
  role: 'employee',
  name: '员工',
  permissions: {
    tasks: {
      view: true,
      create: true,
      edit: false,
      delete: false,
      export: false
    },
    issues: {
      view: true,
      create: true,
      edit: false,
      delete: false,
      export: false
    },
    // ... 其他模块
  }
}
```

### 3. 动态权限生成

系统会自动根据`SYSTEM_MODULES`配置生成：
1. **新建角色时**: 使用`generateDefaultPermissions()`生成初始权限
2. **显示权限列表时**: `RolePermissionDetail`组件动态读取并展示
3. **默认角色创建**: 管理员、经理、员工角色自动包含所有模块

## 📝 使用示例

### 示例1: 添加"考勤管理"模块

```typescript
// 在 constants/modules.ts 中添加
export const SYSTEM_MODULES: ModuleDefinition[] = [
  // ... 现有模块 ...
  
  {
    id: 'attendance',
    name: '考勤管理',
    description: '员工考勤记录和统计',
    defaultPermission: VIEW_CREATE
  }
];
```

保存后，系统自动生效：
- ✅ 角色权限界面自动显示"考勤管理"
- ✅ 新建角色时自动包含"考勤管理"权限
- ✅ 侧边栏需要配合`Sidebar.tsx`添加菜单项

### 示例2: 添加带子模块的"报表管理"

    },

## ⚠️ 注意事项

### 1. 模块ID命名规范
- 使用英文小驼峰命名: `moduleName`
- 子模块使用点号分隔: `parent.child`
- 不要使用特殊字符和空格

### 2. 侧边栏菜单同步
新增功能模块后，需要在`Sidebar.tsx`中添加对应菜单项：

```typescript
const allMenuItems = [
  // ... 现有菜单 ...
  { 
    id: 'attendance', 
    label: moduleLabels[10], // 对应位置
    icon: Calendar, 
    requiresPermission: true, 
    module: 'attendance' 
  }
];
```

### 3. 权限检查
使用`usePermissionContext`检查权限：

```typescript
const { checkPermission } = usePermissionContext();

// 检查是否有创建权限
if (checkPermission('attendance', 'create')) {
  // 显示创建按钮
}
```

### 4. 数据库同步
修改模块配置后：
- 已有角色**不会自动添加**新模块权限
- 新创建的角色会自动包含所有模块
- 如需更新已有角色，需手动在角色权限界面编辑
