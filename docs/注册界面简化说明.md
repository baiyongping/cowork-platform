# 注册界面简化说明

## 更新内容

简化注册界面，移除了不必要的输入项。

### 修改前
注册需要填写：
- ✓ 用户名 *（必填）
- ✓ 姓名
- ✓ 邮箱
- ✓ 部门
- ✓ 密码 *（必填）
- ✓ 确认密码 *（必填）

### 修改后
注册只需填写：
- ✓ 用户名 *（必填）
- ✓ 姓名（可选）
- ✓ 密码 *（必填）
- ✓ 确认密码 *（必填）

## 修改的文件

**`components/LoginPage.tsx`**
- 移除邮箱输入框
- 移除部门输入框
- 简化表单状态
- 移除未使用的图标导入（Mail, Briefcase）

## 数据库说明

注册时，邮箱和部门字段将保存为空字符串：
```javascript
{
  username: 'testuser',
  name: 'Test User',
  email: '',        // 空字符串
  department: '',   // 空字符串
  role: 'user',
  password: '...',
  ...
}
```

## 优势

1. **更简洁**：减少必填字段，降低注册门槛
2. **更快速**：用户可以快速完成注册
3. **更灵活**：后续可以在个人设置中补充信息
