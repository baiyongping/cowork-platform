# 微信扫码登录配置指南

## 功能概述

系统已集成CloudBase微信扫码登录功能,用户可以通过微信扫码快速登录系统,无需注册账号。

## 配置步骤

### 1. 注册微信开放平台账号

1. 访问 [微信开放平台](https://open.weixin.qq.com/)
2. 注册开发者账号
3. 完成企业认证(需300元/年认证费)

### 2. 创建网站应用

1. 登录微信开放平台管理中心
2. 选择"管理中心" → "网站应用" → "创建网站应用"
3. 填写应用信息:
   - 应用名称: 际华定制协同办公管理平台
   - 应用简介: 企业协同办公管理系统
   - 应用官网: https://你的域名
   - 授权回调域: https://你的域名

4. 提交审核(一般1-3个工作日)

### 3. 获取配置信息

审核通过后,在应用详情页获取:
- **AppID** (应用ID)
- **AppSecret** (应用密钥)

⚠️ **重要**: 妥善保管AppSecret,不要泄露!

### 4. 配置CloudBase环境

#### 4.1 在CloudBase控制台配置

1. 登录 [CloudBase控制台](https://console.cloud.tencent.com/tcb)
2. 选择环境: `jihua-oa-dev-3goht9irae4d949f`
3. 进入"身份认证" → "登录方式"
4. 启用"微信开放平台"登录
5. 填入上面获取的AppID和AppSecret
6. 配置授权回调域名:
   ```
   https://jihua-oa-dev-3goht9irae4d949f.service.tcloudbase.com/auth/callback
   ```

#### 4.2 更新前端配置

编辑 `lib/cloudbase.ts`,确保环境ID正确:

```typescript
const app = tcb.init({
  env: 'jihua-oa-dev-3goht9irae4d949f'
});
```

### 5. 域名备案(必需)

⚠️ **重要**: 微信开放平台要求回调域名必须已备案

1. 确保你的域名已完成ICP备案
2. 在微信开放平台应用管理中配置已备案的域名
3. 在CloudBase静态托管中绑定自定义域名

**推荐配置**:
- 主域名: `https://jihua-oa.com`
- 备用域名: `https://www.jihua-oa.com`

### 6. 配置回调地址

在 `lib/wechat-login-service.ts` 中,CloudBase会自动处理回调,无需额外配置。

## 使用流程

### 用户登录流程

1. **首次登录** (未绑定微信):
   ```
   用户点击"微信扫码登录"
   → 跳转微信扫码授权页面
   → 用户扫码授权
   → 自动创建系统账号
   → 跳转到系统首页
   ```

2. **再次登录** (已绑定微信):
   ```
   用户点击"微信扫码登录"
   → 跳转微信扫码授权页面
   → 用户扫码授权
   → 自动登录
   → 跳转到系统首页
   ```

### 数据库设计

用户表(users)新增字段:

```typescript
{
  wechatOpenId: string | null;  // 微信OpenID,绑定微信登录
  loginType: 'password' | 'wechat';  // 登录类型
  ...
}
```

## 安全说明

### 1. 自动审核策略

微信登录用户默认`approvalStatus = 'approved'`,原因:
- 微信实名认证,可信度高
- 提升用户体验
- 管理员可后续禁用账号

### 2. 用户名生成规则

```typescript
username = `wx_${Date.now().toString(36)}`
// 示例: wx_lm3k9f2x
```

### 3. 权限控制

- 微信登录用户默认角色: `user`
- 默认部门: 空
- 可在"员工管理"中修改角色和部门

## 常见问题

### Q1: 点击登录后没有跳转?

**检查项**:
1. CloudBase环境ID是否正确
2. 微信登录是否已在控制台启用
3. AppID和AppSecret是否配置正确
4. 浏览器控制台是否有错误

### Q2: 回调后提示"redirect_uri参数错误"?

**解决方案**:
1. 检查微信开放平台配置的回调域名
2. 确保回调域名与实际访问域名一致
3. 确保域名已备案

### Q3: 扫码后卡在授权页面?

**解决方案**:
1. 检查CloudBase回调地址配置
2. 查看CloudBase控制台日志
3. 确认网络连接正常

### Q4: 用户信息获取不到?

**解决方案**:
1. 检查微信授权scope配置
2. 查看CloudBase登录日志
3. 确认用户已授权获取信息
