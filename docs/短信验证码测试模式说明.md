# 短信验证码测试模式说明

## 📱 概述

为了方便开发和测试，系统在开发/测试环境下，**不会真实发送短信验证码**，而是通过**弹窗直接显示验证码**。

这样可以避免：
- ❌ 配置腾讯云短信服务的麻烦
- ❌ 短信费用成本
- ❌ 测试过程中频繁发送短信

## 🔧 实现原理

### 1. 环境检测

系统会自动检测当前环境：

```typescript
const isDevelopment = import.meta.env.DEV || import.meta.env.MODE === 'development';
```

### 2. 测试环境行为

**开发/测试环境** (npm run dev):
- ✅ 生成验证码
- ✅ 保存到数据库
- ✅ **弹窗显示验证码**
- ✅ 可以正常验证

**弹窗内容示例**:
```
📱 测试环境 - 验证码已生成

手机号: 13800138000
验证码: 123456

有效期: 5分钟

💡 生产环境将通过短信真实发送
```

### 3. 生产环境行为

**生产环境** (npm run build):
- ✅ 生成验证码
- ✅ 保存到数据库
- ✅ **调用腾讯云短信服务发送短信**
- ✅ 用户收到真实短信

## 📝 使用示例

### 用户注册流程

1. **用户填写注册信息**
   - 用户名、密码、手机号等

2. **点击"发送验证码"**
   - 系统生成6位数字验证码
   - 保存到数据库(5分钟有效期)

3. **测试环境：弹窗显示验证码**
   ```
   📱 测试环境 - 验证码已生成
   
   手机号: 13800138000
   验证码: 456789
   
   有效期: 5分钟
   ```

4. **用户输入验证码**
   - 在注册表单中输入弹窗显示的验证码
   - 点击"注册"按钮

5. **系统验证验证码**
   - 验证通过 → 创建账号
   - 验证失败 → 提示"验证码错误或已过期"

### 忘记密码流程

同样的方式：
1. 输入手机号
2. 点击"发送验证码"
3. 弹窗显示验证码
4. 输入验证码和新密码
5. 提交重置密码

## 🚀 切换到生产环境

### 方式1: 构建生产版本

```bash
# 构建生产版本
npm run build

# 部署到服务器
./一键部署-最终版.bat
```

**生产环境特点**:
- `import.meta.env.DEV` = false
- `import.meta.env.MODE` = 'production'
- **真实发送短信**（需要配置腾讯云短信服务）

### 方式2: 配置腾讯云短信服务

**前提条件**:
1. 注册腾讯云账号
2. 开通短信服务
3. 申请短信签名和模板
4. 获取 SecretId 和 SecretKey

**配置步骤**:

1. 修改 `lib/sms-service.ts`:
```typescript
// 配置腾讯云短信参数
const SMS_APP_ID = 'your-app-id';
const SMS_SECRET_ID = 'your-secret-id';
const SMS_SECRET_KEY = 'your-secret-key';
const SMS_SIGN = '际华定制';
const SMS_TEMPLATE_ID = 'your-template-id';
```

2. 重启开发服务器:
```bash
npm run dev
```

## 💡 优势

### 开发阶段
- ✅ **快速测试** - 无需配置短信服务
- ✅ **零成本** - 不产生短信费用
- ✅ **方便调试** - 直接看到验证码

### 生产阶段
- ✅ **真实短信** - 自动切换到真实短信发送
- ✅ **用户体验好** - 用户收到真实短信验证码
- ✅ **安全性高** - 基于手机号验证

## ⚠️ 注意事项

### 1. 数据库验证码仍然生效

即使是弹窗显示的验证码，也会保存到数据库并进行真实验证：
- 验证码有效期：5分钟
- 每个验证码只能使用一次
- 过期验证码会被拒绝

### 2. 生产环境必须配置短信服务

如果生产环境未配置短信服务：
- 会尝试发送短信
- 发送失败后会弹窗显示验证码（作为备选方案）
- **建议生产环境配置真实短信服务**

### 3. 测试手机号格式

即使是测试环境，手机号格式仍需符合规范：
```
✓ 13800138000  (有效)
✓ 15912345678  (有效)
✗ 12345678901  (无效，第二位必须是3-9)
✗ 1380013800   (无效，长度不足11位)
```

## 🔍 常见问题

### Q1: 为什么生产环境也显示弹窗？

**原因**: 短信服务未配置或配置错误

**解决方案**:
1. 检查 `lib/sms-service.ts` 配置
2. 确认腾讯云短信服务已开通
3. 验证 SecretId 和 SecretKey 正确

### Q2: 验证码每次都不同吗？

**是的**。每次点击"发送验证码"都会生成新的6位随机数字。

### Q3: 验证码在哪里查看？

- **测试环境**: 弹窗显示（自动弹出）
- **生产环境**: 用户手机收到短信
- **数据库**: 可以在CloudBase控制台 `sms_codes` 集合中查看

### Q4: 如何测试5分钟过期功能？

可以修改代码临时缩短过期时间：

```typescript
// lib/auth-service.ts 第87行
expiresAt: new Date(Date.now() + 30 * 1000), // 改为30秒
```

## 🎯 总结

这个测试模式设计：
1. ✅ **简化开发流程** - 无需配置短信服务即可测试
2. ✅ **降低测试成本** - 避免频繁发送测试短信
3. ✅ **保持功能完整** - 验证逻辑与生产环境一致
4. ✅ **平滑切换** - 自动根据环境切换发送方式

**推荐做法**:
- 开发/测试阶段：使用弹窗模式
- 生产部署前：配置腾讯云短信服务
- 上线后：真实发送短信给用户
