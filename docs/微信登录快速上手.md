# 微信登录快速上手 (5分钟)

## 准备工作 (需要配置一次)

### 你需要提供的信息

1. **微信开放平台AppID** - 从微信开放平台获取
2. **微信开放平台AppSecret** - 从微信开放平台获取
3. **已备案的域名** - 例如: jihua-oa.com

### 配置步骤 (只需5分钟)

#### Step 1: 在CloudBase控制台配置

```
1. 打开: https://console.cloud.tencent.com/tcb/env/setting?envId=jihua-oa-dev-3goht9irae4d949f&tab=loginConfig
2. 点击"身份认证" → "登录方式"
3. 找到"微信开放平台"
4. 点击"启用"
5. 填入:
   - AppID: _____________ (你的微信AppID)
   - AppSecret: _____________ (你的微信AppSecret)
6. 点击"保存"
```

#### Step 2: 配置回调域名

```
1. 在同一页面,找到"授权回调域名"
2. 添加:
   https://jihua-oa-dev-3goht9irae4d949f.service.tcloudbase.com/auth/callback
3. 保存
```

#### Step 3: 在微信开放平台配置

```
1. 打开微信开放平台: https://open.weixin.qq.com/
2. 进入你的网站应用
3. 修改"授权回调域名":
   添加: jihua-oa-dev-3goht9irae4d949f.service.tcloudbase.com
4. 保存
```

#### Step 4: 更新数据库 (可选,建议执行)

在CloudBase控制台 → 数据库 → 高级操作中执行:

```javascript
// 为现有用户添加微信字段
db.collection('users').where({}).update({
  wechatOpenId: null,
  loginType: 'password'
});
```

或者在CloudBase控制台 → 数据库 → users集合 → 批量操作:
- 添加字段: `wechatOpenId` (类型: String, 默认值: null)
- 添加字段: `loginType` (类型: String, 默认值: "password")

## 功能说明

### 用户体验

1. **首次登录**:
   - 点击"微信扫码登录"
   - 微信扫码授权
   - 自动创建账号并登录
   - 用户名格式: `wx_时间戳`

2. **再次登录**:
   - 点击"微信扫码登录"
   - 微信扫码授权
   - 自动识别并登录

3. **账号管理**:
   - 微信用户自动审核通过
   - 默认角色: user
   - 管理员可在"员工管理"中修改

### 数据结构

微信登录用户的数据结构:

```typescript
{
  _id: "auto-generated",
  username: "wx_lm3k9f2x",  // 自动生成
  password: "",              // 无密码
  name: "微信昵称",
  avatar: "微信头像URL",
  wechatOpenId: "oXX-XXX",   // 微信OpenID
  loginType: "wechat",       // 登录类型
  role: "user",
  approvalStatus: "approved", // 自动审核通过
  ...
}
```

## 测试

### 本地测试

1. 启动开发服务器:
   ```bash
   npm run dev
   ```

2. 打开浏览器: http://localhost:5173

3. 点击"微信扫码登录"按钮

4. 应该会跳转到微信授权页面

⚠️ **注意**: 本地测试时回调可能失败,因为微信要求HTTPS域名

### 生产环境测试

1. 部署到服务器:
   ```bash
   npm run build
   npm run deploy
   ```

2. 访问: https://你的域名

3. 点击"微信扫码登录"

4. 微信扫码授权

5. 应该能成功登录

## 故障排查

### 问题1: 点击登录没反应

**检查**:
```javascript
// 浏览器控制台执行
console.log(app.auth());
```

如果输出undefined,说明CloudBase未初始化。

**解决**: 检查 `lib/cloudbase.ts` 中的环境ID是否正确。

### 问题2: 跳转后提示redirect_uri错误

**原因**: 回调域名配置错误

**解决**:
1. 检查CloudBase控制台的回调域名配置
2. 检查微信开放平台的授权回调域名配置
3. 确保两者一致

### 问题3: 扫码后白屏

**原因**: 回调处理失败

**解决**:
1. 打开浏览器控制台查看错误
2. 检查 `lib/wechat-login-service.ts` 中的逻辑
3. 查看CloudBase控制台日志
