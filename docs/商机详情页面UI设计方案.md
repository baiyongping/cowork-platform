# 商机详情页面 UI 设计方案

## 一、设计目标

打造一个**现代化、信息层次清晰、视觉美观**的商机详情页面,提升用户体验和信息获取效率。

---

## 二、设计理念

### 🎨 视觉风格
- **现代商务风格**: 专业、简洁、高效
- **卡片式布局**: 信息分组清晰,易于浏览
- **渐变色点缀**: 关键数据使用渐变背景突出
- **微交互动效**: 悬停、点击等交互反馈流畅

### 📐 布局原则
- **F型视觉动线**: 从左到右,从上到下的信息阅读路径
- **信息分层**: 核心指标 → 关键信息 → 详细内容
- **响应式设计**: 适配不同屏幕尺寸

---

## 三、页面结构设计

### 1️⃣ 顶部操作栏
**设计要点**:
- 深蓝色渐变背景 (`from-blue-600 to-indigo-600`)
- 左侧: 图标 + 标题 + 锁定状态提示
- 右侧: 形成项目 | 编辑 | 保存关闭 | 回收站 | 关闭

**视觉效果**:
```
┌────────────────────────────────────────────────────────────┐
│ 🎯 商机详情                        [形成项目] [编辑] [保存] [🗑️] [✕] │
│    ⚠️ 该商机已成交，已锁定无法修改                              │

```

### 3️⃣ 关键指标卡片区 (KPI Cards)
**设计要点**:
- 4列网格布局 (`grid grid-cols-4 gap-4`)
- 每个卡片独立渐变背景色
- 数据大字体突出显示
- 可交互元素添加悬停效果

**卡片设计**:

#### 💰 预计金额卡片
- 背景: 蓝色渐变 (`from-blue-500 to-blue-600`)
- 图标: 💰 或 TrendingUp
- 数据: 大号金额 + 单位

#### 📊 商机阶段卡片
- 背景: 白色卡片 + 彩色标签
- 交互: 点击切换阶段(未锁定时)
- 状态色: 动态显示不同阶段颜色

#### ⭐ 重要程度卡片
- 背景: 白色卡片 + 彩色标签
- 级别标签: 重要/一般/低优先级

#### 🎯 成交机会卡片
- 背景: 绿色渐变 (`from-green-500 to-emerald-600`)
- 数据: 百分比 + 进度条
- 进度条: 白色半透明背景 + 白色填充

**视觉效果**:
```
┌─────────┬─────────┬─────────┬─────────┐
│ 💰      │ 📊      │ ⭐      │ 🎯      │
│ 预计金额 │ 商机阶段 │ 重要程度 │ 成交机会 │
│ 50.00万 │ 商务谈判 │ 重要    │ 75%     │

```

## 四、配色方案

### 主色调
- **主蓝色**: `#2563eb` (blue-600)
- **深蓝色**: `#4f46e5` (indigo-600)
- **成功绿**: `#10b981` (green-500) → `#059669` (emerald-600)

### 辅助色
- **警告橙**: `#f59e0b` (orange-500)
- **危险红**: `#ef4444` (red-500)
- **中性灰**: `#6b7280` (gray-500)

### 状态色
- **已完成**: 绿色 (`bg-green-100 text-green-700`)
- **进行中**: 蓝色 (`bg-blue-100 text-blue-700`)
- **未开始**: 灰色 (`bg-gray-100 text-gray-700`)
- **已取消**: 橙色 (`bg-orange-100 text-orange-700`)

### 背景层次
- **页面背景**: `bg-gray-50`
- **卡片背景**: `bg-white`
- **输入框背景**: `bg-gray-50`
- **悬停背景**: `hover:bg-gray-100`

## 十、优化要点总结

### ✅ 已优化
1. 顶部操作栏使用渐变背景,视觉层次清晰
2. 关键指标卡片使用渐变色突出重要数据
3. 信息分组合理,易于快速浏览
4. 统一的圆角和阴影风格
5. 适配不同状态的颜色标识

### 🎯 建议进一步优化
1. **增加微动效**: 卡片悬停时轻微上浮
2. **骨架屏加载**: 数据加载时显示占位内容
3. **图表可视化**: 成交机会可以用环形图展示
4. **时间线优化**: 跟进任务用垂直时间线展示
5. **响应式优化**: 小屏幕下调整为单列布局
