# 废弃user角色修复报告 v2.2.0

## 问题背景

baiyp02用户登录后发现权限不生效,经排查发现:

1. **用户使用`user`角色**:baiyp02的`role`字段为`user`
2. **没有user角色的权限配置**:`role_permissions`表中没有`user`角色的配置
3. **权限匹配失败**:导致用户无法获得任何权限

控制台日志:
```
[权限] 使用 user.role 字段匹配权限: user
[权限] 通过 user.role 匹配到的角色: []  // 找不到权限配置
[权限] 最终权限: {}  // 无任何权限
```

## 根本原因

`user`是一个**系统默认但无用的角色**:
- 微信登录创建新用户时,默认设置`role: 'user'`
- Mock数据中也使用`role: 'user'`
- 但`role_permissions`表中**从未配置**`user`角色的权限
- 导致所有使用`user`角色的用户都无法获得权限

## 修复方案

### 1. 修改微信登录服务

**文件**: `lib/wechat-login-service.ts`

**修改内容**:
```typescript
// ❌ 旧代码
role: 'user',

// ✅ 新代码 (v2.2.0)
role: '', // 不再使用旧的role字段
roles: [], // 新用户默认无角色,待管理员审核后分配
```

**说明**:
- 新用户创建时不再默认设置`user`角色
- 使用`roles`数组替代`role`字段
- 待管理员审核后分配正确的角色

### 2. 修改Mock数据

**文件**: `mocks/opportunityMockData.ts`

**修改内容**:
```typescript
// ❌ 旧代码
role: 'user',

// ✅ 新代码 (v2.2.0)
role: '', // 不再使用user角色
roles: [], // Mock用户无角色
```

### 3. 增强权限检查逻辑

**文件**: `utils/permissionUtils.ts`

**新增特性**:
1. **检测废弃角色**: 识别使用`user`角色的用户
2. **友好提示**: 输出清晰的错误信息和解决建议
3. **防止空角色**: 处理`role`为空的情况

**错误提示示例**:
```
[权限] ⚠️ 检测到用户使用废弃的"user"角色,该角色已被删除!
[权限] 💡 解决方法: 请管理员为该用户分配正确的角色(roles数组)
```

### 4. 数据库清理脚本

**文件**: `scripts/remove-user-role.js` + `移除user角色.bat`

**功能**:
1. 查找所有使用`user`角色的用户
2. 将`role`字段清空为`''`
3. 确保有`roles`字段(空数组)
4. 提示管理员为这些用户分配角色
