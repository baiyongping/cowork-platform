## 🎯 权限体系总结

### 用户类型层次

```
1. admin 超级用户（系统级）
   ├─ 默认拥有所有权限
   ├─ 不在用户列表中显示
   ├─ 不可被删除
   └─ 用于系统初始化和紧急管理

2. 角色用户（业务级）
   ├─ 子管理员（普通角色，无特殊性）
   ├─ 销售经理（普通角色）
   ├─ 区域经理（普通角色）
   ├─ 普通员工（普通角色）
   └─ 其他自定义角色（普通角色）
```

### 权限模块结构

```
任务管理 (tasks)
商机管理 (opportunities)
项目管理 (projects)

目标管理 (goal)
  ├─ 销售目标 (salesGoal)
  ├─ 商机目标 (opportunityGoal)
  ├─ 经营策略 (strategy)
  └─ 执行力地图 (execution)

系统设置 (settings)
  ├─ 用户审核 (userApproval)
  ├─ 员工管理 (employees)
  ├─ 部门管理 (departments)
  ├─ 角色权限 (roles)
  ├─ 类型设置 (typeSettings)
  └─ 操作日志 (operationLogs)
```

## 🔒 权限控制点

### 1. 菜单级别
- Sidebar 根据权限显示/隐藏菜单项
- admin 用户可见所有菜单
- 其他用户根据 view 权限显示

### 2. Tab 级别
- 目标管理和系统设置模块的 Tab 根据权限显示
- 自动选择第一个有权限的 Tab
- 无权限的 Tab 完全不显示

### 3. 功能级别
- 创建/编辑/删除等按钮根据权限显示
- 使用 `checkPermission(module, action)` 检查
- 支持细粒度控制

### 4. 数据级别
- 数据查看权限（基于 ownerId、creatorId、参与者）
- 数据编辑权限（基于角色和数据归属）
- admin 可以查看和编辑所有数据
