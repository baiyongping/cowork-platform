### 2. 权限保存报错修复：docId必须为字符串或数字

**问题描述**：
```
保存角色权限失败: Error: docId必须为字符串或数字
```

**原因分析**：
- `selectedRole._id` 可能为 `undefined` 或非字符串类型
- CloudBase要求 `doc()` 参数必须是字符串或数字

**修复方案**：
```typescript
// 修改前
await db.collection('role_permissions').doc(selectedRole._id).update({...});

// 修改后
const docId = String(selectedRole._id || selectedRole.id);

if (!docId || docId === 'undefined' || docId === 'null') {
  throw new Error('角色ID无效');
}

await db.collection('role_permissions').doc(docId).update({...});
```

**修复逻辑**：
1. ✅ 强制转换为字符串类型
2. ✅ 兼容 `_id` 和 `id` 两种字段
3. ✅ 验证ID有效性
4. ✅ 提供友好的错误提示
