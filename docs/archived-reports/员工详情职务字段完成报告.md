## ✅ 完成内容

### 1. 员工详情页面新增职务字段 📋

在系统设置 > 员工管理 > 员工详情中新增职务字段显示和编辑功能。

#### 显示位置
在员工详情的"基本信息"部分，职务字段位于"上级"字段之后：

```
基本信息
┌────────────┬────────────┐
│ 姓名       │ 手机号     │
├────────────┼────────────┤
│ 状态       │ 上级       │
├────────────┼────────────┤
│ 职务       │            │ ← 新增
└────────────┴────────────┘
```

#### 字段特性
- **查看模式**：显示员工职务，为空时显示"-"
- **编辑模式**：文本输入框，可填写职务名称
- **占位符**：请输入职务
- **数据同步**：与团队模块中的职务字段完全同步

### 2. 技术实现 🔧

#### 状态管理
```typescript
const [editForm, setEditForm] = useState({
  name: '',
  phone: '',
  departments: [] as string[],
  roles: [] as string[],
  status: '在职',
  supervisorId: '',
  position: '' // 新增职务字段
});
```

#### 数据加载
```typescript
useEffect(() => {
  if (employee) {
    setEditForm({
      name: employee.name || '',
      phone: employee.phone || '',
      departments: employee.departments || [],
      roles: employee.roles || (employee.role ? [employee.role] : []),
      status: employee.status || '在职',
      supervisorId: employee.supervisorId || '',
      position: employee.position || '' // 加载职务
    });
  }
}, [employee]);
```

#### 数据保存
```typescript
await db.collection('users').doc(employee._id).update({
  name: editForm.name,
  phone: editForm.phone,
  departments: editForm.departments,
  roles: editForm.roles,
  status: editForm.status,
  supervisorId: editForm.supervisorId,
  position: editForm.position // 保存职务
});
```

#### UI组件代码
```typescript
<div>
  <label className="block text-sm font-medium text-gray-700 mb-1">职务</label>
  {isEditing ? (
    <input
      type="text"
      value={editForm.position}
      onChange={(e) => setEditForm({ ...editForm, position: e.target.value })}
      className="w-full px-3 py-2 border border-gray-300 rounded-lg focus:outline-none focus:ring-2 focus:ring-blue-500"
      placeholder="请输入职务"
    />
  ) : (
    <p className="text-gray-900">{employee.position || '-'}</p>
  )}
</div>
```

### 3. 数据同步说明 🔄

职务字段在以下三个位置保持完全同步：

#### 位置1：员工管理 - 编辑模态框
- 文件：`components/pages/SystemSettings.tsx`
- 功能：编辑员工信息时填写职务
- 同步：保存到users集合的position字段

#### 位置2：员工管理 - 员工详情
- 文件：`components/EmployeeDetailModal.tsx`
- 功能：查看和编辑员工详细信息
- 同步：读取和保存position字段

#### 位置3：个人信息 - 团队模块
- 文件：`components/pages/AccountSettings.tsx`
- 功能：显示部门员工职务
- 同步：读取position字段显示

**所有位置操作同一个数据源（users集合的position字段），自动保持同步。**

## 💡 使用建议

### 1. 职务填写规范
建议使用标准化的职务名称：
- **高层**：总经理、副总经理、总监
- **中层**：部门经理、部门主管、区域经理
- **基层**：组长、主管、专员
- **专业**：销售经理、技术经理、财务经理

### 2. 职务管理流程
```
新增员工 → 在编辑模态框填写职务
↓
员工详情查看职务
↓
需要调整 → 员工详情编辑职务
↓
团队模块自动显示新职务
```

### 3. 与角色的关系
- **角色**：控制系统权限（管理员、普通员工等）
- **职务**：实际工作岗位（销售经理、技术经理等）
- **独立管理**：角色和职务相互独立，分别管理
