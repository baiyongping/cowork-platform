# 🔍 问题排查手册

## 登录问题

### ❌ 密码错误提示
**症状**: 输入正确的密码仍提示密码错误

**排查步骤**:

1. **检查数据库密码哈希**
```javascript
// 正确的管理员密码哈希值
const correctHash = '3798eee73d3dda0851e731edd250a51d691389eca398a1de76cb0471c8fec692';
```

2. **验证 SECRET_KEY 一致性**
```typescript
// lib/auth-service.ts 中的 SECRET_KEY
const SECRET_KEY = 'jihua-oa-platform-secret-key-2025';
```

3. **检查浏览器控制台**
- 打开开发者工具（F12）
- 查看 Console 标签页
- 查找"密码哈希对比"日志

4. **清除浏览器缓存**
```
按 Ctrl + Shift + Delete
选择"缓存的图片和文件"
点击"清除数据"
```

## 构建问题

### ❌ 构建失败
**症状**: `npm run build` 报错

**解决方案**:

1. **清理依赖重新安装**
```bash
rm -rf node_modules package-lock.json
npm install
```

2. **检查 Node 版本**
```bash
node --version  # 应该 >= 16.0.0
npm --version   # 应该 >= 8.0.0
```

3. **强制清理缓存**
```bash
npm cache clean --force
npm install
```

## 数据库问题

### ❌ 查询数据失败
**症状**: 无法读取数据库数据

**排查步骤**:

1. **检查 CloudBase 认证**
```javascript
// 确认已登录
const loginState = await auth.getLoginState();
console.log('登录状态:', loginState);
```

2. **检查数据库权限**
- 登录 CloudBase 控制台
- 查看数据库 → 集合 → 权限设置
- 确认读写权限正确

3. **检查集合名称**
```javascript
// 确认集合名称拼写正确
const users = db.collection('users');  // ✅ 正确
const user = db.collection('user');    // ❌ 错误
```

## 性能问题

### ⚠️ 页面加载缓慢
**优化建议**:

1. **减少数据查询量**
```javascript
// ❌ 不好的做法
const allUsers = await db.collection('users').get();

// ✅ 好的做法
const users = await db.collection('users')
  .limit(20)
  .skip(offset)
  .get();
```

2. **使用索引**
- 在 CloudBase 控制台为常用查询字段创建索引

3. **启用缓存**
```javascript
// 缓存用户信息
localStorage.setItem('userInfo', JSON.stringify(userInfo));
```

## 部署问题

### ❌ 生产环境无法访问
**症状**: 部署后页面打不开

**排查步骤**:

1. **检查服务器状态**
```bash
# 如果使用 Docker
docker ps | grep jihua-oa
```

2. **检查端口占用**
```bash
# Linux/Mac
lsof -i :8003

# Windows
netstat -ano | findstr :8003
```

3. **查看日志**
```bash
# Docker 日志
docker logs jihua-oa --tail 50
```
