# 员工部门同步问题修复报告

## 🔍 问题描述

**现象**：
- ✅ 在员工详情页编辑部门后保存，详情页显示正确
- ❌ 关闭详情页后，员工列表页仍显示旧的部门信息

## 🎯 根本原因

系统中员工部门信息存储在两个地方，需要同步更新：

1. **users 集合**：`departments` 字段（员工所属部门数组）
2. **departments 集合**：`memberIds` 字段（部门成员ID数组）

**员工列表页的部门显示逻辑**（SystemSettings.tsx 第814-820行）：
```typescript
// 从 departments 集合反向查询员工所属部门
const deptMap = new Map<string, string[]>();
deptResult.data.forEach((dept: any) => {
  if (dept.memberIds && Array.isArray(dept.memberIds)) {
    dept.memberIds.forEach((memberId: string) => {
      deptMap.get(memberId)!.push(dept.name);
    });
  }
});
```

**问题**：
- `EmployeeDetailModal.tsx` 只更新了 `users.departments`
- 没有同步更新 `departments.memberIds`
- 导致列表页查询到的是旧数据

## ✅ 修复方案

在 `EmployeeDetailModal.tsx` 的 `handleSave()` 函数中，增加部门同步逻辑：

```typescript
// 1. 更新 users 集合
await db.collection('users').doc(employee._id).update(updateData);

// 2. 同步更新 departments 集合的 memberIds
const oldDepts = employee.departments || [];
const newDepts = editForm.departments;
const deptsToRemove = oldDepts.filter(d => !newDepts.includes(d));
const deptsToAdd = newDepts.filter(d => !oldDepts.includes(d));

// 移除员工
for (const deptName of deptsToRemove) {
  const dept = await db.collection('departments').where({ name: deptName }).get();
  await db.collection('departments').doc(dept._id).update({
    memberIds: dept.memberIds.filter(id => id !== employee._id)
  });
}

// 添加员工
for (const deptName of deptsToAdd) {
  const dept = await db.collection('departments').where({ name: deptName }).get();
  await db.collection('departments').doc(dept._id).update({
    memberIds: [...dept.memberIds, employee._id]
  });
}
```
