## 修复的问题清单

### ✅ 问题1: 成交概率默认值0无法删除
**问题描述：** 成交概率字段第一次填写时有默认的0，删除不掉

**修复方案：**
- 修改成交概率输入框逻辑，当值为0时显示为空
- 增加 `onFocus` 事件，聚焦时如果值为0则清空输入框
- 使用 placeholder 提示用户输入范围

**修改文件：** `components/EditOpportunityModal.tsx`

**代码变更：**
```typescript
// 修改前
value={formData.probability}
onChange={(e) => setFormData({ ...formData, probability: parseInt(e.target.value) || 0 })}

// 修改后
value={formData.probability === 0 ? '' : formData.probability}
onChange={(e) => setFormData({ ...formData, probability: e.target.value === '' ? 0 : parseInt(e.target.value) })}
onFocus={(e) => { if (formData.probability === 0) e.target.value = ''; }}
placeholder="请输入成交概率 (0-100)"
```

const userIds = [...new Set(res.data?.map((item: any) => item.userId).filter(Boolean) || [])];

### ✅ 问题5: 预计金额验证问题
**问题描述：** 预计金额报"请至少添加一条产品需求"的错误，即使没有需求也应该允许金额为0

**修复方案：**
- 修改验证逻辑：只有当存在商机需求时，才要求金额大于0
- 如果没有商机需求，则允许金额为0

**修改文件：** `components/EditOpportunityModal.tsx`

**代码变更：**
```typescript
// 修改前
if (formData.estimatedAmount <= 0) {
  newErrors.estimatedAmount = '请至少添加一条产品需求';
}

// 修改后
if (requirements.length > 0 && formData.estimatedAmount <= 0) {
  newErrors.estimatedAmount = '请至少添加一条产品需求';
}
```
