# 商机目标季度卡片权限修复报告

## 📋 问题描述

**发现问题**:
- 商机目标页面的4个季度卡片上都有"编辑"按钮
- 这些编辑按钮**没有根据权限进行控制**,所有用户都能看到和点击
- 销售目标页面的季度卡片编辑功能已经有了权限限制
- 这是一个权限控制的遗漏

## 🔍 问题分析

### 对比销售目标和商机目标的实现

**销售目标 - 季度卡片** (第1576-1583行):
```tsx
<div className="flex items-center justify-between mb-4">
  <div className="text-base font-semibold text-gray-900">{q.quarter}</div>
  {checkPermission('goal.salesGoal', 'edit') && (  // ✅ 有权限检查
    <button onClick={...}>编辑</button>
  )}
</div>
```

**商机目标 - 季度卡片** (修复前 - 第1699-1710行):
```tsx
<div className="flex items-center justify-between mb-4">
  <div className="text-base font-semibold text-gray-900">{q.quarter}</div>
  <button onClick={...}>编辑</button>  // ❌ 没有权限检查!
</div>
```

### 权限控制缺失的原因
- 年度商机目标的"编辑目标"按钮有权限控制 (第1624-1632行)
- 但实现季度卡片时**遗漏**了权限检查代码
- 导致所有用户都能看到和点击季度卡片的"编辑"按钮

## ✅ 修复方案

### 修改内容
为商机目标的4个季度卡片的编辑按钮添加权限检查,与销售目标保持一致。

### 修复后的代码 (第1699-1712行)
```tsx
<div className="flex items-center justify-between mb-4">
  <div className="text-base font-semibold text-gray-900">{q.quarter}</div>
  {checkPermission('goal.opportunityGoal', 'edit') && (  // ✅ 新增权限检查
    <button 
      onClick={(e) => {
        e.stopPropagation(); // 阻止冒泡，避免触发卡片点击
        handleEditOpportunityGoal(opportunityGoals?.find(g => g.quarter === q.quarter) || null, 'quarterly', q.quarter);
      }}
      className="text-sm text-blue-600 hover:text-blue-700"
    >
      编辑
    </button>
  )}
</div>
```

### 权限检查逻辑
- 使用 `checkPermission('goal.opportunityGoal', 'edit')` 检查权限
- 只有拥有**商机目标编辑权限**的用户才能看到编辑按钮
- 没有权限的用户只能查看数据,看不到编辑按钮

## 📊 修复效果

### 修复前
```
所有用户 → 都能看到季度卡片的"编辑"按钮 ❌
```

### 修复后
```
有编辑权限的用户 → 看到"编辑"按钮 ✅
无编辑权限的用户 → 看不到"编辑"按钮 ✅
```
