# 小程序码生成问题排查及解决方案

## 📋 问题描述

**错误信息**：
```
errCode: -501007 invalid parameters
errMsg: wxacode.getUnlimited:fail missing wxCloudApiToken
```

**影响功能**：
- Web端管理员点击"邀请注册"无法生成小程序码
- 导致二维码图片加载失败
- 下载功能无法使用

---

## 🔍 根本原因分析

### 1. CloudBase 小程序授权配置问题

**wx-server-sdk** 调用微信开放接口 `wxacode.getUnlimited()` 需要：
- ✅ 小程序 AppID 已配置
- ✅ 小程序 AppSecret 已配置  
- ❌ **CloudBase 环境未正确关联小程序**

### 2. 缺少的关键配置

CloudBase 环境需要在控制台进行以下配置：

**控制台地址**：
https://tcb.cloud.tencent.com/dev?envId=jihua-oa-dev-3goht9irae4d949f#/settings

**需要配置的位置**：
```
环境设置 → 授权设置 → 关联小程序
```

### 方案B：临时备用方案（当前可用）

如果暂时无法配置小程序权限，使用备用二维码方案：

#### 修改前端代码

**文件**: `e:/cowork/components/pages/SystemSettings.tsx`

**修改内容**: 使用第三方二维码服务生成邀请码文本二维码

```typescript
const handleGenerateInvitation = async () => {
  setGeneratingInvitation(true);
  try {
    const result = await app.callFunction({
      name: 'createInvitation',
      data: { action: 'create' }
    });

    if (result.result.code === 200) {
      const { invitationCode, expireAt } = result.result.data;
      
      // 使用备用方案：生成邀请码文本二维码
      const qrUrl = `https://api.qrserver.com/v1/create-qr-code/?size=400x400&data=${invitationCode}`;
      
      const expireDate = new Date(expireAt);
      const expireText = `${expireDate.getMonth() + 1}月${expireDate.getDate()}日 ${expireDate.getHours()}:${expireDate.getMinutes().toString().padStart(2, '0')}`;
      
      setInvitationData({
        code: invitationCode,
        url: `邀请码有效期至 ${expireText}`,
        qrUrl: qrUrl
      });
      
      setShowInvitationModal(true);
    }
  } catch (error) {
    console.error('生成邀请码失败:', error);
    alert('生成邀请码失败');
  } finally {
    setGeneratingInvitation(false);
  }
};
```

#### 备用方案说明

**工作流程**：
1. 管理员点击"邀请注册" → 生成邀请码（32位随机字符串）
2. 使用第三方服务生成邀请码文本二维码
3. 新员工扫码 → 看到邀请码文本
4. 手动在小程序注册页面输入邀请码

**优点**：
- ✅ 无需配置小程序权限
- ✅ 立即可用
- ✅ 零成本（使用免费二维码服务）

**缺点**：
- ❌ 用户体验较差（需要手动输入邀请码）
- ❌ 不如小程序码直接跳转方便
