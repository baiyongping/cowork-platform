# 认证系统修复说明

## 问题原因

**根本原因**：密码哈希算法不一致

### 之前的问题
1. **初始化脚本** (Node.js)：使用 `crypto.createHash('sha256')` 生成密码哈希
2. **认证服务** (前端)：使用简单的字符编码哈希（完全不同的算法）
3. **结果**：存储的密码哈希与验证时的哈希不匹配，导致登录/注册失败

## 修复方案

### ✅ 统一密码哈希算法

所有地方都使用 **SHA-256 + SECRET_KEY** 的方式：

```typescript
// 密码加密密钥（与初始化脚本保持一致）
const SECRET_KEY = 'jihua-oa-platform-secret-key-2025';

// SHA-256密码哈希函数（与初始化脚本保持一致）
async function hashPassword(password: string): Promise<string> {
  const encoder = new TextEncoder();
  const data = encoder.encode(password + SECRET_KEY);
  const hashBuffer = await crypto.subtle.digest('SHA-256', data);
  const hashArray = Array.from(new Uint8Array(hashBuffer));
  return hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
}
```

### 修改的文件

- **`lib/auth-service.ts`**
  - ✅ 更新 `hashPassword` 函数为 SHA-256 算法
  - ✅ 将所有调用改为异步 `await hashPassword()`
  - ✅ 添加 `SECRET_KEY` 常量

## 技术细节

### 密码哈希算法对比

**❌ 旧算法（错误）：**
```typescript
function hashPassword(password: string): string {
  let hash = 0;
  for (let i = 0; i < password.length; i++) {
    const char = password.charCodeAt(i);
    hash = ((hash << 5) - hash) + char;
    hash = hash & hash;
  }
  return Math.abs(hash).toString(36);
}
```
- 问题：非标准哈希算法，不安全，与初始化脚本不一致

**✅ 新算法（正确）：**
```typescript
async function hashPassword(password: string): Promise<string> {
  const encoder = new TextEncoder();
  const data = encoder.encode(password + SECRET_KEY);
  const hashBuffer = await crypto.subtle.digest('SHA-256', data);
  const hashArray = Array.from(new Uint8Array(hashBuffer));
  return hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
}
```
- 优点：标准 SHA-256 算法，与初始化脚本一致，更安全

## 安全建议

### 当前实现
- ✅ 使用 SHA-256 哈希
- ✅ 添加 SECRET_KEY 增加安全性
- ✅ 前后端算法统一

### 生产环境建议
1. **使用云函数处理密码**
   - 密码哈希应该在服务器端进行
   - 避免在客户端暴露 SECRET_KEY

2. **使用更安全的算法**
   - 推荐使用 bcrypt 或 Argon2
   - 添加盐值（salt）增加安全性

3. **使用 HTTPS**
   - 确保传输过程中密码加密

4. **添加验证码**
   - 防止暴力破解
   - 限制登录尝试次数

5. **使用 JWT Token**
   - 替代当前的简单 token
   - 添加过期时间和刷新机制
