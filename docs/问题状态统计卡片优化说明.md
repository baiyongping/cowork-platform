# 问题状态统计卡片优化说明

## 修改内容

### 1. 统计卡片重新定义

原有的4个卡片(全部问题、进行中、已完成、延期)改为5个问题状态卡片:

1. **全部问题** - 显示所有问题总数(默认选中)
2. **待接受** - 显示状态为"待接受"的问题数量
3. **处理中** - 显示状态为"处理中"的问题数量  
4. **已处理** - 显示状态为"已处理"的问题数量
5. **已确认** - 显示状态为"已确认"的问题数量

### 2. 卡片交互功能

- 点击任意卡片,列表会根据对应状态进行筛选
- 被选中的卡片会有高亮效果(深色背景 + 边框)
- 默认显示"全部问题"

### 3. 视觉设计

每个状态卡片使用不同的配色方案:

- **全部问题**: 紫色系 (purple)
- **待接受**: 蓝色系 (blue)  
- **处理中**: 黄色系 (yellow)
- **已处理**: 橙色系 (orange)
- **已确认**: 绿色系 (green)

### 4. 删除的功能

- 移除了自动检测延期问题的逻辑 (`checkAndHandleOverdueIssues`)
- 移除了延期统计相关代码
- 新的状态系统中不再需要自动标记延期

## 技术实现

### 状态管理

```typescript
// 新增状态筛选
const [statusFilter, setStatusFilter] = useState<'all' | string>('all');

// 统计数据结构调整
const [statistics, setStatistics] = useState({
  total: 0,
  pending: 0,      // 待接受
  processing: 0,   // 处理中
  processed: 0,    // 已处理
  confirmed: 0     // 已确认
});
```

### 筛选逻辑

```typescript
const filteredIssues = issues.filter(issue => {
  // 类型筛选
  if (typeFilter !== 'all' && issue.type !== typeFilter) return false;
  
  // 状态筛选 (新增)
  if (statusFilter !== 'all' && issue.status !== statusFilter) return false;
  
  // 关键词搜索
  if (searchKeyword) {
    const keyword = searchKeyword.toLowerCase();
    return (
      issue.name.toLowerCase().includes(keyword) ||
      issue.owner?.name?.toLowerCase().includes(keyword) ||
      issue.description?.toLowerCase().includes(keyword)
    );
  }
  
  return true;
});
```

### 统计计算

```typescript
const calculateStatistics = () => {
  const total = issues.length;
  const pending = issues.filter(i => i.status === '待接受').length;
  const processing = issues.filter(i => i.status === '处理中').length;
  const processed = issues.filter(i => i.status === '已处理').length;
  const confirmed = issues.filter(i => i.status === '已确认').length;

  setStatistics({ total, pending, processing, processed, confirmed });
};
```

## 用户体验改进

1. **直观的数据展示**: 5个卡片清晰展示问题在不同状态下的分布
2. **快速筛选**: 点击卡片即可快速筛选对应状态的问题
3. **视觉反馈**: 选中的卡片有明显的高亮效果
4. **响应式设计**: 网格布局自适应不同屏幕尺寸

## 注意事项

1. 卡片布局使用 `grid-cols-5`,在小屏幕上可能需要调整为响应式布局
2. 统计数据实时更新,依赖 `issues` 数组的变化
3. 状态筛选与类型筛选、搜索功能可以同时使用
