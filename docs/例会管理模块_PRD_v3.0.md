## 📌 v3.0 更新说明

本版本的核心更新是**会议议题管理**：

1. **议题化管理**: 将会议议程、关联业务、决议、待办事项等内容重构为议题形式
2. **6种议题类型**: 目标复盘、团队任务汇报、商机分析、项目分析、问题解决、其他议题
3. **智能关联**: 根据议题类型自动关联不同业务对象
4. **多汇报人**: 每个议题支持多个汇报人
5. **结论和任务**: 每个议题可独立记录会议结论和新建任务

## 1. 产品概述

### 1.1 产品背景
例会管理是际华协同办公平台的重要功能模块，旨在通过系统化的会议管理、会议纪要记录和问题跟踪，提高团队协作效率，确保关键决策和问题得到有效跟进落实。

### 1.2 目标用户
- 企业管理层(主持会议、查看会议记录)
- 各部门负责人(参与会议、记录纪要、跟进问题)
- 普通员工(查看相关会议信息、处理分配的问题)

### 1.3 核心价值
- **系统化管理**: 统一管理各类会议，避免会议信息散落
- **可追溯性**: 完整记录会议决议和待办事项，便于后续查阅
- **问题闭环**: 自动关联问题管理，确保会议决议得到执行
- **议题化管理**: 通过议题结构化组织会议内容，清晰明确
- **关联业务**: 议题可关联目标、任务、商机、项目，建立业务全景视图

## 2. 功能架构

### 2.1 模块组成
```
例会管理
├── 会议列表 (Meeting List)
│   ├── 会议创建
│   ├── 会议编辑
│   ├── 会议删除(软删除)
│   └── 会议筛选
├── 会议议题 (Meeting Agenda) ⭐ 新增
│   ├── 议题管理
│   ├── 议题关联业务
│   ├── 汇报人管理
│   ├── 会议结论
│   └── 新建任务
├── 会议纪要 (Meeting Minutes)
│   ├── 纪要编辑
│   ├── 纪要查看
│   └── 纪要导出
└── 问题列表 (Issue List)
    ├── 会议问题查看
    ├── 问题状态更新
    └── 问题关联跳转
```

### 2.2 与其他模块的关联
- **目标管理**: 议题可关联季度目标和季度措施
- **任务管理**: 
  * 议题可关联团队任务
  * 团队任务汇报议题自动生成任务列表
  * 议题可创建新任务
- **商机管理**: 议题可关联商机，讨论商机跟进和成交策略
- **项目管理**: 议题可关联项目，讨论项目进展和风险
- **问题管理**: 议题可关联问题，跟踪问题解决情况

## 3.1 会议列表

### 3.1.1 会议数据模型

**数据库集合**: `meetings`

**字段定义**:
```typescript
interface Meeting {
  _id: string;                    // 会议ID
  title: string;                   // 会议标题(必填)
  type: MeetingType;               // 会议类型
  status: MeetingStatus;           // 会议状态
  startTime: Date;                 // 开始时间(必填)
  endTime: Date;                   // 结束时间(必填)
  location?: string;               // 会议地点(可选)
  isOnline: boolean;               // 是否线上会议
  meetingLink?: string;            // 线上会议链接
  host: string;                    // 主持人ID(必填)
  hostName?: string;               // 主持人姓名(关联查询)
  participants: string[];          // 参会人员ID数组
  participantNames?: string[];     // 参会人员姓名数组(关联查询)
  recorder?: string;               // 记录人ID(可选)
  recorderName?: string;           // 记录人姓名(关联查询)
  
  // ⭐ 会议议题(新增)
  agendaItems: MeetingAgendaItem[]; // 会议议题列表
  
  minutes?: string;                // 会议纪要(整体纪要)
  attachments?: string[];          // 附件URL数组
  
  // 问题关联
  relatedIssues?: string[];        // 关联问题ID数组(从问题管理自动同步)
  relatedIssueCount?: number;      // 关联问题数量
  
  // 元数据
  isDeleted?: boolean;             // 是否已删除(软删除)
  deletedAt?: Date;                // 删除时间
  createdBy: string;               // 创建人ID
  createdAt: Date;                 // 创建时间
  updatedAt: Date;                 // 更新时间
}

// ⭐ 会议议题(新增)
interface MeetingAgendaItem {
  id: string;                    // 议题ID
  title: string;                 // 议题标题(必填)
  type: AgendaType;              // 议题类型
  order: number;                 // 议题顺序
  
  // 汇报人(必填，多选)
  presenters: string[];          // 汇报人ID数组
  presenterNames?: string[];     // 汇报人姓名数组(查询展示用)
  
  // 根据议题类型，关联不同的业务对象
  relatedGoalIds?: string[];           // 关联季度目标ID(目标复盘)
  relatedGoalNames?: string[];         // 关联季度目标名称
  relatedGoalMeasureIds?: string[];    // 关联季度措施ID(目标复盘)
  relatedGoalMeasureNames?: string[];  // 关联季度措施名称
  
  relatedTeamTasks?: {                 // 团队任务汇报(自动生成)
    thisWeek?: string[];               // 本周团队任务ID(周例会)
    thisWeekNames?: string[];          // 本周团队任务名称
    thisWeekProgress?: number[];       // 本周团队任务进度
    nextWeek?: string[];               // 下周团队任务ID(周例会)
    nextWeekNames?: string[];          // 下周团队任务名称
    thisMonth?: string[];              // 本月团队任务ID(月度例会)
    thisMonthNames?: string[];         // 本月团队任务名称
    thisMonthProgress?: number[];      // 本月团队任务进度
    nextMonth?: string[];              // 下月团队任务ID(月度例会)
    nextMonthNames?: string[];         // 下月团队任务名称
  };
  
  relatedOpportunityIds?: string[];    // 关联商机ID(商机分析)
  relatedOpportunityNames?: string[];  // 关联商机名称
  relatedProjectIds?: string[];        // 关联项目ID(项目分析)
  relatedProjectNames?: string[];      // 关联项目名称
  relatedIssueIds?: string[];          // 关联问题ID(问题解决)
  relatedIssueNames?: string[];        // 关联问题名称
  
  content?: string;                    // 议题内容(其他议题)
  
  // 会议结论和新建任务(每个议题都有)
  conclusion?: string;                 // 会议结论
  newTaskIds?: string[];               // 新建任务ID数组
  newTaskNames?: string[];             // 新建任务名称数组
}

// 议题类型
type AgendaType = 
  | '目标复盘'        // 关联季度目标 + 季度措施
  | '团队任务汇报'    // 自动生成本周/本月 + 下周/下月团队任务列表
  | '商机分析'        // 关联商机
  | '项目分析'        // 关联项目
  | '问题解决'        // 关联问题
  | '其他议题';      // 自由文本

// 会议类型
type MeetingType = 
  | '周例会'
  | '月度例会'
  | '季度例会'
  | '专题会议'
  | '临时会议'
  | '项目评审会'
  | '目标复盘会';

// 会议状态
type MeetingStatus = 
  | '待召开'   // 会议创建，还未开始
  | '进行中'   // 会议正在进行
  | '已结束'   // 会议已结束，待整理纪要
  | '已完成'   // 纪要已整理完成
  | '已取消';  // 会议取消
```

### 3.1.2 功能列表

#### (1) 会议列表展示
**功能描述**: 展示所有会议记录，支持筛选和搜索

**展示信息**:
- 会议标题
- 会议类型标签
- 会议状态标签
- 开始时间
- 主持人
- 参会人员数量
- 议题数量 ⭐ 新增
- 关联问题数量
- 操作按钮(查看、编辑、删除)

**筛选条件**:
- 会议类型(全部/周例会/月度例会/...)
- 会议状态(全部/待召开/进行中/已结束/...)
- 时间范围(本周/本月/本季度/自定义)

**排序规则**:
- 默认按开始时间倒序

#### (2) 创建会议
**功能描述**: 创建新的会议记录

**表单字段**:
```typescript
// 基础信息(必填)
- 会议标题 (input, required, max: 100)
- 会议类型 (select, required)
- 开始时间 (datetime-picker, required)
- 结束时间 (datetime-picker, required)
- 主持人 (user-select, required)
- 参会人员 (multi-user-select, required, min: 1)

// 会议方式
- 是否线上会议 (checkbox)
- 会议地点 (input, optional, max: 100) // 线下时必填
- 会议链接 (input, optional, max: 200) // 线上时必填

// 记录人
- 记录人 (user-select, optional)

// ⭐ 会议议题(新增，支持多个议题)
- [+ 添加议题] 按钮
  
  每个议题包含:
  * 议题标题 (input, required, max: 100)

    - 商机分析
    - 项目分析
    - 问题解决
    - 其他议题

  * 根据议题类型显示不同的关联内容:

    - 关联季度措施 (multi-select)
      • 下拉列表: {措施名称} - {状态}
      • 数据来源: goalMeasures 集合
    
    【团队任务汇报】:
    - 自动展示任务列表(根据会议类型自动生成，无需手动选择)

        ▪ 下周团队任务列表
      • 月度例会: 
        ▪ 本月团队任务列表
        ▪ 下月团队任务列表
      • 任务列表格式: {任务名称} - {负责人} - {进度}% - {状态}
      • 数据查询逻辑:
        ```javascript
        // 周例会 - 本周团队任务
        {
          level: '团队级',
          $or: [
            { startDate: { $gte: thisWeekStart, $lte: thisWeekEnd } },
            { endDate: { $gte: thisWeekStart, $lte: thisWeekEnd } }
          ]
        }
        
        // 月度例会 - 本月团队任务
        {
          level: '团队级',
          $or: [
            { startDate: { $gte: thisMonthStart, $lte: thisMonthEnd } },
            { endDate: { $gte: thisMonthStart, $lte: thisMonthEnd } }
          ]
        }
        ```
    
    【商机分析】:
    - 选择商机 (multi-select)
      • 下拉列表: {商机名称} - {客户} - {金额} - {阶段}
      • 数据来源: opportunities 集合
    
    【项目分析】:
    - 选择项目 (multi-select)
      • 下拉列表: {项目名称} - {项目编号} - {状态}
      • 数据来源: projects 集合
    
    【问题解决】:
    - 选择问题 (multi-select)
      • 下拉列表: {问题名称} - {责任人} - {状态}
      • 数据来源: issueRecords 集合
    
    【其他议题】:
    - 议题内容 (textarea, required, max: 1000)
  
  * 会议结论 (textarea, optional, max: 1000)
  * 新建任务 (可选，支持多个)
    - [+ 添加任务] 按钮
    - 任务名称、负责人、截止日期
  
  * 议题排序 [↑] [↓] 按钮
  * [删除议题] 按钮
```

**表单验证**:
- 会议标题: 不能为空，长度1-100字符
- 开始时间: 不能为空，不能早于当前时间(创建时)
- 结束时间: 不能为空，必须晚于开始时间
- 主持人: 必须选择
- 参会人员: 至少选择1人
- 会议地点/链接: 根据会议方式，至少填写一个
- 议题: 至少包含1个议题
- 议题标题: 不能为空
- 议题类型: 必须选择
- 议题汇报人: 至少选择1人
- 其他议题的议题内容: 不能为空

**业务规则**:
- 会议创建后，状态默认为"待召开"
- 创建人自动加入参会人员(如果未选择)
- 主持人自动加入参会人员(如果未选择)
- 团队任务汇报的任务列表根据会议类型和会议时间自动生成
- 新建任务会自动创建到任务管理系统

#### (3) 编辑会议
**功能描述**: 修改会议信息

**权限控制**:
- 创建人可以编辑
- 主持人可以编辑
- 管理员可以编辑

**可编辑字段**:
- 状态为"待召开"时: 所有字段可编辑
- 状态为"进行中"时: 
  * 不可修改: 开始时间、主持人
  * 可修改: 其他字段、议题内容、会议结论
- 状态为"已结束"/"已完成"时:
  * 不可修改: 基础信息(标题、时间、人员)
  * 可修改: 议题内容、会议结论、会议纪要

#### (4) 删除会议
**功能描述**: 软删除会议记录(放入回收站)

**权限控制**:
- 仅创建人和管理员可删除
- 状态为"进行中"的会议不可删除

**删除逻辑**:
- 软删除: 设置 `isDeleted = true`, `deletedAt = now()`
- 删除后会议不在列表展示
- 可从回收站恢复或永久删除

### 3.1.3 会议状态管理

**状态流转**:
```
待召开 → [开始会议] → 进行中 → [结束会议] → 已结束 → [完成纪要] → 已完成
   ↓                                                          ↑
 [取消]                                                      [编辑]
   ↓                                                          ↓
 已取消                                                     已完成
```

**状态触发条件**:
- 待召开 → 进行中: 手动点击"开始会议"，或系统自动在开始时间到达时更新
- 进行中 → 已结束: 手动点击"结束会议"，或系统自动在结束时间到达时更新
- 已结束 → 已完成: 手动点击"完成纪要"，确认纪要整理完成
- 任何状态 → 已取消: 手动点击"取消会议"

**状态颜色规范**:
- 待召开: `bg-gray-100 text-gray-800`
- 进行中: `bg-blue-100 text-blue-800`
- 已结束: `bg-yellow-100 text-yellow-800`
- 已完成: `bg-green-100 text-green-800`
- 已取消: `bg-red-100 text-red-800`

## 3.3 问题列表

### 3.3.1 功能描述
问题列表展示所有解决方式为"会议"的问题记录，这些问题来自问题管理模块。

### 3.3.2 数据来源
**查询条件**:
```typescript
// 从问题管理(issueRecords)集合查询
{
  solutionMethod: '会议',  // 解决方式为会议
  relatedMeetingId: { $exists: true } // 有关联会议ID
}
```

**关联字段**:
- `relatedMeetingId`: 关联的会议ID(问题管理中的字段)
- 通过此字段可以反向查询某个会议的所有问题

### 3.3.3 展示内容

**列表字段**:
- 问题名称
- 问题描述(简略)

## 7. 交互设计

### 7.1 创建会议流程
```
1. 用户点击"新建会议"按钮
2. 弹出创建会议弹窗
3. 填写会议基本信息
4. [+ 添加议题]
5. 选择议题类型
6. 根据议题类型填写关联内容
   - 目标复盘: 选择目标和措施
   - 团队任务汇报: 自动生成任务列表(无需手动选择)
   - 商机分析: 选择商机
   - 项目分析: 选择项目
   - 问题解决: 选择问题
   - 其他议题: 填写议题内容
7. 选择汇报人(多选)
8. (可选)填写会议结论
9. (可选)添加新建任务
10. 调整议题顺序
11. 点击"确定"提交
12. 系统验证表单
13. 调用云函数创建会议
14. 创建成功，关闭弹窗，刷新列表
15. Toast提示"创建成功"
```

### 7.2 编辑议题流程
```
1. 用户进入会议详情页
2. 点击议题的"编辑"按钮
3. 修改议题内容
4. 填写/更新会议结论
5. 添加新建任务
6. 点击"保存"
7. 系统保存议题内容
8. Toast提示"保存成功"
```

### 7.3 团队任务汇报自动生成流程
```
1. 用户选择议题类型为"团队任务汇报"
2. 系统读取会议类型(周例会/月度例会)和会议时间
3. 根据会议类型自动查询任务:
   - 周例会: 查询本周和下周的团队级任务
   - 月度例会: 查询本月和下月的团队级任务
4. 系统自动填充任务列表到议题中
5. 用户无需手动选择任务
6. 保存议题时自动保存任务ID列表
```
