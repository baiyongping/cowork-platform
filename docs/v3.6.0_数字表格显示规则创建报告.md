## 📚 规则主要内容

### 字体规范核心要点

| 元素 | 字体 | 大小 | 权重 |
|-----|------|------|------|
| 普通数字 | font-mono | 15px | normal |
| 合计行 | font-mono | 16px | bold |
| 表头 | - | 14px | semibold |

### 数字格式规范

```typescript
// 千分位显示
formatNumber(1234567) → "1,234,567"

// 金额(万元,一位小数)
formatAmount(1234.567) → "1,234.6"

// 百分比(一位小数)
formatPercent(85.555) → "85.6%"
```

### 颜色语义

- **text-gray-900**: 普通数字
- **text-red-600**: 负数/异常
- **text-green-600**: 达标/正常
- **text-orange-600**: 警告
- **text-gray-400**: 未填写

### 合计行样式

```tsx
<tr className="bg-blue-50 border-t-2 border-b-2 border-blue-300">
  <td className="px-4 py-3 text-left font-bold">合计</td>
  <td className="px-4 py-3 text-right font-mono text-base font-bold">
    {formatAmount(total)}
  </td>
</tr>
```
