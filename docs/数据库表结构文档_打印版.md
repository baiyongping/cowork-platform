## 📝 详细表结构

### 1. users - 用户信息表

**表名**: `users`  
**描述**: 存储系统用户的基本信息、角色权限、部门归属等数据

#### 字段列表

| 字段名 | 类型 | 必填 | 说明 | 默认值 |
|-------|------|-----|------|--------|
| _id | string | ✅ | MongoDB主键 | 自动生成 |
| _openid | string | ❌ | CloudBase用户标识 | - |
| username | string | ✅ | 用户名（唯一） | - |
| password | string | ✅ | 密码（SHA-256加密） | - |
| email | string | ✅ | 邮箱（唯一） | - |
| phone | string | ✅ | 手机号 | - |
| name | string | ✅ | 真实姓名 | - |
| role | string | ✅ | 角色（admin/user） | 'user' |
| department | string | ✅ | 部门 | - |
| avatar | string | ❌ | 头像URL | - |
| isActive | boolean | ✅ | 是否激活 | true |
| approvalStatus | string | ✅ | 审核状态 | 'pending' |
| status | string | ✅ | 在职状态 | '在职' |
| createdAt | Date | ✅ | 创建时间 | 自动生成 |
| updatedAt | Date | ✅ | 更新时间 | 自动生成 |

#### 索引

- `username` (唯一索引)
- `email` (唯一索引)
- `_openid` (普通索引)

#### 枚举值

- **role**: `'admin'` | `'user'`
- **approvalStatus**: `'pending'` | `'approved'` | `'rejected'`
- **status**: `'在职'` | `'离职'` | `'休假'`

## 🔗 数据关系图

```
users (用户)
  ├─→ tasks.owner (任务负责人)
  ├─→ tasks.collaborators[] (任务协同人)
  ├─→ opportunities.owner (商机负责人)
  ├─→ projects.owner (项目负责人)
  ├─→ projects.members[] (项目成员)
  ├─→ goals.owner (目标负责人)
  ├─→ departments.leader (部门负责人)
  ├─→ task_comments.userId (评论人)
  └─→ operation_logs.userId (操作人)

opportunities (商机)
  └─→ projects.opportunityId (商机转化的项目)

tasks (任务)
  ├─→ tasks.relatedTo → opportunities._id (商机任务)
  ├─→ tasks.relatedTo → projects._id (项目任务)
  └─→ task_comments.taskId (任务评论)

departments (部门)
  └─→ users.department (用户所属部门)
```
