### 3. 公式引擎实现

#### 核心函数

**formulaToString** - 将公式节点数组转换为可读字符串
```typescript
const formulaToString = (formula: FormulaNode[]): string => {
  return formula.map(node => {
    if (node.type === 'account') {
      const account = accounts.find(acc => acc.id === node.value);
      return account?.name || '未知科目';
    }
    return node.value;
  }).join(' ');
};
```

## 九、重要提醒

### ⚠️ 数据迁移说明
- 现有的旧版公式数据**不会自动迁移**到新格式
- 新创建的计算项将使用新版formula字段
- 编辑旧科目时可选择性升级到新格式
- 建议在合适时机统一迁移(提供迁移工具)

### ⚠️ 删除计算项时注意
- 删除科目前需检查是否被其他公式引用
- 目前暂未实现引用检查(下一版本补充)

### ⚠️ 性能考虑
- 复杂公式(30+节点)可能影响计算性能
- 建议公式长度不超过20个节点
- 深度嵌套(5层以上括号)需谨慎使用
