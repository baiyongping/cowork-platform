# 解决方式字段移除"形成任务"选项说明

## 修改概述

移除问题管理中的"形成任务"解决方式选项，保留三个核心解决方式。

---

## 📝 修改详情

### 1. 类型定义 (types/issue.ts)

**修改前：**
```typescript
export type IssueSolution = '本人解决' | '转交' | '会议研讨' | '形成任务';
```

**修改后：**
```typescript
export type IssueSolution = '本人解决' | '转交' | '会议研讨';
```

### 2. 样式函数 (types/issue.ts)

移除了 `getSolutionColor` 函数中关于"形成任务"的绿色样式映射：

```typescript
case '形成任务':
  return 'bg-green-100 text-green-800';
```

### 3. 组件下拉选项更新

**修改的组件：**
- `components/CreateIssueModal.tsx` - 新建问题弹窗
- `components/EditIssueModal.tsx` - 编辑问题弹窗

**修改内容：**
移除了以下选项：
```html
<option value="形成任务">形成任务</option>
```

---

## 🎨 解决方式完整列表（修改后）

1. **本人解决** (青色 - bg-cyan-100)
2. **转交** (蓝色 - bg-blue-100)
3. **会议研讨** (紫色 - bg-purple-100)

---

## ✅ 修改的文件清单

| 文件路径 | 修改内容 |
|---------|---------|
| `types/issue.ts` | 移除类型定义中的'形成任务'，移除颜色映射 |
| `components/CreateIssueModal.tsx` | 移除下拉选项 |
| `components/EditIssueModal.tsx` | 移除下拉选项 |

---

## 🔄 生效方式

**刷新页面**后：
- ✅ 新建问题时不再显示"形成任务"选项
- ✅ 编辑问题时不再显示"形成任务"选项
- ✅ 已存在的"形成任务"数据会正常显示但无法再次选择

---

## 📋 注意事项

1. **历史数据**：已有问题如果选择了"形成任务"，仍会正常显示，但编辑时无法再选择此选项
2. **数据迁移**：如需处理历史数据，可运行数据库脚本将"形成任务"批量改为其他解决方式
3. **向后兼容**：类型定义的修改不影响已有数据的显示
