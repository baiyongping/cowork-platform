# 任务公开权限功能说明

## 功能概述

为任务管理模块添加了"是否公开"的权限控制功能，支持公开任务和私密任务两种模式。

## 功能详情

### 1. 任务公开设置

在创建和编辑任务时，可以设置任务的公开状态：

- **公开任务（isPublic: true）**
  - ✓ 团队所有成员都可以看到此任务
  - 默认选项，适用于团队协作任务
  
- **私密任务（isPublic: false）**
  - ✗ 仅以下人员可见：
    - 任务负责人
    - 任务协同人
    - 任务负责人所在部门的部门负责人
    - 管理员角色（admin）
  - 适用于个人任务或敏感任务

### 2. 权限控制逻辑

#### 任务列表查询
在任务列表页面加载时，系统会根据当前用户的身份和权限，过滤显示任务：

```typescript
// 1. 公开任务 - 所有人可见
if (task.isPublic) return true;

// 2. 私密任务 - 需要满足以下条件之一
const isOwner = task.owner._id === currentUserId;           // 任务负责人
const isCollaborator = task.collaborators.includes(userId);  // 协同人
const isDepartmentHead = currentUserRole === 'department_head' && // 部门负责人
                        currentUserDepartment === taskOwnerDepartment;
const isAdmin = currentUserRole === 'admin';                 // 管理员

return isOwner || isCollaborator || isDepartmentHead || isAdmin;
```

#### 部门负责人权限
部门负责人可以看到本部门成员创建的所有私密任务，条件为：
- 当前用户角色为 `department_head`
- 当前用户的部门与任务负责人的部门相同
- 部门字段不为空

### 3. UI 设计

#### 创建/编辑任务表单
- 复选框：选择是否公开任务
- 动态提示文字：
  - 勾选时：✓ 团队所有成员都可以看到此任务
  - 不勾选时：✗ 仅任务负责人、协同人、部门负责人和管理员可见

#### 任务列表
- 用户只能看到有权限查看的任务
- 无权限的私密任务不会出现在列表中

## 技术实现

### 数据库字段
任务表（tasks）中使用 `isPublic` 字段：
- 类型：`boolean`
- 默认值：`true`
- 说明：标识任务是否公开

### 前端实现

#### TaskManagementPage.tsx
```typescript
// 加载任务时，获取当前用户信息
const currentUserStr = localStorage.getItem('current_user');
const currentUser = JSON.parse(currentUserStr);
const currentUserId = currentUser.userId;
const currentUserRole = currentUser.role;

// 查询用户完整信息以获取部门
const userResult = await db.collection('users').doc(currentUserId).get();
const currentUserDepartment = userResult.data[0].department;

// 权限过滤任务
const filteredTasks = tasksWithUsers.filter((task: any) => {
  if (task.isPublic) return true; // 公开任务
  
  // 私密任务权限判断
  const isOwner = task.owner._id === currentUserId;
  const isCollaborator = task.collaborators?.some((c: any) => c._id === currentUserId);
  const isAdmin = currentUserRole === 'admin';
  const isDepartmentHead = currentUserRole === 'department_head' && 
                           currentUserDepartment === taskOwnerDepartment;
  
  return isOwner || isCollaborator || isDepartmentHead || isAdmin;
});
```

#### CreateTaskModal.tsx & EditTaskModal.tsx
```typescript
// 表单数据包含 isPublic 字段
const [formData, setFormData] = useState({
  // ... 其他字段
  isPublic: true // 默认公开
});

// UI 渲染
<div className="space-y-2">
  <div className="flex items-center gap-2">
    <input
      type="checkbox"
      id="isPublic"
      checked={formData.isPublic}
      onChange={(e) => setFormData({ ...formData, isPublic: e.target.checked })}
    />
    <label htmlFor="isPublic">公开任务</label>
  </div>
  <p className="text-xs text-gray-500">
    {formData.isPublic 
      ? '✓ 团队所有成员都可以看到此任务' 
      : '✗ 仅任务负责人、协同人、部门负责人和管理员可见'}
  </p>
</div>
```

## 使用场景

### 公开任务场景
- 团队协作任务
- 公司级任务
- 需要多人知晓的工作事项
- 跨部门协作项目

### 私密任务场景
- 个人工作计划
- 敏感商务信息
- 部门内部事务
- 需要保密的项目任务

## 权限矩阵

| 角色/身份 | 公开任务 | 私密任务（负责人） | 私密任务（协同人） | 私密任务（部门负责人） | 私密任务（其他） |
|---------|---------|-----------------|----------------|---------------------|----------------|
| 任务负责人 | ✓ | ✓ | - | - | - |
| 任务协同人 | ✓ | - | ✓ | - | - |
| 部门负责人 | ✓ | - | - | ✓ | - |
| 管理员 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 普通成员 | ✓ | - | - | - | - |

说明：
- ✓ 表示有权限查看
- \- 表示无权限查看

## 数据安全

1. **前端过滤**：在任务列表加载时进行权限过滤，无权限的任务不会显示
2. **用户验证**：基于 localStorage 中的用户信息进行身份验证
3. **部门验证**：通过查询用户完整信息获取准确的部门信息
4. **角色控制**：支持管理员、部门负责人等不同角色的权限管理

## 后续优化建议
