# 任务回收站功能说明

## 功能概述

任务回收站功能为用户提供了一个安全删除机制，防止误删重要任务。用户可以将不需要的任务放入回收站，并在需要时恢复，或者永久删除。

## 功能特点

### 1. 软删除机制
- 任务删除改为"放入回收站"，不会立即删除数据
- 通过 `isDeleted: true` 标记区分正常任务和已删除任务
- 记录删除时间 `deletedAt`

### 2. 回收站入口
- 位置：任务管理页面，新建任务按钮旁边
- 图标：垃圾桶图标 (Trash2)
- 颜色：灰色背景，与新建任务按钮区分

### 3. 回收站列表
显示所有已删除的任务，包含以下列：
- **任务名称**：显示任务名称和简短描述
- **级别**：公司级/团队级/个人级（带颜色标签）
- **类型**：日常工作/商机跟进/项目任务
- **负责人**：显示负责人姓名和团队
- **截止日期**：任务原定的截止日期
- **状态**：任务删除前的状态
- **删除时间**：任务被放入回收站的时间

### 4. 搜索功能
- 支持按任务名称或负责人搜索
- 实时过滤显示结果

### 5. 任务详情
点击回收站中的任务可查看详细信息：
- 任务基本信息（级别、类型、负责人、状态等）
- 任务描述
- 完成进度
- 删除时间提示

### 6. 两个操作按钮

#### 返回继续执行（恢复）
- 按钮位置：右侧，绿色背景
- 图标：旋转箭头 (RotateCcw)
- 功能：
  - 移除 `isDeleted` 标记
  - 清空 `deletedAt` 时间
  - 更新 `updatedAt` 为当前时间
  - 任务恢复到正常列表
- 说明：恢复后任务保留删除前的所有信息和状态

#### 永久删除
- 按钮位置：左侧，红色背景
- 图标：垃圾桶图标 (Trash2)
- 功能：
  - 真正删除任务记录
  - 同时删除任务相关的所有评论
  - 需要二次确认
- 警告：永久删除后无法恢复

### 7. 二次确认对话框
永久删除时会弹出确认对话框：
- 显示警告图标和提示信息
- 高亮显示将要删除的任务名称
- 提示相关评论也将被删除
- 用户必须点击"确认永久删除"才会执行

## 技术实现

### 数据库字段
```typescript
interface Task {
  // ... 其他字段
  isDeleted?: boolean;      // 是否已删除
  deletedAt?: Date | string; // 删除时间
}
```

### 查询逻辑
- **正常任务列表**：查询 `isDeleted != true` 的任务
- **回收站列表**：查询 `isDeleted == true` 的任务

### 软删除
```typescript
await db.collection('tasks').doc(taskId).update({
  isDeleted: true,
  deletedAt: new Date(),
  updatedAt: new Date()
});
```

### 恢复任务
```typescript
await db.collection('tasks').doc(taskId).update({
  isDeleted: false,
  deletedAt: null,
  updatedAt: new Date()
});
```

### 永久删除
```typescript
// 删除任务
await db.collection('tasks').doc(taskId).remove();

// 删除相关评论
const comments = await db.collection('task_comments')
  .where({ taskId })
  .get();
  
await Promise.all(
  comments.data.map(comment =>
    db.collection('task_comments').doc(comment._id).remove()
  )
);
```

## 用户操作流程

### 删除任务流程
1. 在任务列表或任务详情中点击"放入回收站"
2. 弹出确认对话框
3. 确认后，任务从正常列表消失，进入回收站

### 恢复任务流程
1. 点击"回收站"按钮
2. 在回收站列表中找到要恢复的任务
3. 点击任务查看详情
4. 点击"返回继续执行"按钮
5. 任务恢复到正常列表

### 永久删除流程
1. 在回收站中点击任务查看详情
2. 点击"永久删除"按钮
3. 弹出二次确认对话框，说明永久删除无法恢复
4. 确认后，任务和相关评论被永久删除

## 注意事项

1. **数据安全**：永久删除前有二次确认，防止误操作
2. **关联数据**：永久删除会同时删除任务的所有评论
3. **状态保持**：恢复任务后，任务的所有信息和状态保持不变
4. **搜索功能**：回收站支持按任务名称和负责人搜索
5. **UI区分**：
   - 放入回收站：橙色按钮
   - 永久删除：红色按钮
   - 恢复：绿色按钮
