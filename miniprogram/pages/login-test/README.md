# 微信登录测试页面

## 页面功能

这是一个专门用于测试微信小程序用户登录和获取头像功能的页面。

## 主要功能

### 1. 一键完整登录
- 自动完成获取登录code
- 自动获取用户openId
- 自动获取用户头像和昵称
- 将用户信息保存到云数据库

### 2. 分步操作
- **第一步：获取登录Code**
  - 调用 `wx.login()` 获取临时登录凭证code
  - 调用云函数 `wxLogin` 获取用户openId
  
- **第二步：获取用户头像**
  - 支持新的 `wx.getUserProfile()` API
  - 兼容旧版 `wx.getUserInfo()` API
  - 支持更换头像功能

### 3. 状态监控
- 实时显示当前登录状态
- 显示获取的code和openId
- 显示用户信息（头像、昵称等）

### 4. 操作日志
- 详细记录每一步操作的结果
- 显示成功/失败信息
- 支持清除日志

### 5. 数据管理
- 将用户信息保存到 `users` 集合
- 支持新用户创建和老用户信息更新
- 本地存储用户信息

## 访问方式

1. **直接访问**: 在小程序中输入路径 `/pages/login-test/login-test`
2. **通过"我的"页面**: 在个人中心页面点击"登录测试"菜单项

## 技术实现

### 云函数
- 使用 `wxLogin` 云函数获取用户openId
- 支持保存用户信息到云数据库

### 数据存储
- 集合名称：`users`
- 存储字段：openId、nickName、avatarUrl、gender、city、province、country等

### API使用
- `wx.login()`: 获取登录凭证
- `wx.getUserProfile()`: 获取用户信息（新版本）
- `wx.getUserInfo()`: 获取用户信息（兼容版本）
- `wx.cloud.callFunction()`: 调用云函数

## 注意事项

1. **隐私政策**: 获取用户信息需要用户授权
2. **版本兼容**: 自动检测并使用合适的API版本
3. **数据安全**: 敏感信息如openId不会在前端显示
4. **错误处理**: 完善的错误处理和用户提示

## 测试步骤

### 完整流程测试
1. 点击"一键完整登录"
2. 授权用户信息获取
3. 查看用户信息显示
4. 检查操作日志
5. 验证数据保存到云数据库

### 分步操作测试
1. 点击"获取登录Code"
2. 查看是否获取到code和openId
3. 点击"获取用户头像"
4. 授权并查看用户信息
5. 测试更换头像功能

## 故障排除

### 常见问题
1. **获取code失败**: 检查网络连接和小程序配置
2. **云函数调用失败**: 确认云函数名称和权限配置
3. **用户信息获取失败**: 检查用户授权状态
4. **数据保存失败**: 检查云数据库权限和集合是否存在

### 调试方法
1. 查看操作日志了解详细错误信息
2. 使用"检查当前状态"功能查看各变量值
3. 在开发者工具中查看Network和Console输出
